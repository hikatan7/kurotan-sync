[[anesthesia-essay-prompt]] で書いた読み物に図表を付けるときのプロンプト。図表は本文と1対1で対応させ、概念図と実測値を必ず区別する。

**Why:** ユーザーの教育資料は概念理解を優先した代表値を多く含むため、図を実測データのように見せると医学的に不正確になる。

**How to apply:** 以下をプロンプトとして使う。

```
上記の読み物に付ける図表一式を設計してください。

# 出力する項目（図表ごとに）
1. 図表タイトル（本文の見出しではなく、図が伝える一文）
2. 図表の目的
3. 図表の種類（概念図／模式図／折れ線グラフ／コンパートメント図／比較表 など）
4. レイアウト（配置、列構成、矢印の向き）
5. 図中のラベル（すべて列挙）
6. 矢印・線種の意味（実線＝薬物の移動、点線＝臨床効果との対応、双方向＝可逆的分布 など）
7. 使用する数式（あれば）と、その臨床的な意味
8. 概念図作成用の模式的な数値（実測値ではないことを明記）
9. 図中に入れる注意書き
10. 本文への接続文（図の直前に置く2〜3文）
11. キャプション（図番号＋一文の要約＋前提と限界）

# 最後に必ず出す表
- 図表と本文の対応表（図表番号／対応する本文の章／中心メッセージ／種類）
- 図表全体で伝える中心メッセージを1文で

# 図表作成時の必須注意点
1. 実測値と概念値を分ける。概念図の曲線を特定薬剤・特定患者の実測値として提示しない。
   実測グラフでは、薬剤名、対象、投与条件、採血時点、測定法、解析モデルを明記する。
2. モデル上の区画を解剖学的臓器と誤解させない。
   例：分布容積は、薬剤が実際に占める体内空間ではなく、体内薬物量と血漿中濃度から計算される
   薬物動態学的パラメータである、と必ず注記する。
3. 推定値であることを明記する。効果部位濃度は直接測定された脳内濃度ではなく、
   血中濃度と薬効の時間差をモデル上の区画で表現したもの。
4. 異なる種類の「濃度」を同列に置かない。測っている対象と、臨床効果との距離が異なる。
5. 作用機序を単一受容体に単純化しない。代表的な標的を示しつつ、
   全身麻酔の成立は複数の受容体・イオンチャネル・神経回路の変化によることを注記する。
6. 数字は代表値・範囲・条件をセットで示す。
```

## 3層の切り分け（本文でも図でも使う）
数値や因果関係は、次の3層に分けて書くと、面白さと医学的精度が両立する。

1. 確立した生理学
2. 臨床で役立つ近似
3. 魅力的だが単純化を含む比喩

（例：心拍数と寿命の関係、アロメトリーの指数、小児の無呼吸時脱飽和時間、薬物クリアランスの体重補正は、いずれも対象や条件で変わるため 2 か 3 に置く。）
