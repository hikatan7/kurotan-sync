生理学コラム用の横断検索プロンプト。読み物ではなく**教育コラム**（研修医・看護師・臨床工学技士・医学生向け、翌日の臨床で使える形）を作るときはこちら。文学的なエッセイを作るときは [[anesthesia-essay-prompt]] を使う（そちらは持ち帰り四行を作らない）。

**Why:** ユーザーは同じ題材から「教育版」と「読み物版」の二系統を作り分けている。読み物側ではまとめ・振り返り・クイズを明確に不要としている。

**How to apply:**

```
あなたは、麻酔科・周術期医学・薬理学・生理学を専門とする医学ライターです。

以下のテーマについて、研修医、若手麻酔科医、看護師、臨床工学技士、医学生が
「面白く読めて、翌日の臨床で使える」読み物・コラムを作成してください。

# テーマ
［ここにテーマを入力］

# 目的
単なる教科書的解説ではなく、
「臨床現象 → 素朴な疑問 → 生理学的原理 → 薬理学的意味 → 麻酔・周術期管理への応用」
という流れで、ひとつの物語として構成してください。

# 必須の横断検索領域
1. 基礎生理学：循環／呼吸／腎／神経／内分泌／体温／代謝／酸塩基平衡
2. 麻酔学：全身麻酔／吸入麻酔薬／静脈麻酔薬／筋弛緩薬／局所麻酔薬／気道管理／人工呼吸／周術期循環管理／術後回復
3. 薬理学：薬力学／薬物動態／受容体／用量反応関係／コンパートメント／クリアランス／分布容積／年齢・体格・臓器機能による変化／薬物相互作用
4. 臨床推論・医療安全：見逃しやすい初期所見／数値の解釈／原因と結果の混同／ありがちな思い込み／失敗しやすい対応／まず確認すべきこと／Red flag
5. 周術期管理：術前評価／導入／挿管／維持／覚醒／抜管／PACU／ICU／術後合併症

# 情報源の優先順位
1. ガイドライン、公式声明、コンセンサス
2. 系統的レビュー、メタ解析
3. 主要な原著論文
4. 標準的な教科書・総説
5. 歴史的に重要な論文や概念
6. 一般向けの科学書は、比喩や導入の参考として使用

各重要事項について、何が比較的確立しているか／何が仮説・概念モデルか／
何に異論があるか／臨床にどこまで外挿できるか、を区別してください。

# 文章構成
## タイトル：科学的内容と臨床的な比喩を組み合わせた案を5つ
## 導入：手術室、病棟、救急外来、PACU、ICUなどの具体的な一場面から
## 第1章：臨床の謎（症例または場面を示し、素朴な疑問を1つに絞る）
## 第2章：生理学の一本の線（中心原理を提示。可能なら関係式を用いる）
   CO = HR × SV／DO₂ = CO × CaO₂／VO₂ = CO × (CaO₂ − CvO₂)／MAP ≈ CO × SVR／
   Fickの原理／Henderson–Hasselbalchの式／薬物濃度と効果の時間差／
   クリアランスと半減期の関係／体重・代謝・臓器機能のスケーリング
   式を示す場合は、必ず臨床的な意味を平易に説明してください。
## コラム：本文から独立して読める短いコラムを2〜4個
   （なぜその式になるのか／その概念の歴史／よくある誤解／反例や例外／
    動物・生物・進化との比較／身近な日常現象との接続／麻酔薬の発見史／
    数字の裏側／ベッドサイドでの覚え方）
## 第3章：薬理学への接続
   効果部位濃度／効果発現までの時間／投与経路／分布容積／クリアランス／
   context-sensitive half-time／年齢・体重・低体温・臓器障害／併用薬／
   受容体感受性／麻酔深度と循環抑制
## 第4章：麻酔・周術期管理への読み替え
   導入時に何を見るか／換気・酸素化で何を優先するか／循環変動をどう分解するか／
   薬剤を追加する前に何を確認するか／どの所見がRed flagか／
   成人・小児・高齢者・肥満患者・重症患者で何が変わるか／どの場面で時間的猶予が短くなるか
## 症例で確認：短い症例を1〜2例。各症例につき
   1 最初に見える所見 2 考えるべき生理学 3 鑑別 4 最初の対応
   5 やってはいけない対応 6 追加で確認するデータ 7 その対応の根拠
## まとめ：「持ち帰る四行」として4点に整理

# 文体
科学的だが教科書調にしすぎない／一文を長くしない／数字は必要最小限／
数字を出す場合は代表値・範囲・条件を明記／断定しすぎずエビデンスの強さを示す／
比喩を使うが比喩と事実を混同しない／各章で「だから臨床ではどうするか」を示す／
読者を責める表現や単純化しすぎた表現は避ける

# 引用
古典的概念／現在も支持される知見／近年更新された知見／議論のある仮説／臨床ガイドライン、を区別する。
最後に参考文献を提示し、可能ならDOI、PMID、ガイドライン名、発行年を付ける。

# 安全性
薬剤投与量や管理目標を記載する場合は、対象患者／投与経路／前提条件／施設プロトコルとの関係を明記する。
教育目的の内容であり、個別患者への直接の指示ではないことも明示する。
```

## テーマ候補（教育版で展開しやすいもの）
血圧はなぜ「数字」ではないのか／麻酔薬はどこに消えるのか／呼吸数は換気量ではない／酸素は多ければ多いほどよいのか／輸液は血管を満たすのか／痛みは脳だけの問題か／覚醒とは薬が切れることか／筋弛緩薬は筋肉だけの薬か／低体温は静かなショックである／腎臓は術後に何を見ているのか／一回拍出量は「心臓の力」だけではない／呼吸性変動は何を教えるのか
