麻酔・薬理・生理の読み物を作るとき、**「持ち帰る四行」「まとめ」「明日から使えるポイント」「振り返り」「クイズ」は付けない**。臨床応用は教訓としてではなく、物語の自然な帰結として扱う。最後は最初の場面に戻るか、比喩を静かに反転させて余韻で終える。

**Why:** ユーザーは教育資料としてのチェックリストではなく、独立した短編科学エッセイとしてシリーズを増やしたいと明言している。教育版が必要なときは [[anesthesia-crosssearch-prompt]] を別に使う。

**How to apply:**
- 1本ごとに独立した読み物として成立させる。作品ごとに異なる比喩と導入場面を使い、同じ説明・同じ結論を繰り返さない。
- 中心に強い比喩を1つ置く（「ゾウとネズミ」型）。比喩と事実は明確に区別して書く。
- 記事を成果物として出すときは、**毎回パレット・書体・レイアウトを変える**。同じテンプレートを流用しない。
- 数値や因果は3層に分けて扱う（確立した生理学／臨床で役立つ近似／魅力的だが単純化を含む比喩）。詳細は [[anesthesia-figure-prompt]]。
- 図表は本文と1対1で対応させ、概念図であることを必ずキャプションに書く。
- 執筆プロンプトは [[anesthesia-essay-prompt]]、テーマのストックは [[anesthesia-essay-themes]]。
