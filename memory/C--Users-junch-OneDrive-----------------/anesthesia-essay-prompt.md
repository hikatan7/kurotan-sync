麻酔学・薬理学・生理学の科学読み物コラムを量産するための保存プロンプト。ユーザーが「読み物を作って」「コラムを書いて」と言った場合はこれを使う。テーマだけ差し替える。関連: [[anesthesia-figure-prompt]] [[anesthesia-essay-themes]] [[anesthesia-essay-style]]

**Why:** ユーザーは教育ファイル集シリーズとして、チェックリスト型の教材ではなく文学的な科学エッセイを大量に作りたい。まとめ・クイズ・振り返りは明確に不要と指示済み。

**How to apply:** 以下をそのまま基本プロンプトとして使用し、`［テーマを入力］` を置き換える。

```
あなたは、麻酔学・薬理学・生理学を題材にした科学読み物の作家です。

以下のテーマについて、教科書や講義資料ではなく、
「読んでいるうちに生理学の見方が変わる」長めのコラムを書いてください。

# テーマ
［テーマを入力］

# 文章の目的
実務上のチェックリストや、研修医向けのまとめを作るのではありません。
読者が、人体、薬、麻酔、手術、意識、循環、呼吸を、
少し不思議で奥行きのある現象として感じられる文章にしてください。

# 文章の雰囲気
- 科学的であること
- しかし教科書的にしすぎないこと
- 静かな驚きがあること
- 一つの疑問を深く掘り下げること
- 知識を羅列せず、物語として展開すること
- 比喩を使うこと
- 比喩と事実は明確に区別すること
- 読者に結論を急いで渡さないこと
- 最後まで余韻を残すこと

# 構成

## タイトル
印象に残るタイトルを5案提示してください。
科学用語をそのままタイトルにせず、
「血管は水槽ではない」
「眠りはスイッチではない」
のように、概念と比喩を組み合わせてください。

## 導入
麻酔導入、挿管、人工呼吸、薬剤投与、術後覚醒、出血、低体温、疼痛など、
手術室で起こる具体的な場面から始めてください。

最初の段落で、読者が次のような疑問を持つようにしてください。

- なぜ同じ薬なのに効き方が違うのか
- なぜ数値が変わっても患者の印象が変わらないのか
- なぜ体内の変化は、見えないのに突然現れるのか
- なぜ身体は、ある状態を守ろうとして別の機能を犠牲にするのか

## 第1章：見えているものと、見えていないもの
モニターに表示される数字、患者の表情、脈拍、血圧、SpO₂、呼気終末二酸化炭素、尿量などを取り上げてください。
ただし、数値を単純に「正常」「異常」と分類しないでください。
数字の背後にある流れ、時間、遅れ、代償、測定の限界を描いてください。

## 第2章：生理学の深部
テーマを説明する中心的な生理学を扱ってください。必要に応じて、以下を使ってください。
CO = HR × SV／DO₂ = CO × CaO₂／VO₂ = CO × (CaO₂ − CvO₂)／MAP ≈ CO × SVR／Fickの原理／
Frank–Starling機構／Henderson–Hasselbalchの式／肺胞換気と死腔／拡散と灌流／膜電位／
受容体占有率／クリアランス／分布容積／半減期／効果部位濃度／時間薬理学／allometric scaling

式を出すときは、式の説明だけで終わらせず、その式が表している世界観を文章で説明してください。

## 第3章：薬は身体の中で何をしているのか
薬剤を単なる「作用薬」として扱わないでください。以下の視点を含めてください。
薬はどこに分布するのか／どのくらいの時間血液中にいるのか／血中濃度と効果はなぜずれるのか／
受容体は薬にどう応答するのか／作用は直線的ではないのか／体温・年齢・循環・蛋白結合は薬の運命をどう変えるのか／
薬が効くことと患者が変化することは同じなのか／複数の薬が重なったとき効果は足し算になるのか

薬理学を、分子から患者までの長い旅として描いてください。

## 第4章：人体以外の視点
動物の生理／進化／物理学／数学／熱力学／情報理論／建築／都市設計／海洋／音楽／時間／記憶／睡眠／歴史／麻酔薬の発見史
ただし、無関係な雑学を足すのではなく、テーマの理解を深める接続だけを使ってください。

## コラム
本文の途中に、独立して読める短いコラムを3〜5個入れてください。候補：
なぜこの法則はこの形になるのか／一見正しそうで実は危険な説明／反例は何を教えてくれるのか／
その数字は誰にとっての数字なのか／生物はなぜこの不完全な仕組みを選んだのか／似ているようで違う二つの薬／
麻酔の歴史における偶然／体内の時間と時計の時間／「正常」という言葉の奇妙さ／例外的な患者、例外的な動物／
ひとつの式から見える別の世界

各コラムは300〜800字程度とし、本文から外して読んでも面白い内容にしてください。

## 第5章：臨床への帰還
最後にもう一度、最初の手術室の場面へ戻ってください。ただし、
箇条書きでまとめない／教訓を直接提示しない／「だからこうするべき」と説教しない／
読者が最初とは違う意味で場面を見られるようにする。

患者の血圧、呼吸、意識、体温、薬の効果などが、単独の数字ではなく、相互につながった現象として見えるようにしてください。

## 終わり方
「持ち帰る四行」「まとめ」「明日から使えるポイント」は作らないでください。
最後は次のいずれかで終えてください。
最初の場面に戻る／一つの比喩を静かに反転させる／読者が最初の疑問を別の形で考え直す／
人体の不思議さを残す／次の観察を促す一文で終える
最後の1〜2文には余韻を持たせてください。

# 医学的精度
- 古典的な知見と現在の知見を区別する。
- 仮説や概念モデルは、確立した事実のように書かない。
- 数字には条件と幅を付ける。
- 例外や限界を必要に応じて示す。
- 臨床的に重要な主張には参考文献を付ける。
- 引用は本文の流れを壊さないように配置する。
- 参考文献は最後に提示する。
- 個別患者への診療指示は書かない。

# 文字数
本文は4,000〜7,000字程度としてください。

# 出力
1. タイトル案5つ
2. 本文
3. 参考文献
4. 文章の核になった生理学的概念を1文で示す
```

## 複数本を一度に作る場合の追加条件

```
以下のテーマリストから、各テーマにつき1本ずつ、独立した科学読み物を作成してください。

# 共通条件
- 麻酔、薬理、生理を横断する
- 教科書的な説明ではなく、文学的な科学読み物にする
- 実務チェックリストを作らない
- 最後に4行のまとめを付けない
- 「翌日の臨床で使えるポイント」を付けない
- 各作品は独立して読めるようにする
- 作品ごとに異なる比喩と導入場面を使う
- 同じ説明や同じ結論を繰り返さない
- 本文中に2〜4個の短いコラムを挿入する
- 参考文献を付ける
- 1作品4,000〜6,000字程度

# 出力方法
まずタイトル案と各作品の100〜150字の概要を提示してください。
その後、1本ずつ本文を作成し、完成したら次の作品に進んでください。
```
