## 連作シリーズ（単発ではなくシリーズとして読ませる並べ方）
- **眠り**：眠りはスイッチではない／麻酔薬は意識を消すのか／眠っている脳と麻酔された脳／覚醒は薬が切れることではない／記憶はどこで失われるのか／目を開けることと意識が戻ること／痛みのない覚醒は可能か／夜のICUで時間が壊れる／鎮静と拘束のあいだ／夢を見ない麻酔、夢を見る麻酔
- **血液**：血液は赤い川である／血圧は川の速さではない／血管は水槽ではない／出血は血液量の問題ではない／ヘモグロビンは酸素のタクシーか／酸素は多ければよいのか／血液が濃いことの代償／輸液はどこへ消えるのか／血管の壁にある見えない門／輸血は数字を戻すことなのか
- **時間**：新生児の時間／麻酔薬の時間／薬の半減期という時間／手術室の数十秒／低体温で遅くなるもの／肝臓が薬を忘れるまで／術後せん妄の夜／ICUで昼夜がなくなる／痛みの時間／心臓が待てる時間
- **呼吸**：呼吸数は換気量ではない／二酸化炭素は身体の言葉である／肺胞は小さな部屋ではない／FRCという見えない貯金／無呼吸の時間／片肺換気の肺／人工呼吸器は呼吸をしていない／PEEPという見えない支柱／酸素化と換気は別の話／呼吸を止めても生きている身体
