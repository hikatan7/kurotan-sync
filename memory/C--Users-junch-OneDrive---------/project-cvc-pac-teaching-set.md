読者は冒頭で骨格文献の全体像と番号を同時に見られる。

旧付録Dのうち SUPPORT／ESCAPE／FACTT／Schwann／Wiener／Connors／Pronovost は、
本文が研究名と掲載誌・巻号頁をその場で明記しているため一覧に重ねていない（その旨を前書きに明記）。

**Why:** この巻は本文が「Merrer らの RCT（JAMA 2001;286:700-707）」のように
出典を地の文で書く体裁だったので、番号は文末に足すだけで済んだ。
逆に地の文の書誌を消してしまうと読みにくくなるため残した。

**How to apply（事故と対策）:** 付録Dを削るとき、`付録D` で最初にヒットした段落は
**目次（TOC）の行**だった。そこから末尾まで消して本文1142段落を失った。
バックアップ bk06.docx から復旧して事なきを得たが、
**見出しを探すときは「最初の一致」ではなく最後の一致を採るか、本文中の位置（段落番号）で確認する**こと。
TOC はフィールドなので、[[env-word-com-doc-generation]] の topdf.ps1 が付録Dの行を自動で落としてくれる。
