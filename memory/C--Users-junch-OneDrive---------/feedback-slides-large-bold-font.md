スライドの本文は、枠に収まる範囲で可能な限り大きく、太字にする（2026-09-27 Junko指示「フォントが小さくて読みにくい」）。pptxlib 既定の 8.8〜9.5pt は小さすぎた。
研修医・専攻医向けの資料では、略語をそのまま並べない。冒頭に略語一覧、本文の初出に「略語（日本語）」を入れる（同日指示）。

**Why:** 投影して読むスライドで小さな文字は読めない。研修医版で略語だらけだと読み手が止まる。
**How to apply:** pptxlib を使うときは `ICLS_開心術後ALS配布資料\_生成スクリプト\build_slides.py` の fit_and_draw（18ptから0.5刻みで下げる）と、ランへの lang=ja-JP 付与を流用する。関連 [[project-pptxlib-slide-engine]] [[workflow-abbreviation-expansion]]

**短い項目は 1 行に収める（2026-09-27 追加指示）。** 表の左列（項目名）・カード見出し・数値セルが 2 段に折れたら、必ず修復して 1 行にする。
「78%→35%→14% は術後患者の成／績」のように折れた例をユーザーが指摘した。直す順番は
① 列を広げる（右の列から比例して差し引く。左列は全体の 45% まで）→ ② それでも入らなければ文字を 0.5pt ずつ下げる（本文の 0.8 倍まで）→ ③ 言い回しを短くする。
本文セルでも 1〜2 文字だけ次行に落ちる（「…超える／る」）ものは言い回しを縮めて直す。
実装は `ICLS_開心術後ALS配布資料\_生成スクリプト\pptxlib.py` の `widen_label_col()`・`one_line()`（推定幅に 0.90 の余裕）。**最後は必ず PDF 化して目視で確かめる**（推定と実描画はずれる）。

**Word の表にも同じ規則を当てる（2026-10-09 指示）。** docx の表は `自作ファイル集\表の列幅自動調整\fit_tables.py 入力.docx --pdf` で後処理する。メイリオ等の字幅を実測→「表の高さ＋短い項目・左列（45%まで）・見出しが折れた罰点」が最小になる列幅を局所探索→折れが減るときだけ文字を5%ずつ縮小（0.85倍まで）→Word COMで行数を数えて残りを補正。表の全体幅は変えない。教材を作ったら納品前に必ず通す。
