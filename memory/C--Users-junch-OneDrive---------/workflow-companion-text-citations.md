## 編集用原本の在り処（重要）

デスクトップ側の教育ファイル集には **PDF しか置いていない短編がある**。
docx は `OneDrive\_旧デスクトップ\_編集用原本（Word・PPT）\教育ファイル集\…` に同じ階層で入っている。
「docx が無いから直せない」と判断する前に、必ずこちらを見ること。

**Why:** 別冊は「根拠は本編を参照」で済ませていたが、別冊だけを配られる人が実際にいる。
親の台帳を使い回し、その冊子に出てくる分だけを出現順で番号化した。
本編にしか出てこない文献は入れず、その旨を前書きに書く。

**How to apply:**
- 表が主体の資料では `dumpdocx.py` が中身を拾わない。scratchpad の `tblhash.py` でセルの文のハッシュを出す
  （`citedocx.apply` は表も歩くので、ハッシュさえ渡せば肩付き番号が入る）。
- 付録が末尾でない本は `applycites_inplace.py`（引数は docx 台帳 シート json 見出し 注記 終端見出し の順）。
  引数の順を間違えると黙って0件になる。件数を必ず確認する。
- 肩付き番号を節見出しや数式の直後（「23.5」の後など）に置かない。直前・直後の本文へ寄せる。
