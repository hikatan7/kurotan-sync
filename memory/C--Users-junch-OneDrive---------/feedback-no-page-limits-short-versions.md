研修医用・看護師用・専攻医用などの短縮版は、「10頁」「5枚」のような頁数の上限で作らない。図表と文字が読める大きさであることと、内容が足りていることを優先する。
増える頁数の目安は 5→8 程度まで。10→20 のような 2 倍以上の増量にはしない。

**Why:** 2026-10-08、「枚数の制限をしたために図表の文字が小さくなったり、内容が不十分になってしまった」と指摘された。

**How to apply:**
- 図は本編と同じ 16 cm 幅で入れる。旧 build_short* の 12 cm 縮小はやめる。
- 表の文字は 4 列以下なら 9.5 pt、5 列以上なら 9 pt。文献一覧は 9 pt。
- 図版自体の文字も大きくする。figkit では cols を size=14.5、rows を 15、two を 15.5 にした。短い項目が 2 行に折れたら言い換える（[[feedback-slides-large-bold-font]]）。
- 頁数のために外していた図・表があれば戻す。
- ファイル名から「10頁」などの頁数を外す。
- 作業順はユーザー指定で、〔53〕ステロイドから始めた（2026-10-08）。同日、①⑤⑥⑦⑧⑨⑫⑱㉒〔52〕と㉚〜51の専攻医版・研修医版・要点ガイドを全て直した（docx は直接編集、㉚〜51 は build_short*.py に shortfix.py＋short_additions.json で本編の図を足す方式。旧 build は .頁数制限前.bak）。総目次とポータルも更新済み。
- 図版の描き直し（2026-10-08）：scratchpad の shortfigs.py が figlib に割り込み、図の中の本編番号（図12-1 等）を外し、文字を K 倍（1.25→1.0 で figqa 0件かつ行末1〜3字の折り返しなしの最大値）にして 図版/_専攻医版/ に出す。build_short* は shortfix.figpath() でそちらを優先。docx 直編集の巻（①⑱㉒〔52〕）は swapimg.py で埋め込み画像を差し替え（バイト一致→縮小画像の類似で対応）。⑱の図は fit_size で縮む作りなので効きが弱い。
- HTML 版（ポララミン・ノルアドレナリン・ゾウの時間）は固定頁の .page を流し組みに変え文字を拡大、柱とノンブルは PyMuPDF で後入れ（Chrome PDF は wrap_contents() してから書く）。ポララミンの確認問題は削除。トルーソーは _編集用原本 の docx を拡大して PDF を教育ファイル集へ。
- ⑦⑫アルブミン製剤ミニテキストの図11点は画像しかなかったので新規作図（scratchpad→各 _生成スクリプト\図版_短縮版_作図.py、図の中に見出しを置かない・16cm で約10〜11pt）し、swapmap.py で差し替え（2026-10-08）。
- 『周術期のはじめかた』は流し組み56頁に作り直し済み（[[project-perioperative-reader]]）。
- スライド23本（研修医版＋用語解説19本、BIS②、自己血レクチャー、早剝要点、心停止要点）も処理済み（2026-10-08）。道具は 自作ファイル集\スライド文字拡大ツール（9月の relayout 等も保存）＋ scratchpad の glossary_pptx.py（用語解説 3列×6行7.5pt → 2列×4行・用語20/説明14〜16pt、見出しが「用語・略語解説」で始まるスライドだけを対象にする＝表紙の目次に反応した事故あり）、split_panels.py（左右の区画を別スライドにして等倍拡大、最大2分割、片側が空に近いなら分けない）、remove_cases.py（CASE 症例スライド削除）、fix_count_words.py（「10枚ダイジェスト」等の文言）。relayout は表の行があふれて不採用。
- BIS②専攻医向けは 6→11枚に組み直し（元の帯・見出し・表の行・カードを雛形に複製して新レイアウト、本文16〜20pt）。スクリプトは 12_BISモニター\_生成スクリプト\スライド②専攻医向け_組み直し.py。これで短縮版・スライドの頁数制限解除は全件完了（専門医版①20枚の名前は短縮版でないので据え置き）。
