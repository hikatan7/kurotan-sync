グロービスの配布資料（例：`経営学\グロービズMBAコース\ビジネス・アナリティクス\Day1` のケース PDF、テキスト PDF、添付 xlsx）には、全ページに
「複製、編集、転載、配布、および生成AIへの入力や保存を固く禁ずる」（違反は受講規約上の懲戒対象）と明記されている。2026年10月期ビジネス・アナリティクスで確認（2026-09-24）。

**Why:** Junko さんの受講資格に直結する。一度ケースを読み込んでしまい、抽出テキストを削除して止めた経緯がある。

**How to apply:**
- グロービスの科目フォルダ内のファイルは開かない。課題の相談を受けたら、一般論・公刊書・架空データで支援する
- 答案の下書き、ケース数値の分析やグラフ作成はしない。Junko さんが自分の言葉で説明した内容の壁打ちならよい
- 教材を作るときは本文を自分で書き、例題は架空データにする（[[project-ba-quant-intro-textbook]]）
- 既刊の [[project-mba-critical-thinking-textbook]] は講義資料の再構成で作られている。今後同じやり方で作らない
