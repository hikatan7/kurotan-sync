心臓麻酔の資料が3か所に分かれ、一部が重複していたため整理した（2026-09-22）。
**ユーザーの選択は「統合せず、重複章だけ相互参照で整理して残す」＋「抜けている基礎は書き足す」。**

**資料の配置（整理後）**
- `教育ファイル集\高度心臓血管麻酔`：全8章（各論。ペースメーカー／脳保護／脊髄保護／M-TEER／
  TAVI／透析患者／人工心肺と輸血／神経モニタリング）＋文献台帳210件
- ミニ教科書：⑩ICU心房細動、㉛止血戦略、㉜大血管の脳・脊髄保護、**㉝心臓麻酔の基礎（新規）**
- JSCVA2026（他者演題のレビュー）

**入れた相互参照（双方向）**
- 高度 第Ⅱ章・第Ⅲ章 → ㉜、第Ⅶ章 → ㉛、第Ⅷ章 → ㉛㉜。目次の直後に紫の枠で挿入。
- ㉛㉜の前書きにも逆参照を入れて再ビルド。

**docx の目次直後に段落を足すときの落とし穴（重要）**
python-docx で「toc スタイルの最後の次」に挿入すると、**Word が TOC を更新した瞬間に
フィールドの結果ごと消える**（実際に一度消えて、PDF に反映されなかった）。
`w:fldCharType="end"` を最後の目次エントリより後ろで探し、**その次の段落の前に**入れること。
道具は `scratchpad\xref\add_xref.py`（退避先は `高度心臓血管麻酔\_相互参照前`）。

**㉝『心臓麻酔の基礎』**（52頁・全29章・図版16点・表20点・番号引用41件）
`教育ファイル集\麻酔科ミニ教科書シリーズ\33_心臓麻酔の基礎\`。
軸は「病態で目標を決め、TEE で確かめ、人工心肺の生理を理解し、順番を決めて離脱する」。
第II部が弁膜症の血行動態（狭窄性は遅い心拍数・後負荷維持、逆流性は速め・後負荷低下、
SAM は強心薬で悪化）、第III部が TEE の基本、第IV部が CPB の生理、第V部が離脱後。
各論は㉛㉜と『高度心臓血管麻酔』へ送る「入口の巻」として位置づけた。


**第III部（TEE）を10章に拡張（同日）**：ユーザーの「TEEを詳しく」を受けて、
4章 → 10章（何を見るか／装置と画像のなりたち／標準断面①中部食道の角度連続／
標準断面②経胃・深部経胃／ドプラの基本／心機能と容量／大動脈弁／僧帽弁・三尖弁と
Carpentier 分類／離脱時の順番／記録・安全性・落とし穴）。
図版6点（プローブ操作、中部食道の角度、経胃、ドプラ、大動脈弁、僧帽弁）と
文献11件（ASE の心腔計測・逆流・狭窄・拡張機能・人工弁・3D・心表面エコー、
Carpentier 1983、TEE 安全性2件）を追加。IV部・V部の章番号は 20〜29 へ繰り下げた。

**ポータルのテーマ整理**：循環・不整脈に「心臓麻酔・心臓血管麻酔・弁膜症・人工心肺」を追加。
これで心臓麻酔関連16件が一つのテーマに集まる（第Ⅶ章だけは輸血・血液製剤に残る＝㉛と同居）。

㉝を土台に4巻を新規作成した ──
[[project-cardiac-emergency-mcs-textbook-34]]（㉞緊急と補助循環49頁）／
[[project-mics-robotic-cardiac-textbook-35]]（㉟低侵襲・ロボット46頁）／
[[project-achd-anesthesia-textbook-36]]（㊱成人先天性心疾患48頁）／
[[project-transplant-anesthesia-textbook-37]]（㊲移植44頁）。
4巻とも専攻医版ちょうど10頁つき。㊲第21章に7冊の相互関係の表を置いた。
ポータルの「循環・不整脈」に心臓麻酔関連20件が集約されている。
