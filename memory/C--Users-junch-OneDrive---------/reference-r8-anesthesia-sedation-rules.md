令和8年度診療報酬改定（2026年6月施行）で全身麻酔の評価が「①麻酔の深度 ②気道確保デバイスの有無 ③麻酔管理体制」の3軸に再編された。

- 新L001「吸入麻酔又は静脈麻酔による鎮静」＝10分未満120点／10分以上20分未満310点。旧L000迷もう麻酔・旧L001筋注全麻・旧L001-2静脈麻酔の1・旧L007開放点滴式全麻を統合（旧L007は廃止、番号は同じで中身が別物）。**20分以上の区分が存在しない。**
- 新L007「吸入麻酔又は静脈麻酔による深鎮静（声門上器具又は気管挿管による気道確保を伴わないもの）」＝20分以上・意識消失を伴い気道確保の適切な管理を要するもの。麻酔管理体制で4区分（専従2,600／指導下専従1,700／専従900／その他600点）。2時間超で麻酔管理時間加算（30分毎 区分1=780点、区分2=510点）、3〜6歳未満幼児加算10%。実施主体は医師限定（特定行為研修修了看護師では算定不可、一部行為の実施は可）。通知(5)ア「担当医師又は常勤の麻酔科標榜医が深鎮静前後の診察を行い、担当医師が深鎮静を行うこと」。
- 新L008＝声門上器具又は気管挿管による気道確保を伴う閉鎖循環式全身麻酔（15歳未満に例外あり）。

プレセデックス（デクスメデトミジン）の効能・効果は3つのみ：①集中治療における人工呼吸中及び離脱後の鎮静 ②成人の局所麻酔下における非挿管での手術時及び処置時の鎮静 ③小児の非挿管での非侵襲的な処置時及び検査時の鎮静。**全身麻酔中の補助という効能はない**＝L008下の使用は適応外。

支払基金・国保統一事例【麻酔】106（令和6年3月29日）：L002硬膜外麻酔／L004脊椎麻酔／L005上・下肢伝達麻酔／局所麻酔／DPCレセプトにおける局所麻酔下の非挿管での手術時の鎮静目的での投与 — の薬剤算定は原則として認められる。
https://www.ssk.or.jp/shinryohoshu/sinsa_jirei/kikin_shinsa_atukai/shinsa_atukai_i/masui_1.files/masui_3.pdf

実務上の空白：局所麻酔・非挿管で20〜60分の鎮静（慢性硬膜下血腫穿頭術など）が「深鎮静ではない」と査定されるとL007不可・L001も時間区分外で麻酔料の受け皿がない。薬剤費は別勘定で認められる。関連 [[project-iji-monthly-tool]] [[project-receipt-tool-workbook]]
