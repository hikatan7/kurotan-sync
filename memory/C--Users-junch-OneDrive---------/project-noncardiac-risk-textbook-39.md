`教育ファイル集\麻酔科ミニ教科書シリーズ\39_非心臓手術の心血管リスク評価\`（2026-09-22）。
`_教材化待ち\guidelines\JCS2014...pdf` を出発点に調査して作成。

**調査で分かった最重要のこと**
手元の **JCS2014 は旧版**。現行は
**「2022年改訂版 非心臓手術における合併心疾患の評価と管理に関するガイドライン」
（班長：平岡栄治、Circ J 2023;87(9):1253-1337、PMID 37558469）**。
GRADE/Minds 方式・文献439件・図19点の全面改訂で、循環器・外科・麻酔科の合同。
米国も **2024 AHA/ACC ほか**（Circulation 2024;150:e351-e442、PMID 39316661／
JACC 版 39320289）で2014年版から10年ぶりの全面改訂。変更点の要約は 40169218。
欧州は **2022 ESC**（36017553）。**三者とも前版は2014年**だった。

**構成**：本編52頁・全26章・図版9点・コラム7本・番号引用45件（全て PubMed）
＋専攻医版**ちょうど10頁**。
- 第I部 何を決めるための評価か（1-3）／第II部 リスクを測る（4-8）
- 第III部 検査（9-12）／第IV部 薬（13-17）／第V部 併存疾患（18-22）
- 第VI部 術中と術後（23-26）

**貫く軸**：「その検査・その薬で、何が変わるのか」。術前評価が答えているのは
〈進めてよいか／直せるものはあるか／何を見張り準備するか〉の三つで、
「やめるため」の評価ではない。

**位置づけが反転した／下がったもの**（本書の骨格）
- β遮断薬の術前新規開始 → POISE(18479744) で死亡・脳卒中が増えた。**続けると始めるを分ける**
- 予防的冠動脈血行再建 → CARP(15625331)。機序（需要と供給の不均衡）と噛み合わない
- ヘパリン橋渡し → BRIDGE(26095867) で血栓減らず大出血増。DOACは PAUSE(31380891)
- 一律の術前検査・負荷試験 → 低価値検査として研究対象に(27542420, 39813049)
**位置づけが上がったもの**：BNP/NT-proBNP(24076282)、構造化した運動耐容能
（METS study 30070222 ── 主観的推定は予測できなかった）、術中血圧、MINS。

**MINS の特殊性**：診断が治療より先に来た。測れば見つかり予後が悪いと分かるが、
見つけたあと何をするかは未確立（MANAGE 29900874 は解釈に議論）。
→ 「測る前に、対象・対応・説明・フォローを決める」

**書かなかったこと**（付録D-5）：リスク指標の点数ごとの発生率、ステント後の待機週数、
抗血栓薬の休薬日数、バイオマーカーの閾値、術中血圧の目標値。
**理由が特殊** ── 指針の版で変わってきた数値なので、数字だけが残ると
古い版の推奨に従い続ける原因になる。
