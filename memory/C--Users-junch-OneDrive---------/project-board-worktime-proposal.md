麻酔科医局の内部検討資料「法人への要求案_川本0912.docx」（10項目・3層構成）を、2026-09-15に理事会提出用へ書き換えた。

**自院ではなく他院の案件**（原案は川本氏）。そのため院内文書配下ではなくデスクトップ直下に置く。
病院名は入れていない（宛先は「理事長・理事各位」のみ）。

配置：`デスクトップ\勤務環境提案_理事会2026`

書き換えの方針（次に改訂するときも維持する）：
- 「要求」ではなく「ご提案」。全編敬語、法人側の非を責めない。「賃金はすでに適正にお支払いいただいている／残るのは枠組みだけ」の型で入る。
- 各項目に必ず「法人が得るもの」を併記（労基署対応の完了／手術枠と高難度症例の安定稼働／時間外上限の管理余裕／定着）。
- 「追加費用なし」を表紙・要旨・各表で繰り返す。増員要求は本文に入れない（原案では交渉材料扱い）。

図版と数字（すべて前提値。実数は付記の【要記入】欄に入れて差し替える）：
- 図2 日祝当直の未算定9時間 → 年68回で年612時間
- 図3 当直月4回の医師の所定不足 月32時間＝年休4日
- 図4 当直明けをシフト扱いにした場合の時間外圧縮 1人年160時間
- 前提：医局員12名、年間当直365回（日祝68回）、月所定160時間、明け勤務年20日、通常時間外300時間/年
