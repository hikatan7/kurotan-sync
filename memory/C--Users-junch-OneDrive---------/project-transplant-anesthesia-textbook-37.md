`教育ファイル集\麻酔科ミニ教科書シリーズ\37_心臓移植・肺移植の麻酔\`（2026-09-22）。
心臓麻酔の補完リスト**4番目＝最後**。これで㉛㉜㉝㉞㉟㊱㊲の7冊が揃った。

**構成**：本編44頁・全21章・図版7点（全て自作）・コラム6本・番号引用37件（全て PubMed）
＋専攻医版**ちょうど10頁**（図7点・引用37件、本編とは別採番）。
- 第I部 移植という枠組み（1-3）／第II部 心臓移植（4-9）
- 第III部 肺移植（10-14）／第IV部 共通の問題（15-17）／第V部 移植のあと（18-21）

**貫く軸**：移植の麻酔には三つの特徴がある ── 患者が二人いる／時間が外から決まる／
**臓器が働き始めるところまでが麻酔の仕事**。心臓と肺は臓器が違っても
「重症の患者に他人の臓器を入れて働かせる」構造が同じなので一冊にまとめた。

**この巻で押さえた要点**
- **除神経された心臓**（第6章）── 安静時心拍数が高く、必要なときの上昇が遅い。
  アトロピンが効かない。前負荷依存。狭心痛が出ない。**移植後何年経っても続く**。
- 心臓移植の離脱の山場は**右室の不一致** ── レシピエントの PVR は高いまま、
  ドナー右室は低い抵抗に慣れている。プロタミンの PVR 急上昇が致命的になりうる。
- 肺移植は「両肺換気に戻す」逃げ道が使えず、体外循環が早く選択肢に入る。
  ECMO vs CPB は出血・輸血・呼吸の転帰で ECMO 有利の報告。
- **ECMO が三つの別の役割で登場する**（移植までの橋／術中の補助／術後の支え）。
  ㉞の「何を足したいのかを先に言葉にする」がここでも効く。
- 移植片機能不全（肺）の定義は2005年の作業部会（16210116）以来、**現在も
  精密化が議論中**（42144087、2026）。分類に当てはめるより経時変化を追う。
- 第18章（移植後患者の別の手術）が、この巻で**いちばん多くの読者に関わる章**。

**書かなかったこと**（付録C-6・C-7）：目標値、換気設定値、阻血時間の許容範囲、
免疫抑制薬の用量と目標血中濃度、薬剤量。生体肺移植・小児・心肺同時移植・
拒絶の診断と治療・臓器提供の法的枠組みは対象外。
国内の実施施設・待機の運用・臓器配分の基準は未確認（最新の公的資料を参照）。
