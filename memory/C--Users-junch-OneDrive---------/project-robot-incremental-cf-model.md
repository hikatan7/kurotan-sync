**モデルの骨格:** 反実仮想＝ロボットなしで同じ患者を従来法で手術。症例を置換（胸腔鏡・開胸）／算入のみ／対象外／純増に分ける。材料の純増＝院内RATS非償還365,945円−従来法非償還10万円（仮定）。**2026-10-16 第2版（他AIをChromeで直接操作して補完）:** 仙骨腟固定36件を加算対象に、保守を公表実額の中央値1,800万に。基準（本体3億・保守1,800万・加算対象216/算入39/対象外29・純増0）で通常年CF −5,695万円、NPV7年 −6.35億、10年 −7.45億、IRR算出不能。**NPVゼロに要る純増は年104件（7年）・92件（10年）**。呼外の導入前後の件数差（142→265）より小さい。国内の純増の根拠＝Sugihara 2017 JJCO（ロボットが10km内に入ると非導入病院−18%、導入病院+101%）。詳細版13頁・引用34件、Excelの照合33項目・出典44件。
