## 押さえた数字
- 国内添付文書：初回 1 mg/kg、1 mg/kg ずつ追加、**総量 7 mg/kg**、溶解は日局注射用水のみ、
  **pH 約9.5** で血管外漏出に厳重注意。国内使用23例の実投与量は平均 2.32 mg/kg（0.71-6.3）。
- EMHG 2024：初回 **2-2.5 mg/kg**、1回最大 300 mg、10分ごと反復、累積 10 mg/kg、
  活性炭フィルタを吸気・呼気に、冷却は **38.5 ℃** で中止、最低24時間監視。
- 疑う九つの所見（JSA）。踏み切るのは初期症状 ── 換気量を増やしても上がる ETCO2、
  原因不明の頻脈、高CO2、高体温、筋強直。**高K・高乳酸は単独では根拠にしない**。
- **PaCO2 ＜ ETCO2 の逆転**はこの病態でしか説明しにくい。
- 初発症状の順位は報告で入れ替わる（Riazi 2014 と Visoiu 2014）。熱は遅れて出る。
- PMH は MH の 1.9-8.3%、死亡率 12.2%。再燃は 14.4-20.0%。
- 検査の時刻表：発症時・30分・4・12・24・48時間。
- カルシウム拮抗薬とダントロレンの併用は禁忌（致死的高K）。

## 当院の事情（本書の第10章・第19章）
**ダントロレン備蓄は手術室内6本＋薬剤管理庫8本＝14本（280 mg）。**
1瓶20 mgを注射用水60 mLで溶解するので、70 kgに2 mg/kgで7本・420 mL。
シミュレーションのシナリオは63歳男性92 kg（腹腔鏡下結腸切除、4年目麻酔科医担当、
4時間かけて膀胱温36.6→38.9℃・ETCO2 40→93）。**92 kgでは14本で3 mg/kgに届かない。**
振り返りの問いは物・人・時間だけ。知識の問題は出てこない。
