麻酔の教材（ミニ教科書・専攻医版・別冊・研修医向け資料）は、引用文献・ガイドラインを付けた解説とコラムだけで作る。次のものは入れない。
- 症例検討：患者の提示、「あなたならどうする？」、「答えと考え方」
- 問題：自己評価・確認問題・設問・クイズ・ドリル・症例演習
- 研修医向けの FAQ（よく出る質問・Q&A）、学習チェックリスト

**Why:** 2026-10-07 に段階的に指示された。最初は「症例は不要、問題も不要。解説だけで良い」、続いて「研修医向けの質問解説も要らない。引用文献、ガイドライン等が付いた解説、コラムのみで良い」。MBA必修4冊でも「演習・点検表は不要」と言われていた（[[project-mba-required-four-books]]）。

**How to apply:**
- 臨床の具体例は、「場面別の考え方」として一般化した解説で書く。患者の年齢・性別・提示は書かない。
- コラムの題に「Q&A」を付けない。
- 既刊の書き換えの記録は [[project-case-quiz-removal-2026-10]] にある。
