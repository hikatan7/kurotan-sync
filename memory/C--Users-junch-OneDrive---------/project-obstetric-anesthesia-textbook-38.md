`教育ファイル集\麻酔科ミニ教科書シリーズ\38_産科麻酔\`（2026-09-22）。
心臓麻酔7冊が完了したあと、`_教材化待ち` のなかで最大の未カバー領域として選んだ。

**構成**：本編45頁・全22章・図版8点（全て自作）・コラム7本・番号引用35件
（PubMed 34件＋院内資料1件）＋専攻医版**ちょうど10頁**。
- 第I部 妊婦という患者（1-3）／第II部 無痛分娩（4-9）
- 第III部 帝王切開（10-16）／第IV部 難しい妊婦（17-18）／第V部 体制をつくる（19-22）

**貫く軸**：「手技ではなく、体制で決まる」。硬膜外麻酔と脊髄くも膜下麻酔そのものは
難しくない。難しいのは、いつ呼ばれ・どこで導入し・誰が見張り・帝王切開へどう移るか。
だから第V部を体制の話に充てた。

**この巻で押さえた要点**
- 開始時期で帝王切開率・器械分娩率は変わらない（Cochrane 25300169、RCT 15716559）。
  観察研究で「早く始めた人はもともと難産だった」という交絡が働いていた。
- 分娩が遅れるかの議論は、**濃い局所麻酔薬の時代の知見**。薄い濃度＋オピオイド併用が
  標準になって前提が変わった（第二期の RCT 29016499）。産科と議論が噛み合わない
  ときの原因はここにある。
- 血圧低下は**先回りする** ── 起きる前から昇圧薬（国際合意 29090733）。
- 硬膜外関連発熱は感染とは別機序だが決め手の対策なし（36925412, 35934529）。
  「硬膜外だから」と決めつけない ── 児への抗菌薬の判断に関わる。
- 「効いている硬膜外」は緊急帝王切開で**最も価値のある資産**。まだら効きは増やしても
  足りない。
- 術後鎮痛の要件は「痛みが取れ、かつ眠くない」── 翌日から児の世話をするから。

本書に採録せず**、「体制として何を決める必要があるか」という枠組みだけを使い、
その旨を付録C-5に明記した。refs38_extra の `JP-LUKE-LABOR` で帰属。

**書かなかったこと**（付録C-6・C-7）：局所麻酔薬の種類・濃度・量、オピオイド・
昇圧薬・子宮収縮薬の用量、血小板数の基準値、抗凝固の中断期間。
国内の無痛分娩提供体制・安全対策の現状、国内の抗凝固と脊髄幹麻酔の指針との整合、
笑気の国内での位置づけ、新生児蘇生、妊娠中の非産科手術は未確認／対象外。
