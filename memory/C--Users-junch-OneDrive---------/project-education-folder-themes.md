直下のテーマフォルダ：麻酔管理の基礎／術前評価と麻酔計画／気道・導入・覚醒／モニタリング・血管確保／区域麻酔・鎮痛／産科・小児・高齢者／凝固・輸血・大量出血／呼吸器外科の麻酔／心肺蘇生・急変対応／アレルギー・アナフィラキシー対応／周術期医学・安全・チーム／学会発表・教育／診療報酬・算定。シリーズ型は「麻酔科ミニ教科書シリーズ」と「高度心臓血管麻酔」だけ残した。`_` で始まる作業用フォルダはそのまま。

- テーマ別スライド集（01〜11）・動画リスト・研修医・専攻医向けテキストは解体し、各テーマへ。スライドの閲覧用 PDF は pptx と同じテーマフォルダに並べた（ポータルは同名で合流させる）
- 複数ファイルの企画フォルダ（ICLS_開心術後ALS配布資料、JSCVA2026、CVCカテ講習会2026、周術期アナフィラキシー、宗教的輸血拒否）は、名前を変えずにテーマフォルダの下へ入れた（1_目録を作る.py の TOPIC_DIRS がフォルダ名で引くため）
- ポータルを作り直し、整理前の目録 659 パスは全件追えた。リンク切れ0。控えは `_ポータル生成\_更新前_20261007_フォルダ整理`
- **空の旧フォルダ10個（テーマ別スライド集、_PDF（閲覧用）、動画リスト、研修医・専攻医向けテキスト（中に空の _旧版）、周術期・術前管理、麻酔・気道管理、学会発表・プレゼン、読み物（サイズの生物学）、肺癌・呼吸器外科、_ガイドライン新旧対照）は削除できずに残っている**。教育ファイル集に Everyone の削除拒否 ACL（[[project-file-protect-tool]]）がかかっているため。ACL はくろたんが変えない。Junko が保護を一時解除して消す

**How to apply:** 新しい資料はテーマフォルダに入れる。「新旧対照」「テキスト集」のような形式や作業の名前のフォルダを直下に作らない。分類語はフォルダ名にも当たるので、テーマ名＝部の名前のままにしておく。関連 [[project-anesthesia-material-portal]] [[project-education-file-collection]]
