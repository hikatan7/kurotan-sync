## ㊺『周術期生理学』（45_周術期生理学）
本編30頁・全23章・図版8点・コラム6本・番号引用18件＋専攻医版ちょうど10頁。
- 軸＝**「麻酔で止まるものはほとんどない。ずれるだけ」**。
  外れるのは圧受容器反射・血管緊張・呼吸中枢のCO2応答・低酸素性肺血管収縮・
  体温調節の閾値・姿勢。残るのは自己調節・腎のホルモン系・侵襲反応・凝固。
- 繰り返す六つの形：ずれる／圧と流れは別／決めているのは末梢／供給と需要で見る／
  測っている場所と起きている場所は違う／時間に向きがある（再分布は先、喪失は後）。
- **数値を一切書かない巻**。「正常値は健康な若年成人を覚醒・安静仰臥位で測ったもので、
  麻酔中の体はその条件をどれ一つ満たしていない」（第2章コラム）。
- ㊹『麻酔科医の臨床推論』と対 ── あちらが「どう考えるか」、本書が「なぜそうなるか」。
- 28頁で短かったので、抜けていた**心筋の酸素需給・肝血流・高齢/肥満/妊娠**の3章を
  c45_p2b.py として追加（第IV部を「腎・脳・体温・臓器ごとの事情」に改称、第V部を22-23章へ）。

## ㊻『麻酔導入と覚醒・抜管』（46_麻酔導入と覚醒・抜管）
本編28頁・全19章・図版7点・番号引用14件＋専攻医版10頁。
- 軸＝**「導入と抜管は対称ではない」**。条件が揃っているのは導入の側だけ
  （絶食・前酸素化・人がいる・器材が並ぶ）。抜管時はそのどれもが崩れている。
  だから判断は「入れられたか」ではなく「いま出しても、また入れられるか」。
- 前酸素化＝**酸素の貯金**。置き場所（FRC）が小さい人と使う速さ（VO2）が大きい人では
  持ち時間が短い。高流量経鼻酸素が延ばすのは「酸素化を保てる時間」であって
  「呼吸を止めていてよい時間」ではない（CO2は上がり続ける）。
- 覚醒は**意識・呼吸・気道の防御の三層が別々に戻る**。「指示に従う」は気道の証拠にならない。
- 抜管の条件を**四つに分ける**と、待つ理由を言葉にできる。
- 導入後の低血圧は「薬の副作用」ではなく**隠れていた状態の顕在化**。
- **抜管の指針（DAS 2012 等）は題名照合で実物を確定できず、引用していない** ──
  内容は㉙へ渡し、付録Eにその旨を明記した。

## ㊼『心臓植込み型電子デバイス』（47_心臓植込み型電子デバイス）
本編29頁・全19章・図版7点・番号引用19件＋専攻医版ちょうど10頁。
- 軸＝**感知は「刺激しないための仕組み」**。ここから周術期の問題のほぼ全部が出る
  （雑音を「拍った」と誤認→刺激が止まる／「頻脈」と誤認→不要なショック）。
- **「ペースメーカーが止まった」は多くの場合、機械は止まっていない**（コラム）。
- 磁石の効果は PM と ICD で違い、機種にも依存する ── **当てたら心電図で確かめる**。
- **必要のない変更にも不利益がある**（非同期＝自拍と競合／頻脈治療停止＝守られていない）。
  そして**最も抜けるのは「戻すこと」**。
- 術前に確かめる五つ／植込み手術の麻酔（胸壁の区域麻酔で鎮静を浅く保つ流れ）も収録。
- 『高度心臓血管麻酔』第Ⅰ章とは棲み分け ── あちらは心臓血管麻酔でのデバイス患者。
