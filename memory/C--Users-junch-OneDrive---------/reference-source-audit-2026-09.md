## Genspark の回答に含まれていた誤り2点

再照合で見つけた。**回答をそのまま台帳に入れていたら本に入っていた。**

- Choi 2003 の PDPH の 95%CI を「51.4–89.2%」と書いてきた。抄録の実際は **51.4–52.8%**。
  下限だけ合っていて上限が違う。数字の形が正しいので目視では気づきにくい。
- Dobson 2022 を「BMC Anesthesiol 2022;**22:39**」とし、著者に **Kilgore JS** を挙げた。
  実際は **22(1):43**、著者は Dobson, Weller, Edwards, Turner, Jaffe, Reynolds, Henshaw。

**Why:** 判定（実在する／しない）は6件とも正しかった。間違えたのは**細部の数値と巻号**である。
つまり「実在するか」は任せてよいが、**抄録に書かれた数値と巻号頁は必ず原文で読み直す**。
→ [[feedback-verify-ai-supplied-urls]] [[feedback-vancouver-citation-style]]

**How to apply:** 照合の手順は3段。
① PMID を PubMed で開いて題名・著者・年・誌名を見る →
② 数値を引用しているなら **abstract 本文を読んで数字を目で合わせる** →
③ 巻・号・頁は PubMed の書誌欄から写す（AI の回答から写さない）。
