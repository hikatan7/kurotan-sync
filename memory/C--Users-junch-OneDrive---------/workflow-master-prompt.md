ユーザーが「マスタープロンプトで:【テーマ】」(または「マスタープロンプトで: ○○」)と入力したら、以下の指示をそのテーマに適用して回答する(2026-07-05登録。Gemini側にも同一プロンプトを登録済み、[[workflow-chrome-search-two-modes]]のAI横断検索と対で運用)。

## 学習資料作成用マスタープロンプト(全文)
指定テーマについて、資料作成の素材として、追加質問なしの1回の回答で最大限網羅した詳細情報を出力する。情報過多で構わない、分量制限なし。

出力要件:
1. 全体像(定義・位置づけ・体系を基礎から専門レベルまで階層的に)
2. 主要トピックの完全網羅(重要概念・フレームワーク・理論を漏れなく、各々「定義→仕組み→具体例→実務・試験で問われるポイント」の順で詳述)
3. 重要用語集(英語併記)
4. 実在の具体的事例を各トピックに最低1つ
5. 数値・データ・数式・基準値の明示
6. 対立概念・類似手法の比較表
7. 直近1〜2年の最新動向
8. 定番教科書・必読書・公式ガイドライン(書誌情報は正確に、不確かなら※要確認と付記。可能ならWebSearchで書誌を検証する)
9. よくある誤解と注意点
10. 初学者→中級→上級の学習ロードマップ

厳守事項:
- 推測・不確実情報には※要確認を付ける
- 前置きと締めの挨拶は不要で本文のみ
- 見出しを階層化し文書化しやすい構造にする

**Why:** ユーザー(医療従事者・MBA生)は複数AIで学習資料の素材を集めており、どのAI・どのモデルでも同じ1回の質問で網羅的な素材が得られる状態にしたい。

**How to apply:** トリガー文字列を見たら即この要件で回答する(スキルやツールの有無は問わない)。Claude Codeではさらに強みを活かし、要件8の書誌検証にWebSearchを使い、回答後に「Wordノート化([[env-word-com-doc-generation]]の手順)まで必要か」を確認するとよい。貼り付け用の原本はデスクトップ「AI横断検索用マスタープロンプト.txt」。
