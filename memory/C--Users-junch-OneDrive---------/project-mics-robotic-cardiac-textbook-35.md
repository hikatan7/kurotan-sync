**貫く軸**：「胸骨を開けない分、術者が失ったものを誰が補うか」。
肺を虚脱させる・末梢から送脱血する・TEE で器具を誘導する・体表から除細動する ──
この四つが麻酔科と臨床工学技士へ移る、で全章を通した。

**この巻で押さえた要点**
- 分離肺換気は麻酔科にとって純粋な「負債」。人工心肺中は酸素化が保たれるので、
  本当に問題なのは**導入〜送脱血**と**離脱〜閉創**の二区間だけ。
- 右肺を落とすのに左用ダブルルーメンを使う理由＝右主気管支が短く上葉枝が近い（コラム）。
- 末梢送血の最重大合併症は**医原性大動脈解離**。送血開始の数十秒に三者が別々の指標を
  見ているので、「送血開始します」と声に出す取り決めに意味がある（コラム）。
- 大動脈内バルーンは動く → 上流へずれると腕頭動脈を塞ぐ。両側上肢で圧を測る施設がある。
- CO2 送気は「残る気体を溶けやすいものに置き換える」工夫。転帰への効果は研究が不一致。
- 学習曲線は外科医個人のものではない ── 施設全体で上がる。

**書かなかったこと**（付録C-5・C-6）：換気設定値、送血圧・脱血陰圧・灌流量、
胸腔内送気圧の上限、薬剤量。TAVI・M-TEER は対象外（院内資料『高度心臓血管麻酔』へ）。
国内の実施状況・施設基準・保険上の扱いは確認していない。
