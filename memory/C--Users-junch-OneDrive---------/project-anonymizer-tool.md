デスクトップ「自作ファイル集\匿名化ツール」の**患者データ匿名化ツール.xlsm**。AI不要・完全オフラインでExcel単体動作。

**構成**: シート=使い方(ボタン2つ)/貼付エリア(貼って変換+クリア)/設定/ログ。モジュール modAnonymize。①ファイル選択→「元名_匿名化.xlsx」出力(元ファイル不変更、xlsmはfmt52) ②貼付エリアはその場置換。ANON_AUTOMODE名定義でMsgBox抑止(COMテスト用)、VersionInfo()あり。

**設定シートは4列**: 分類 / 検出キーワード(カンマ区切り、`=`接頭辞で完全一致、上の行ほど優先) / 置換文字列・連番の接頭辞 / **方式(マスク or 連番、プルダウン付き)**。

**v3 連番仮名化(2026-08-12)**: 患者ID行のみ「連番」方式=同じ値に同じ通し番号(患者00001)。対応表は保存しないので不可逆だが、実患者数・再手術追跡は保てる。桁数はデータ件数から自動(数百件→患者001、数万件→患者00001)。採番は**1回の実行(ボタン1押し)で選んだファイル群の間で一貫**、実行ごとにリセット。実装は外部部品を使わない自前のオープンアドレス法ハッシュ表(Scripting.Dictionary等を避ける)。
**v2 高速化(2026-08-05)**: v1のセル単位ループが5000件でフリーズ→配列一括読込/列単位一括書戻しへ。Findで実データ範囲確定(UsedRange肥大対策)、CELL_BUDGET=60000でチャンク分割、電話/メール走査に事前フィルタ、StatusBar進捗、TurboOn/Off。

**実測**: 5,712行×32列=1.2秒 / 40,072行×16列(20,230患者)=7.2秒。検証で1対1対応・欠番なし・元ID残存0件・他列全保持を確認済み。

**注意点**:
- 手術実績の「実施担当者内容_N」列の医師名は患者データでないため対象外。外部提出時は設定に「担当者」追加が必要。
- 「コピー215449_..._検索結果_手術麻酔.xlsx」(40,073行×16列)は**患者IDが元データで匿名化済み**のため処理不要。かけると匿名化済みIDまで置換され患者の区別を失う。
- 準識別子リスク: 年齢+性別+診療科+術式+日時。1回限りの術式327種、90歳以上1,285行(最高104歳)。外部提出時は年齢丸め・日時粗化を検討。

**VBAの重要教訓(このツールで踏んだ)**:
- モジュールレベルの `Private 変数` 宣言をプロシージャの後ろに置くと宣言セクション扱いにならず「変数が定義されていません」でコンパイルエラー → 必ずモジュール先頭に置く
- `With obj` ブロック内の `ReDim .Member(...)` は不可 → ローカル配列に作って代入
- **`Application.Run` はコンパイル・オン・デマンドなので他プロシージャのコンパイルエラーを検出できない** → 実処理を走らせて確認する
- COM実行中のエラーはVBEモーダルダイアログ(class=#32770)で無限待ちになる → EnumWindows/EnumChildWindowsで本文を読みEXCELをkillするwatchdog方式が有効([[project-occurrence-tool]]のVBScript.RegExp禁止と同系)
