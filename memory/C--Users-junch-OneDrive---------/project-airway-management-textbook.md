2026-09-03 作成。専攻医〜専門医向け、全5部16章・コラム8本・付録A〜E・表9点。

**通した主題**は「守るのは挿管の成功ではなく、酸素化と換気の連続性」。
各章の枠は Take Home / Pitfall / Evidence / コラムの4種で、既刊の体裁に合わせてある。

**構成**：I 原則と生理（階層・上気道の3閉塞点・無呼吸耐用時間）／II 術前評価（病歴と所見・
スコアと超音波・3層への層別化）／III 手技（体位とマスク換気・SGA・喉頭鏡・覚醒下挿管）／
IV 危機（Plan A〜D・CICO と eFONA・特殊病態）／V 挿管後と抜管と体制。

**出典の扱い**（ユーザー指示）：確認できたものだけ本文に載せ、確認できなかったものは
