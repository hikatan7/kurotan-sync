**2026-08-14に再編**。旧「麻酔中の輸液管理（111頁）」と「同 実践編（61頁）」の2冊を解体し、
重複を削って**ベーシック／アドバンス**の2冊へ組み直した。旧2冊はごみ箱へ送った。
置き場は [[project-anesthesia-minitextbook-series]] の ①②。

- **① ベーシック**（PDF 82頁・図版22点）＝ 専攻医向けの土台。
  第I部 土台の生理学（体液区画と改訂Starling／volume kinetics／晶質液を選ぶ）／
  第II部 尿量を読む（腎血行動態／濃縮・希釈／交感神経・RAAS・AVP／乏尿／多尿／指標の限界）／
  第III部 入れた水の行方（リフィリング／自己増幅ループ）／
  第IV部 戦略（Dry vs Wet／ゼロバランスとGDFT／術式別／モニタリング）／第V部 症例18例／付録A〜E
- **② アドバンス**（PDF 55頁・図版13点）＝ 専門医向けの上限値と根拠。
  グリコカリックスの臨床評価／コロイド製剤別の上限／低Na補正・高張療法・マンニトール／
  SID／特殊集団／見えない総入力／反応性と耐容性・VExUS／静注Kの安全上限／大量出血DCR／付録A〜D

**削った重複**（3か所）：①膠質液の各論は旧①3-4と旧②2で二重だったのでアドバンスへ一本化し、
ベーシックには製剤比較表と位置づけだけ残した ②旧①14-2「患者背景別」表は旧②7-1の特殊集団
サマリーと同内容なので削除（章のまとめだけ14-1末尾へ移動）③モニタリングは旧①15と旧②9に
割れていたのでベーシック第15章へ統合し、重複する「測ってはいけないもの」を削除。
旧②付録A（旧版への精度チェック）は役割を終えたので削除した。

**修正済みの医学的な誤り**：VExUS腎静脈波形は「二相性＝中等度／D波のみ＝重度」、
HES禁忌は日本とEUを分けて書く（EUは2022年に販売承認停止）、大量輸血1:1:1は絶対視しない（PROPPR）、
iCaは1.1〜1.3 mmol/Lを実測、マンニトールは「浸透圧320」でなく浸透圧ギャップ>20で判断。

**本文ソースを失った巻の組み直し方**（今回使った手順。scratchpad に一式）：
1. `extract.py` … doclib製docxを呼び出し列（IR）へ逆変換する。枠の種類はセルの塗り色から、
   太字/赤字は run の書式から復元する。
2. `restructure.py` … IRを part/h1/h2 の木に切り、章・節単位で取捨選択・並べ替えする。
   コラムは節ごとに **機序→歴史→根拠→計算→症例→Q&A→Pearl→Column→Pitfall→Take Home** の順に並べ替える。
3. `build_two.py` … 2冊分の構成表を書いて docx と HTML を出力し、Chrome で PDF 化する。

**この逆変換での落とし穴**（再実行時に必ず確認）：
- `dl`（▸ 用語　説明）は太字runが「▸ 用語　」まで含むため、`**▸ 用語　**説明` という形で
  抽出される。素朴に「　」で切ると `**` が本文に残る。専用の正規表現で分解すること。
- **図版のファイル名順は本文の登場順と一致しない**（あとから追加した図があるため）。
  連番で機械的に対応づけると図とキャプションがずれる。`FIG_ORDER` に明示的な対応表を持つこと。
- 章冒頭（最初の h2 より前）にも図がある。節だけを拾うと取りこぼす。

PDF は Word COM で出せる（2026-09-15に確認。`to_pdf.ps1` → Fields.Update → ExportAsFixedFormat）。Chrome の `--print-to-pdf` は代替（[[env-word-com-doc-generation]]）。
