Genspark（AI Chat）向けのプロンプトは、**1回の返信で教材1本ぶんの全ジョブ**をまとめて出させる形にする。教材N本なら「次」はN回、最後に横断ジョブZを1回。

**Why:** 2026-09-25、1返信1ジョブ（16回「次」）の設計に対してJunkoが「何回も次を要求される」と不満を示し、「今後の他の作業にも応用したいので回数を減らす。これからは1回で多くの回答が得られるプロンプトに」と指示。ブラウザ自動操作で「次」を代打する案よりも、こちらを選んだ。

**How to apply:** 雛形は `自作ファイル集\プロンプト集\24_Gensparkに連続ジョブを流す.md`（第2版）。規約・ジョブ部品（医学／経営学）を md に置き、`_ツール_査読キット.py <教材フォルダ> <医学|経営学> <題名>` でコピーボタン付きキットHTMLを生成する。件数は「最大」で目標ではないと明記、切れたら「続き」で再開させる。グロービス授業資料由来の本は渡さない → [[feedback-globis-materials-no-ai-input]]。関連 [[project-genspark-capability-ledger]]

**例外（2026-10-07）：** 1通目に全ジョブの仕様を詰めて「次」で進める方式では、**ジョブ1（大量の Web 検索）のあとに Genspark が仕様を忘れ、ジョブ2の本文を聞き返してきた**。検索が重いジョブを連ねるときは、**ジョブごとに規約と仕様を全部入れた1通完結のプロンプトを作り、新しいチャットに貼らせる**（29番の第2版）。
