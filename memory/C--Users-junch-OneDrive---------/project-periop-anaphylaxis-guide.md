**本書の中心にした論点**
- **付録D に原資料間の食い違い12点を表で整理**した。最大のものは「アドレナリンは筋注か静注か」──
  資料③「心停止でなければ絶対に静注するな」vs 麻酔科学会・Mertes「静注が前提」。
  静脈路・モニター・術者の3条件の違いであって矛盾ではない、と第15章で解いた
- 日本麻酔科学会2021本文の「トリプターゼ 15—25 μg／ml」は **μg/L の誤記**と判断し、付録Dに明記
- Mertes 5.4.1「予防的抗菌薬は麻酔導入前に覚醒下・モニタ下で投与する」は
  実務を変えうるのに知られていない推奨として第40章に立てた

**レイアウトの要点（今回踏んだ落とし穴）**
- 表を先に置くと中身に合わせて縮み、スライド下半分が真っ白になる。
  下部ブロック（cards／strip）を `bottom=True` で底揃えにし、
  上の表を `panel_grid(..., fill=True)` で余白まで伸ばす
- `bottom=True` のブロックは `_cur`（上からの積み上げカーソル）を進めてはいけない。
  進めると次の `panel_grid` がスライド外へ描かれる
- 検証は PowerPoint COM → PDF → PyMuPDF で画像化して目視。これ以外に確実な方法はない

**ビルド**：`_生成スクリプト\build_ana.py` ＋ `ana_p1〜p4.py`（本文）、`fig_ana.py`（図版）。
基盤は⑯⑰から複製した `bookkit.py`／`figlib.py`／`figkit.py`／`boxaudit.py`／`fix_blank.py`。
図版は `fig_ana.py` に足した `trim()` で下端の白余白を自動で切り詰める。
`figkit.two_col`／`three_col` は**この複製版だけ見出しを枠幅に自動縮小するよう改修**してある
（原本のままだと見出しが枠から食み出す）。
空白ページは `fix_blank.to_page_break_before()` で構造的に消してから Word COM で PDF 化。
