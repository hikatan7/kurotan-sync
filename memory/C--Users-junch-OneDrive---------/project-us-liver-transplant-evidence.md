2026-09-17作成。`学習ファイル\移植\米国肝移植_臓器供給エビデンス` に4点（詳細版docx/pdf 20頁、2ページ要約docx/pdf、データ集xlsx、図版8点PNG）。

検証した3仮説の結論:
- 「2〜3ヶ月で移植できる」→ 正しい。2024年に移植を受けた成人の65.5%が待機90日未満（2014年は45.5%）。OPTN/SRTR 2024 ADR: Liver の Table LI 8。
- 「C型肝炎消失の影響」→ 正しい。成人待機リストのHCVは4,309人(28.3%)→553人(6.1%)。待機リスト縮小6,119人のうち3,756人＝61%がHCV。
- 「B型肝炎の影響」→ 米国では小さい。HBVは米国でもともと肝移植の約5-7%で独立項目がない。日本・アジアとは事情が違う。

重要な論点（他資料でも使える）:
- 待機リストは「需要」ではなく「在庫」。新規登録は2022年12,862→2024年14,637と増加中。縮んだのは在庫。
- 供給増の正体はドナー数でなくDCD＋機械灌流。2025年は死亡ドナー −2.5% なのに肝移植 +7.7%。
- オピオイド危機／HCV陽性ドナー説は2020年までの話。HCV抗体陽性ドナーは2020年9.7%がピークで2024年は7.9%。

未検証のまま残した記述（付録C・xlsxの09シート）: Transplant Hepatology認定医777人、フェロー未充足62%、2033年35%不足、2019年のGI+THデュアル認定経路の施行年。
