**2026-09-30 第2弾（元は `_文字拡大前_20260930`）:** 包括手術・09声門上器具②・鎮静ガイド・room10・RATS収益分析・致死的出血3本・材料価格リスト2本・橈骨動脈を作り直し。道具は scratch `%TEMP%\fontscan\step1\`：

- `zoom2.py`（PDFの区画を show_pdf_page で拡大して別頁へ。ベクターのまま検索可。"FULL"=元スライドを全体像として残す。line_cut で行間かつ枠をまたがない位置で上下に割る）。頁の縦横比の制約で、縦に詰まったスライドは 1.2〜1.5倍が上限＝倍率²ほど頁が増える。

**測り方の教訓:** span の size は pdf-lib 製PDFで拡大変換が入ると過小に出る（研修医講義「評価・計画…」は実際19pt相当で問題なし）。字の bbox 高さで測る（`step1/measure.py`）。A3/横長の頁をA4幅換算すると過小評価（CVCポスターはA3実寸10.6ptで問題なし、SG15-1も問題なし）。
