`病院経営学\財務諸表\立川メディカルセンター\` に、財務所見5頁（2026-10-08）→統合所見8頁（docx/pdf）、`長岡3病院_公開データ推移.xlsx`（DPC推移・救急車・公式心外実績・AI照合・出典リンク）、財務分析xlsx、横断検索プロンプト6本HTML。

**結論：** MDC05（循環器）手術ありは2017→2024年度で1,100→1,455（長岡3院中の比率68%で不変）。公式の心臓・胸部大動脈手術は区分1〜5合計で2024年341件。2024年から公表値が「TAVI除く256」に変わったため減ったように見えていた。減ったのは消化器：MDC06手術あり964→541、比率23.7→13.7%（2023年3月外来休止・9月常勤不在）。2025年度も赤字（理事長年頭挨拶）。病床稼働率66.9%（令和6年度、研修案内）。

**Why:** 経営者情報（心臓手術が減った等）の検証依頼。経営者情報を外部AIには「仮説」として渡した。
**How to apply:** DPC原表はAIでは読めない（Gensparkは所在の特定まで）。くろたんがcurl＋openpyxlで直接取る：ページは newpage_00203（R6）/00137（R5）/39119（R4）/0000196043_00001〜00006（H29〜R3）、「手術化学療法放射線療法全身麻酔」に総数・手術・全麻・救急車が1行で入る。R6はデータ期間が6月〜翌5月。病床機能報告個票は「救急車の受入件数（年間）」が病院単位で使える（手術数は病棟ごとに伏せ字）。AI照合：Geminiは全行推測でほぼ誤り（URLも捏造）、Copilot/ChatGPT/Perplexityは引用一致だが年月の取り違えあり。関連 [[project-hospital-financial-statements-folder]] [[feedback-verify-ai-supplied-urls]] [[reference-gemini-search-limits]]
