`教育ファイル集\麻酔科ミニ教科書シリーズ\42_周術期感染対策\`（2026-09-22）。
`_教材化待ち\guidelines` の CDC 血管内カテーテル関連感染予防ガイドライン2011 が出発点。
**これで `_教材化待ち` からの4テーマ（産科・非心臓手術リスク・手術室外鎮静・小児・感染対策）
がすべて教材化された。**

**構成**：本編39頁・全20章・図版7点・コラム6本・番号引用31件
（PubMed 30件＋WHO 指針1件）＋専攻医版**ちょうど10頁**。
- 第I部 どこにいるのか（1-2）／第II部 手術部位感染と持ち場（3-9）
- 第III部 手と作業域（10-12）／第IV部 自分が入れるもの（13-17）
- 第V部 まとめかた（18-20）

**範囲の決め方**：「外科の問題／病棟の問題」と整理されがちなこの領域で、
**麻酔科が自分で動かしている四つ**に絞った ──
①抗菌薬の時刻と追加投与・体温・血糖・酸素 ②自分が入れるカテーテル
③自分が行う脊髄幹麻酔 ④自分の手と作業域。外科の手技と病棟管理は扱わない。

**この巻の要点**
- この領域には**新しい発見がほとんど出てこない**。CDCの血管内カテーテル指針は
  2011年のまま枠組みが変わっていない。課題は知識ではなく**実行の継続**。
- ただし**決着した推奨といまも動いている推奨を混ぜない**（第2章のコラム）。
  動いている＝吸入酸素濃度・血糖の目標値・手術室の服装。
  混ぜると「エビデンスが弱いから」で手指衛生まで相対化される。
- 予防投与の質はほぼ**「いつ入れたか」**で決まる。早すぎる投与も問題。
  失敗は手技ではなく**責任の曖昧さ**（外科が指示・麻酔科が投与・看護が準備）。
- **追加投与が最も忘れられやすい** ── 担当交代時の申し送り項目にする。
- 体温は1996年の RCT（8606715）で「快適さ」から「感染対策」に変わった。
- カテーテルで最も効くのは**「入れない」「早く抜く」**。入れるときに
  「いつ抜くつもりか」を記録しておく。
- 最終章＝**「見えない部屋」**。手術室は感染対策チームから最も見えにくい。
  麻酔記録には抗菌薬の時刻も体温も血糖も残っている ──
  **集計して外へ出すことは麻酔科にしかできない**。

**書かなかったこと**（付録C-5・C-6）：抗菌薬の薬剤名・投与量・時刻の具体・
追加投与の間隔、血糖と体温の目標値、吸入酸素濃度、カテーテルの留置期間と
被覆材の交換間隔、器材の再処理方法。国内の制度・規則の具体も扱っていない。
