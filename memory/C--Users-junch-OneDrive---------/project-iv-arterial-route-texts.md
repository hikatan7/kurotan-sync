原典で確かめた要点：
- 元スライドの「裁判所が示した静脈穿刺のルール（手首から12cm以内：過失ではない／技量ある者が／十分な注意で）」は **静岡地判 平成28年3月24日**（6102万円認容、東京高判H29.3.23で約5696万円、H29.10.26上告不受理）。過失は「痛みの訴えがあったのに1〜2mm進めた＝深く刺さない義務違反」。名古屋地裁2019（肘窩採血）は棄却
- 12cm の出典は Vialle 2001 Anesth Analg（献体33肢）
- 元スライドの誤り2点：CDC 2011 の「6日超ならミッドライン/PICC」は **カテゴリー II**（IBではない）。「72〜96時間ごとに入れ替え」は誤読で、原文は「より頻繁に替える必要はない（IB）」、成人の臨床的理由での交換は未解決。本文では「元の講義では」と書かずに正しい記載だけにした（[[feedback-no-process-notes-in-handouts]]）
- CDC 2011 の原文は PMC3106269 を内蔵ブラウザで読める（cdc.gov の PDF はダウンロードになり読めない）
- Scheer 2002 の橈骨動脈の頻度表は PMC137445（仮性動脈瘤 0.09%＝14/15,623、出血 0.53% は n=375）
