**①〜⑫を㉒と同じ体裁に組み直した**（2026-09-14）。適用した6つの基準 ──
①目次は部・章・コラムだけに簡素化 ②行間とフォントを全巻統一 ③表の幅を実測で調整
④章末は「この章のまとめ」に統一（Take Home / Pitfall の枠は廃止）
⑤コラムを生成して番号を振り直し目次に反映 ⑥施設差は一般的な前置きだけにする。
**元資料に章のまとめが無い巻は、本文を読んで全章分を書き起こした**
（⑥25本・⑨22本・⑩17本・⑧10本ほか、計約100本）。
スクリプトは各巻の `_生成スクリプト` に入れてある ── `docx2blocks.py`（旧docxから
フォントサイズと太字で構造を復元）→ `build_restored.py`（㉒体裁で組む）→ `run_vol.py`、
章まとめは `sumNN.py`、増補は `addNN.py`。元のPDFは各巻 `_旧レイアウト` に退避。

`00_麻酔科ミニ教科書シリーズ_総目次.docx/.pdf`（20頁・**㉙まで反映済み**、2026-09-17）に全巻の作成日・分量・章立て・収録ファイルを載せてある。作り直しは 22 巻の `_生成スクリプト/build_toc.py`：VOLS に1巻分のタプル（番号・表題・副題・作成日・分量・図版数・部構成・収録ファイル）を足し、表紙の「既刊N巻」と日付を直して再実行 → Word COM で PDF 化。㉖はこの方式で追加した（下の deepcopy 方式はもう使わなくてよい）。
巻を足すときは総目次に1巻分のブロックを追記する。`build_series_index.py` は残っていないので、**既存巻のXMLブロックを deepcopy してテキストだけ差し替える**方式で足す（⑫、および⑬〜⑰）。実装は各巻の `_生成スクリプト` にも入れた `add_index.py`：⑫のブロック（巻タイトル／サブタイトル／2行表／空段落／章立て／収録ファイル）の11要素を丸ごと複製し、各段落の `w:t` の1つ目にテキストを入れて残りを空にする。同時に直すもの ── 冒頭の「既刊N巻（本編N冊…）」、日付、末尾の組版基盤の記述、**候補テーマ表から収録済みになったテーマを削る**、そして収録ファイル行に書いてある頁数（別冊◯頁など）。

**表紙の共通仕様**（doclib/htmldoc の `cover()`、kind＝series/sub/main/sub2/note/rule/date/sig）：
「麻酔科ミニ教科書シリーズ　◯」→ 肩書き → 大タイトル → サブタイトル → 分量 → 罫線 →
「作成日　YYYY年M月D日」→ **「静岡市立静岡病院　麻酔科　玉里順子」**。
別冊は「◯ ── 別冊」、付録は「◯ ── 付録」と肩に書く。
大タイトルが14字を超えるときは `mains` を2要素に分けて30ptにする（1要素のままだと末尾数文字だけ折り返す）。

**表紙だけ差し替える方法**（本文ソースが無い巻でも可）：scratchpad の `cover_patch.py` / `series_covers.py`。
- 表紙ページがある docx … `patch_docx()` が先頭の改ページまでの段落を置換する
- 表紙ページが無い docx … `patch_docx_nobreak()` が先頭に表紙＋改ページを差し込む
- PDF … 表紙ありは `patch_pdf()` で1頁目を差し替え、無しは `insert_pdf_cover()` で1頁挿入
- **PDFを作り直せない巻では、docx側の旧タイトル行を消さないこと**（消すとPDFと中身がずれる）

**共通の編集方針**（総目次に明記）：①数字は境界でありスイッチではない ②原典に当たる
③よくある誤解を章の主題として扱う ④コラム10種（Pearl/Pitfall/Mechanism/Column/History/
Evidence/Q&A/Case/計算してみる/Take Home）⑤図表は自作。

**⑬以降のビルド基盤**：doclib/htmldoc が残っていないため、⑬では`bookkit.py`（既刊⑪の docx をテンプレートに開いて本文を空にし、python-docx で組み直す）＋`figlib.py`（図版）で作った。スタイル・ページ設定・フッターが既刊とそのまま揃う。フッターはテンプレート由来の巻名が残るので `set_footer()` で差し替えること。実物は各巻の `_生成スクリプト`。⑭以降には図版検査の `boxaudit.py`、⑯⑰にはレイアウト部品の `figkit.py`（two_col／three_col／rows／note／banner）も入れてある。⑮以降は⑭の `build14.py` を写して使うのが早い。

スライドは [[project-pptxlib-slide-engine]]、新規作成時の4点セットは

**元資料の退避先**：`教育ファイル集\_統合済み元資料`（2026-09-04新設）。⑭〜⑯の元資料5点を「統合済_」を付けて移した。何をどこへ統合したか、なぜ残したものがあるかは同フォルダの`_このフォルダについて.txt` に書いてある。他施設作成の講義資料は退避せず原資料として残す。
