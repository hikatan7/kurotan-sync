**主題**：早剝の帝王切開は「児を早く出す手術」ではなく「児を娩出しながら母体のDICを同時に治療する手術」。
数値の軸は Fbg 200＝危険域／150＝緊急、投与量は `(目標−現在)÷1.7 mg/kg`（妊婦の血漿量3.8Lでは3gでは足りない）。

**産科DIC診断基準は原典画像（2026-09-14にユーザー提供）に従った**。早剝は一律4点ではなく「子宮硬直＋児死亡5点／児生存4点／画像・CTG診断4点」、Fbg ≦150は1点、FDP ≧10は1点、8点以上でDIC（検査項目2点以上を含むこと）。元原稿の「2024年改訂版（早剝4点・Fbg<150で3点・FDP≧60で2点）」とは体系が違うので混同しないこと。

**ビルド時の落とし穴（次巻でも必ず踏む）**
- `bookkit.py` の `TEMPLATE`（11巻の docx）は**もう存在しない**。既刊は PDF 化後に docx を削除しているため。この巻では `new_document()` を A4／Meiryo 10.5pt／余白2.2cm でゼロから組む実装に差し替えた。22巻の `_生成スクリプト\bookkit.py` を今後の雛形にすること。
- 部見出し前の明示的 `page_break` は空白ページを生む。`pb`+`h1` の並びは落として `h1` に `page_break_before` を付ける。→ [[workflow-docx-exact-page-count]]
- pptxlib は版面あふれを黙って重ねる。`check(s, n)` で `_cur` と `_bfloor` を比べる関数を build_slides.py に入れてある。**目視QAの前に必ずこれを通す**。空白帯は下段カードを先に置いて床を決め、上の表に `fill=True` を付けると埋まる。→ [[project-pptxlib-slide-engine]]
- figlib は高さを先に決めるので下に白が残る。`trimfig.py`（下端だけ切る）を save() に噛ませてある。
- **`figqa.py` が版面の自動検査**。figlib.Canvas.save に割り込んで、①文字どうしの重なり（縦が文字高の35%以上）②キャンバス外へのはみ出し ③文字が枠の境界をまたぐ ④白文字が明るい面（明度0.68超）に乗る、を座標で検出する。**目視の前に必ず通す**。実際これで18件見つかった。
- **枠ブロックの末尾の空段落が白紙ページを作る**。改頁直前に来ると1枚まるごと空く。`bookkit.drop_orphan_blanks(doc)` を保存前に呼ぶこと。
- **手で `page_break(doc)` してから見出しを置くと、直前の節がページ境界で終わったとき白紙が出る**。見出し側の `page_break_before` を使う（目次の直後も同じ）。
- build22.py で `note` という変数名を使うと bookkit.note を潰す。表の注記は `tnote` にしてある。
- **表の列幅はセル幅だけ設定しても効かない**。固定レイアウトで Word が見るのは `w:tblGrid/w:gridCol`。`_fixed_layout()` でグリッド・`tblW`・`tblCellMar` をまとめて書き換えている。
- 幅の見積り係数：Meiryo の欧文は **0.56em**（0.5では1文字ぶん溢れる）、セル余白は左右 0.10cm に詰めて `pad=0.30`。
