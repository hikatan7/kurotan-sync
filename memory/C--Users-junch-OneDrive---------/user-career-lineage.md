Junko（玉里順子、静岡市立静岡病院 麻酔科）の経歴と、恩師の系譜。

- **麻酔科医として、東京女子医科大学で移植麻酔に携わった**（腎臓病総合医療センターの系譜を手術室の側から見ていた）。
  外科医ではない。ここを取り違えないこと。
- 腎臓外科の **寺岡慧先生**（1992年7月〜 女子医大第三外科教授、日本移植学会理事長）に、
  **東京大学腎臓内科の大学院**への進学を薦められた（麻酔科医に腎臓内科へ行け、という話）。
- 大学院では、女子医大 腎臓内科・血液浄化療法科の **新田孝作先生**・**土谷健先生**に
  腎移植と AKI を教わった（新田＝腎臓内科三代目主任教授・日本透析医学会理事長、
  土谷＝のちに血液浄化療法科教授）。麻酔科医でありながら腎臓内科・泌尿器科・
  移植外科の先生方に代わる代わる指導を受けた。
- 大学院修了後、**田邉一成先生**（女子医大 泌尿器科教授 2006–2021）の推薦で
  **クリーブランド・クリニックに留学**。
- 留学中、すでに引退していた **Dr. Satoru Nakamoto（中本悟）** が面倒を見てくれ、
  Kolff 時代の逸話を直接聞いた。帰国後は連絡が取れず、**2020年に逝去**。

**この系譜は㉓（急性腎障害AKI）の「あとがき ── なぜ歴史を書いたか」と、
第15章・第23章のコラムに記載済み**（2026-09-14）。
中本先生から直接聞いた話が下敷きであることも明記してある。
あとがきは**本文5段落＋経歴表だけ**に切り詰めた（2026-09-14の指示）。
削除したもの＝博物館の案内／「クリーブランドと女子医大は東大第二外科の同じ問いから
枝分かれ」という一文／2020年の逝去と連絡が取れなかったこと／**謝辞のブロックそのもの**。
逝去の事実は経歴表の中にだけ残っている。

腎臓・透析・移植・人工臓器の話題では、この背景を前提にしてよい。
一般論として説明するより、この系譜に接続したほうが役に立つ。
