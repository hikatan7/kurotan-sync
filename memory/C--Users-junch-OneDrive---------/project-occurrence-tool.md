- **オカレンス統合分析ツール.xlsm**: 旧「オカレンスレポート入力シート_完成版.xlsm」ベースに再構築。シート⓪使い方/①基本入力/②月別推移/③クロス集計/④時間帯・診療科/⑤コメント/⑥報告収集(J列=件数,K列=参考件数)/⑦貼付エリア/⑧グラフ(推移・職種×分類・Pareto)/⑨設定(麻酔科分類番号→大分類マッピング)。①③④は⑥からSUMIFSで当月自動集計(キー=B3&"/"&B4、⑥B列は文字列書式必須)。
- **OccurrenceInput.bas / OccurrenceReport.bas**(cp932): 新マクロ。転記は貼付形式自動判定(麻酔科サマリ=「34.準備不足 45件」集計行から件数取得、総計/オカレンスなし→K列参考値、CE表=日付|主科|機器|内容で日付前行引継ぎ、NS表=日|診療科or部屋|出来事)。Word月報生成はWord COM遅延バインディング。名前定義 OCC_AUTOMODE があるとMsgBox抑止(⑨J2にログ)→COMテスト用。
- **v3追加(2026-07-19)**: ①B13/B14=前月の手術件数・オカレンス合計を②からINDEX/MATCH自動取得(12月→1月の年跨ぎ対応)。Word作成時にUpsertTrend Trueで当月を②へ自動反映。新マクロ「コメント自動作成」=⑤の多発場面/職種別動向/SHELL/注目事象(重大キーワード抽出)/GoodJob/重点課題/割付根拠を⑥当月データから件数+割合付きで生成(空欄のみ書込・B3:B5推移コメントは手入力欄・データ無い欄は空白)。⑤にボタン設置。結合セル貼り付け対応済(クリアはRows.Clear方式)。
- **状態**: 完成・全テスト合格(2026-07-18)。ユーザーがAccessVBOM有効化→COM注入+実データテスト完了(NS44/麻酔科101・延べ113・参考302/201/CE46/②既存値保全/Word月報生成31KB)。テスト後ユーザーに設定を戻すよう案内済み。⑥には2025年サンプルデータ入り、①は2025/6設定。
