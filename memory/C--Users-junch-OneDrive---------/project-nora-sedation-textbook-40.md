`教育ファイル集\麻酔科ミニ教科書シリーズ\40_手術室の外の鎮静\`（2026-09-22）。
`_教材化待ち` の guidelines（ASA 2018 中等度鎮静）＋マニュアル（カテ室セデーション）
を出発点に作成。シリーズ40巻目。

**構成**：本編43頁・全22章・図版7点・コラム6本・番号引用27件
（PubMed 26件＋国内の制度1件）＋専攻医版**ちょうど10頁**。
- 第I部 場所が変わるということ（1-3）／第II部 始める前に（4-9）
- 第III部 薬（10-13）／第IV部 起きたときと終わったあと（14-18）
- 第V部 体制（19-22）

**貫く軸**：「難しさは手技ではなく、状況のほうにある」。
モニタが少ない・人手が読めない・患者に手が届かない・情報が足りない・
深くなったときに戻す手段が近くにない。だから薬より段取りの話にした。

**この巻の要点**
- **鎮静と全身麻酔に境目はない**。ASA が要求するのは「意図より一段深い状態から
  引き上げられること」。「目指す深さ＝計画」と「なった深さ＝結果」を混同しない。
- **処置をする人と患者を見る人を分ける** ── 実務上いちばん重要で、いちばん守られにくい。
- **酸素は低酸素血症を遅らせるが低換気は止めない**。その空白に二酸化炭素が溜まり、
  二酸化炭素自体が鎮静を深くする。だからカプノグラフィ。
- **痛みは鎮静薬では取れない** ── 痛い処置に鎮静薬を足すと呼吸だけ止まる。
- **処置終了直後が危ない**（刺激が消えて深くなる）。「目が覚めた」は帰宅基準でない。
- 集計で見るべきは「中等度のつもりがどれだけ深くなっているか」。

**国内の制度（第18章）**：[[reference-r8-anesthesia-sedation-rules]] を根拠に
令和8年度改定の3軸再編に触れたが、**点数・要件・時間区分の具体は書いていない**。
「算定や請求の根拠として用いるものではない、最新の通知と医事担当に確認」と明記し、
refs40_extra の `JP-R8-SEDATION` で出典を示した。

**書かなかったこと**（付録C-5・C-6）：鎮静薬の投与量と速度、絶飲食の時間、監視の間隔、
帰宅までの観察時間、拮抗薬の用量。**小児の処置鎮静・ICU の人工呼吸中の鎮静・
緩和ケアの鎮静は対象外**（体制も枠組みも別物）。

**残りの `_教材化待ち` 候補**：小児麻酔の基礎（女子医大の小児心臓・小児カテ麻酔
マニュアル）／周術期感染対策（CDC 2011 の血管内カテーテル関連感染）。
