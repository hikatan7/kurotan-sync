オカレンスレポート（麻酔科／CE／NS）の月報では、**報告件数の増加を肯定的に評価する**。「最悪の水準」「実質的な悪化」といった否定的な断定は使わない。

**Why:** オカレンスレポートはアクシデント報告とは性質が違い、件数はインシデントの発生量ではなく、現場が事象を拾い上げて共有できているかを示す指標。件数の減少はむしろ過少報告を疑う場面。ユーザー（手術室のCE／医療安全担当）から2026-09-07に明示的な指示があった。

**How to apply:**
- 件数増 →「報告文化・ヒアリング文化が機能している」「拾い上げられている」と書く。分類別の増加（例：手術準備不足27→35件）も「欠品が確実に可視化されている」と捉え、そのうえで対策継続を promptする。
- 安全性の評価は件数の多寡ではなく、**個々の事象の重大性と再発の有無**で行う。患者到達事例・法令順守事項（麻薬管理等）・職業感染は「件数とは切り離して重点対応」と明記して両立させる。
- 指標名は「100手術あたり発生率」ではなく **「100手術あたり報告件数」**（2026年8月度から改称、定義は同じ）。表・グラフ軸ラベル・本文すべてで統一する。
- 付記には評価の考え方（件数増＝報告文化の定着／件数減＝過少報告を疑う／安全性は事象の重大性で判断）を毎回1行入れる。

作成手順そのものは [[workflow-occurrence-monthly-report]] を参照。
