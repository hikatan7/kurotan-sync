## ㊽『術後鎮痛と体幹の区域麻酔』（本編25頁・全18章・図7・引用17）
- 軸＝**「薬を選ぶ仕事ではなく、時間と場所を設計する仕事」**。
  患者が痛がる原因は薬の選択より設計（効き始めの時刻／切れる時間帯に手が無い／
  病棟で実行できない指示／副作用で結局使えない）。
- **痛みを三つに分ける**（体性・内臓・神経障害性）。
  効くのは「筋膜面ブロックは内臓痛に届かない」の一点 ──
  腹壁ブロックを入れて痛がるとき「効いていない」のか「届かない痛みが残っている」のか。
- 目標は痛みゼロではなく**動けること**（咳・深呼吸・座る・歩く）。
- 筋膜面ブロックは**面に広げるため量が要る**＝局所麻酔薬の総量が最大の制約。
- 失敗の最頻形＝**切れる時間帯が夜間になる設計**。

## ㊾『弁膜症手術と冠動脈バイパス術の麻酔』（27頁・全18章・図6・引用14）
- 弁膜症は病名でなく**圧負荷か容量負荷か**の二軸で読む。
  「脈は速め／遅め」「後負荷は下げる／保つ」は全部ここから出る。
- **弁膜症手術では手術そのものが生理を変える** ──
  狭窄を取れば後負荷が急減、逆流を直せば逃げ場が無くなる（術前の方針を離脱後に持ち込まない）。
- 僧帽弁閉鎖不全で離脱後に駆出率が落ちるのは合併症ではなく、隠れていた機能の露呈。
- CABG は**心拍数が供給と需要の両側に出てくる**＝頻脈を避ける原則の根拠。
- 血管麻痺は「足りない」ではなく「締まらない」── 輸液を重ねると浮腫だけ増える。
- 血行動態の目標は**方向だけ**書き、数値は書かない。

## ㊿『高齢者麻酔』（26頁・全18章・図6・引用15）
- 軸＝**「年齢そのものはほとんど何も教えてくれない」**。予備能と機能で評価する。
- 予備能の減り方は臓器ごとに違う ──「どの列が最も細いか」を患者ごとに見積もる。
- せん妄：**低活動型が見逃される**（静かな患者は「落ち着いている」と記録される）。
  素因と誘因に分けると、素因が大きいほど小さな誘因で起きる関係が見える。
- 予防で確かなのは**多因子の非薬物的介入**。「薬で予防」は代わりにならない。
  **麻酔深度を浅く／区域麻酔にする、はいずれも大規模RCTで明快な支持を得ていない**。
- 最終章に**「手術をしないという選択肢」**を置いた ──
  十七章がすべて「手術をする」前提の上に立っているため。

## 〔51〕『脳神経外科の麻酔と脳保護』（26頁・全18章・図6・引用15）
- 軸＝**頭蓋という閉じた箱**（㊸の腹腔と同じ構造。ただし限界が早く来る）。
- 脳灌流圧＝動脈圧−頭蓋内圧。**麻酔科は両側を動かせる**。
  頭蓋内圧を上げてしまう操作はどれも日常の手順（気道刺激・換気不足・頸部・PEEP・頭低位）。
- **「脳を守る」を三つに分ける**（灌流／需要／二次的傷害）。確かなのは三つめだけ。
  神経保護薬は前臨床で有望・臨床でほぼ全滅という歴史を第17章に置いた。
- 脳の弛緩は**順番で作る** ── 引き算が先、薬は四番目、五番目は「頭蓋内で何か起きている」。
- 血圧は「値」より**変動させないこと**（傷んだ脳では自己調節が働いていない）。
- 抜管の条件に**⑤神経学的評価**が加わる ──「抜かない」が正解になりやすい。
