2026-10-12、Junko「これまでのテキスト全部確認、頁制限で小さくなっていたら作り直して」。教育ファイル集＋経営学テキスト＋グロービス復習ノート39本ほか、自作 docx 168本（グロービスの課題提出物26本は対象外）。

- 道具：`自作ファイル集\表の列幅自動調整\readable_docx.py`（process＝_旧版に「_見やすさ調整前」を控えて上書き、reprocess＝控えなしでやり直し）。fit_tables.py を import。
- 見つかったこと：109本で見出し・章番号が MS ゴシック＋Calibri（python-docx 既定テンプレのテーマ書体）。6本は本文が游明朝／游ゴシック。本文 8.5〜9.5pt が9本、表 7.5〜8.5pt が多数。CVC研修医専攻医版に白紙頁10枚・表紙題名に略語展開・「A4 31頁」、SGB要点ガイドに「A4 8頁」と表紙前の略語一覧、復習ノート9本に白紙頁。
- 結果：全168本で書体メイリオのみ、本文10pt以上、表8.5pt以上、白紙頁0。総頁 4,300→4,549。エホバ「最新動向2頁」→「最新動向」に改名。ポータル再生成（220資料）。一覧は デスクトップ\教材の見やすさ調整_一覧_20261012.xlsx（リンク付き）。
- 落とし穴：表セルの重複除去に id() を使うと使い回されて取りこぼす（要素そのものを set に）。fit_tables は MIN_PT=8.5 未満に縮めない。白紙頁削除は Word で頁範囲の文字が改行・改頁だけのときのみ、セクションをまたぐ頁は触らない（SGB の表紙前改頁は手で削除）。
- **How to apply:** 生成スクリプト（build_*.py 等）から教材を作り直したら、最後に readable_docx.py の reprocess を通す。新規教材も同じ。関連 [[feedback-slides-large-bold-font]] [[feedback-no-page-limits-short-versions]]
