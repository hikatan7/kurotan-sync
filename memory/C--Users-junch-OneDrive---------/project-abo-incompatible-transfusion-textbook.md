麻酔科ミニ教科書シリーズ㉕『ABO不適合移植と輸血 ── 血液型という圧縮ファイルを、一度だけ解いてみる』を2026-09-17に作成。58頁、全5部23章＋付録A〜C、図版15点・表15点・コラム7本。
`教育ファイル集\麻酔科ミニ教科書シリーズ\25_ABO不適合移植と輸血\`（docx＋PDF＋_生成スクリプト）。

**この巻の設計方針**：ユーザーから「マニュアル用ではない、チェックリストは不要、読み物として面白く輸血の概念を考えさせるもの」と明示指定。そのため早見表・チェックリストを本文から排し、次の一本の論理で全章を貫いた。

- 「O型である」は〈赤血球の抗原〉と〈血漿の抗体〉という独立した2事実を一語に畳んだ圧縮ファイル。展開の前提は「体内のABO抗原領域は患者の赤血球ただ一つ」。
- ABO不適合移植はこの前提を壊す（グラフト内皮＝第二の抗原領域）→ 適合性は「三本の軸」で数え直す。第3軸（製剤の抗体 vs グラフト抗原）が移植で初めて現れる。
- 結論は暗記表ではなく「三つの問い」（抗原領域は何種類か／製剤は何を持ち込むか／その抗体価は誰が作ったか）。

**内容上の判断**（他AI提案からの修正を含む）
- 「AB型FFPは万能」を退け、**AB型＝安全解／ドナー型＝最適解**の二段構えに。可溶性ABO物質（分泌型＝日本人の約8割）とAB型の供給制約を根拠にした。
- 警戒期間は「術後2週間」ではなく**数週間〜1か月**（accommodation成立に個体差）。
- 赤血球は**O型を反射で選ばない**、レシピエント型優先。
- 「移植とは、二度と洗い流せない輸血である」を第5章の中心命題に据えた。
