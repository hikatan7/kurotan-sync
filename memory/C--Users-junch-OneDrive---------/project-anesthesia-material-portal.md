**2026-09-14 改訂：1件＝1つの資料（テーマ）にまとめ、役割ボタン4つにした。**
それ以前は 1ファイル群＝1件で、BIS のように版が多い資料が7行並んで探しにくかった。

- ボタンは **詳細版 / 研修医テキスト / 要点解説プレゼン / 資料ファイル** の4つ。
  「専門医」「完全ガイド」等は**専門医テキストを作らず詳細版に寄せる**（ユーザー指示）。
  中身が2本以上のボタンは数字が付き、押すと下に一覧が開く（`.rwrap`/`.rdrawer`）。
- Word・PowerPoint の原本、`_略語対応前` など先頭 `_` のフォルダの控えは全部「資料ファイル」送り。
  `KEEP_UNDERSCORE`（`_PDF（閲覧用）` `_スライド版` `_デスクトップコピー統合_…`）だけは通常フォルダ扱い。
- ミニ教科書シリーズの巻名は `12_BISモニター` という**フォルダ名を正**とする。
  `_スライド版` の長い名前がタイトルを乗っ取らないよう `topic_of()` が `sure` を返す。
- **122資料**（2026-09-14時点）。一次資料は全部 [[project-teaching-material-backlog]] へ出したので、
  ポータルに並ぶのは自分の教材だけになった。分野→対象者→テーマの絞込は従来どおり。
- `_PDF（閲覧用）` の書き出しPDFは、同名の pptx/docx がある文書へ合流させている
  （別フォルダにあるため、素直にやると同じ資料が2件に割れる）。
- スライドしか無い資料は詳細版に繰り上げない（①専門医版20枚が「詳細版」と
  名乗ると本があるように見えるため）。繰り上げるのは研修医テキストだけ。

  語の切れ目まで戻して8字以上、切れ目が無くても14字以上一致していれば同じ資料とみなす。

  「手術室_経営分析」「予定手術時間逸脱による経営損失の拡大」などがこれで1行になった。

  **「麻酔科研修医講義：周術期を…」が「麻酔科」になっていた**。

  「…：初期」のような削り残しと末尾の記号も落とす。
- `TITLE_FIX` … 題名そのものの直し（「周術期のおける」→「周術期における」、
  末尾の配布日 `HY_20230116` / `20150727`、先頭の `2023.02`、末尾の「について」）。
