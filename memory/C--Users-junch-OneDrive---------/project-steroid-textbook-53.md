**別冊『副腎とステロイド製剤』12頁・引用26件（2026-10-07）**：旧4頁版『静注ステロイドの使い分け』を取り込んで置き換えた。4頁版はごみ箱に送ってある。
- 前半は副腎の皮質三層と髄質の分泌・働き（新図 f09）、副腎不全の病型、褐色細胞腫、クッシング術後の補充。
- 後半は製剤の違いと役割（静注・内服・フルドロコルチゾン）、静注5製剤の使い分け、投与の注意、コハク酸エステル。
- 生成は c53_adrenal.py → build_adrenal53.py。c53_iv.py と build_iv53.py は旧版の残り。
- 添付文書は PMDA で確認済み（キー PMDASC・PMDAPSL・PMDADEX・PMDARIN・PMDASM40）。ソル・メドロールは500 mgを超える量を10分未満で入れると心停止の報告があり、250 mgを超えるなら30分以上かける。デキサート6.6 mgは「デキサメタゾンとして」の量（塩としては8.74 mg）。
- NSAIDs 過敏喘息で問題になるのはコハク酸エステルの構造（Taniguchi 2023, PMID 38026126）。
- 原発性アルドステロン症の術後高カリウムの推奨は、Funder 2016 の本文で確認できなかったので書いていない。
