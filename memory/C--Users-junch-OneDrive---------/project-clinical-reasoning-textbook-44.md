**この巻の軸**
- **麻酔科の推論は「診断してから治療する」ではなく「介入しながら診断を絞る」。**
  血圧が落ちたとき最初に知りたいのは病名ではなく、いま何をすればよいか。
- **三つの問い**＝①いま危ないか ②何が変わったか ③確かめる手はあるか。
  ①を飛ばすと患者が悪くなり、②を飛ばすと鑑別が広がりすぎ、③を飛ばすと思い込む。
- **鑑別は臓器別でなく機序別の「箱」で並べる。** 箱は打つ手に対応し、
  空いている箱を見れば「まだ考えていないこと」が分かる。
  頻度は箱のなかでの順番に使うもので、箱の選び方には使わない。
- ③には必ず**測り方の疑い**を含める。モニターが測っていないもの（灌流・心拍出量・
  酸素運搬量・腎機能）を、測っているもので代用するところから誤りが始まる。
- **振り返りで最も多い結論は「診断は正しかったが、たどり着くのが遅かった」。**
  この失敗は知識を増やしても減らない。減るのは気づいてから動くまでの時間。
  そして遅れの多くは「まだ確信がないから」で生じる ── 確信がないことは呼ばない理由にならない。
- 振り返りでは**「誰が」ではなく「何が」を問う**（コラム）。
- 最終章＝説明がつかないとき、一人で考え直すのではなく人を増やし外部の手順に頼る。
  内科の推論と最も違うのは「手術室には一緒に考える人がすぐそばにいる」こと。
