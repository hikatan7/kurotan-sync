令和8年度診療報酬改定で「内視鏡手術用支援機器加算 15,000点（150,000円）」が新設。**施行は2026年6月1日**（ユーザー確認済み。院内ガイドHTMLの表紙には「4月施行」とあるが誤り）。対象手術1件ごとに算定。

施設基準4要件：①ロボット手術 年間200例以上（告示26区分の診療科合算）②麻酔科標榜・常勤麻酔科標榜医＋常勤臨床工学技士1名以上 ③保守管理計画＋関連学会レジストリ参加 ④前年症例数・平均在院日数のWeb公開（経過措置 令和9年5月31日まで）。

**訂正（2026-10-16）:** 加算の注（K939-4）の対象25区分に **K865-2 腹腔鏡下仙骨腟固定術**（ほか K674-2 総胆管拡張症・K778-2 腎盂形成）が入っている（厚労省概要p38＋告示転載 knowlety/しろぼん）。施設基準の200例は K843-4 前立腺を加えた26区分。施設基準＝麻酔科標榜・常勤麻酔科標榜医・緊急手術体制・常勤CE1名以上・保守管理計画・レジストリ・Web掲載（経過措置R9.5.31）、様式73の4、通知 第80の12。疑義解釈その5（2026-05-08）問17＝Web掲載は手術ごと、平均在院日数＝(退院−入院+1)÷患者数。
**当院の再集計（手術1行データ、2025-08〜2026-07で284件を再現）:** 産婦人科59＝仙骨腟固定36・腟式子宮全摘21・附属器1・卵管1 → **加算対象216（呼外89・消外68・泌尿23・仙骨腟固定36）／算入のみ39／対象外29、200例の算定対象255件（余裕55）**。下の旧ルールの「仙骨腟固定術は対象外」は誤り。医事課が6月以降の36件に加算を請求しているかは未確認。

**対象判定のルール（ユーザー確認済み）**
- **加算の対象は悪性腫瘍手術のみ**
- 前立腺癌手術（腹腔鏡下前立腺悪性腫瘍手術）＝施設基準の200例には**算入されるが、手術自体に加算は付かない**（唯一の非対称）
- 良性手術は加算にも200例にも入らない：婦人科の仙骨腟固定術・腟式子宮全摘術・附属器・卵管、呼外の胸腔鏡下肺切除術（区域切除・良性）など
- 胸腔鏡下良性縦隔腫瘍手術（支援機器）は加算が付かないため導入初期の数件のみで、現在は実施していない
- 鼠径ヘルニア・尿管ステント留置＝対象区分外

静岡病院の直近12ヶ月ロボット284件の内訳＝加算算定可180件（呼外89・消化器外科68・泌尿器科23）／200例カウントのみ39件（前立腺癌）／対象外65件（産婦人科59・呼外の良性肺切除3・鼠径ヘルニア2・尿管ステント1）。**200例カウント対象は219件で基準は満たすが余裕は19件のみ**。良性のロボット手術は増やしても200例には効かない。年換算の増収は呼外1,335万円・全科2,700万円。加算対象のロボット症例の利益率は47.0%→54.3%（+7.2pt）・1件差引44.6万→59.6万円に改善するが、従来胸腔鏡79%は下回ったまま。

判定コード（`scratchpad/thoracic3.py` の `addon_cls`）：前立腺悪性腫瘍→カウントのみ、`['良性','肺切除術','肺縫縮','肺嚢胞','仙骨腟固定','子宮','卵管','附属器','ﾍﾙﾆｱ','ｽﾃﾝﾄ留置']` のいずれかを含む→対象外、それ以外→加算。

**呼吸器外科の基本K点数（院内マスター `レセプトデータ作る君_マスター.xlsx` シート `s_20260501`、列index 2=コード/4=名称/11=点数）**
胸腔鏡下肺悪性腫瘍手術 部分60,170／区域72,640／肺葉以上92,000／気管支形成107,800／肺全摘93,000。
開胸K514 部分60,350／区域69,250／肺葉以上72,640／気管支形成80,460。**支援機器使用区分は対応する胸腔鏡下区分と完全に同点数**（区域72,640・肺葉92,000）で、基本点数の上乗せは存在しない。
良性K513 部分45,300／区域72,600／肺葉以上81,000。胸腔鏡下の縦隔悪性・良性縦隔・拡大胸腺はいずれも58,950。
併算定：自動縫合器加算2,500点/個（肺切除は6個上限=15,000点）、超音波凝固切開装置等加算3,000点、画像等手術支援加算（ナビ）2,000点。
→ RATS肺葉切除1件は改定前110,000点、支援機器加算15,000点を加えて改定後125,000点（+13.6%）。
なお同マスターは令和6年度改定ベース（初診料291点）で、15,000点加算は未収載。

出典資料：デスクトップ `呼外プレゼン資料作成\thoracic_surgery_reimbursement_guide_R8.html`。ただし同ガイドのK点数（VATS肺葉切除50,160点など）は院内マスターの値（92,000点）と食い違うため、基本点数はレセプトデータ作る君マスターを使うこと。
