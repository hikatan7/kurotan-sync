**Why:** 器具の失敗は文言では直らない。形状を名指しで指定（フランジ・ローレット・接続角度）すると部品の形は改善するが、位置関係は破綻したまま。しかも自己申告は全項目「はい」で実物と一致しなかった＝**描いた絵を見ずに報告している**。完了報告は規約遵守の確認には使えるが、品質の確認には使えない。同じ図はGeminiのほうが正確だった（消費ゼロ）。
