**この巻の軸**
- **腹部の麻酔は「腹腔内圧」という一本の軸でまとめられる。** 気腹でも、腸閉塞でも、
  腹腔内出血でも、圧が上がったとき起きることは同じ順序（横隔膜↑／静脈還流↓／
  腎の出口が細る／内臓灌流↓）。この共通項があるから一冊になる。
- **予定手術と緊急手術は別の仕事。** 予定は ERAS の枠組みで判断の多くが術前に済む。
  緊急は評価の時間が無く、成績を決めるのは手技より体制
  （ERAS の緊急開腹指針が術前・術中術後・**体制**の三部構成なのがその証拠）。
- 腹腔鏡は「術後の回復が早い」だけで、**術中の生理はむしろ大きく動く**。
- **気腹中の尿量は容量の指標にならない**（圧に対する反応）。輸液で追うと体液だけ増える。
- 送気圧は麻酔科が指示する数字ではなく「下げたければ深い筋弛緩で支えます」という交換条件。
- 肝切除の離断中だけ**低い中心静脈圧＝逆向き**。離断終了を誰が宣言するかを決めておく。
- 最終章の主張＝**腹腔内の圧と血流を数字で見ているのは麻酔科だけ**。外科は術野、病棟は術後。
  だから役割は「見えている数字を、見えていない人に届けること」。
