「いきなり CIED などの略語が出てきて読めない」という指摘から、
シリーズ全13巻・20ファイルに略語対応を入れた（2026-09-03）。

**Why**：専門医向けでも、初出の略語が説明なしに出ると読者が止まる。
ユーザーの指定した形は **`略語（英語表記：日本語表記）`**、
総称語はさらに「何の総称か」を先に説明してから始める。

**方針**（ユーザー選択）：巻頭に「本書で使う略語」の表＋本文は章ごとの初出で展開。
ICU・CT・ECG など日本語として定着した語だけは巻で1回（`COMMON_ONCE`）。

**道具**（scratchpad と `13_気道管理\_生成スクリプト`）
`abbr_dict.py`（GLOBAL 269語＋巻別 PERVOL＋巻別 EXCLUDE）／`apply_abbr.py`（置換の実装）／
`run_abbr.py`（1ファイル処理）／`concept_blocks.py`（総称の概念ブロック）／`master_abbr.py`（全巻）。
原本は各巻 `_略語対応前` に退避してから上書きする。

**踏んだ落とし穴（同じことをするなら必ず入れる）**
1. **二重括弧**。`総体液量（TBW）` をそのまま展開すると `（TBW（total body water：総体水分量））` になる。
   括弧の中に略語だけがある場合は、括弧ごと `（TBW：total body water）` に書き換える。
2. **同義の重複**。既に `（central venous catheter：CVC）` と書いてある段落を展開すると英語が2回出る。
   「英語綴りが同じ段落に既出なら触らない」を条件に入れる。
3. **文献リスト**。参考文献の行を展開すると引用文そのものを書き換えてしまう。
   `et al.` `doi:` `2015;10:471` などを含む行は除外する。
4. **巻ごとに意味が違う略語**。第3巻の MAC は膜侵襲複合体、第9巻の MAP は保存液、
   第3巻の LR は白血球除去（第1・2巻は乳酸リンゲル）。巻別の辞書と除外リストで切り分ける。
   試験名（ELAIN, ADVOR…）・雑誌名・著者イニシャルは辞書に入れないことで自動的に除外する。

**概念ブロックの挿入位置**は「章見出しの直後」。ただし部の中扉に並ぶ章名一覧を拾わないよう、
「後続に40字以上の本文段落があること」を条件にし、節見出し・図表キャプション・空行は読み飛ばす。
