詳細版も配布資料なので、書籍のように**参考文献・参考書・付表だけ**を載せる。検索・照合・記述の過程は全部書かない（2026-09-28 Junko指示「全ての文書で徹底して」）。

書いてはいけないものの例：付録「出典の確かさと、確認できていないこと」「確認できなかったこと・保留した数値」「本書の作り方と限界」「原案の検証記録」「検証した記載と載せなかった記載」「本書作成にあたって修正した記述」「本書が数値を書かなかった事項」、参考文献の前書きの「PubMed 識別子（PMID）と DOI を確認した。台帳は…SourceLedger.xlsx にある」「この巻にはこれまで文献の一覧がなかった」、本文の「本資料の作成時点で…確認できていない（付録B）」「原案は…としていた」「他のAIに検索を依頼した」。
（当初は研究の限界・施設で決めておくこと・扱わない範囲・臨床の「照合」「検証」を残したが、同日の追加指示で全部削除対象になった。下記参照）

**Why:** 読者は受講者・院内スタッフ。制作の舞台裏は配布物に不要で、信頼性を下げて見える。
**How to apply:** 新しく作る教材では最初から書かない（bookkit の付録テンプレにも入れない）。SourceLedger.xlsx は手元の管理用として作ってよいが、本文から参照しない。
2026-09-28 に既存 92 docx＋スライド 9 本を一括で削除済み（元は各フォルダ `_過程記載削除前_20260928`）。作業スクリプトは scratch の `strip/strip2.py`・`strip3.py`。**各巻の _生成スクリプト（c??_p?.py 等）の本文ソースには過程記載が残っている**ので、ビルドし直すときはソース側も削ること。

**2026-09-28 追加指示：基本テキストは「事実のみ」。** 院内文書として配布するときは作り直すので、教科書本体には次も書かない。
- 「本書で触れた研究と、その限界」「本書の立場と限界」「本書と第⑳巻の分担」
- 「施設で決めておくこと／決めておきたいこと」
- 扱わない範囲の断り書き（「本書は用量を書かない」「本書が書かなかったこと」「本書の対象外」）
- 「照合」「検証」を含む文（輸血の照合手順や「〜を検証した試験」も含む。ユーザーが文ごと削除を選択）
付録を削ったら記号を詰める（A・C・E → A・B・C。本文の「付録C」「C-5」「表C-1」も振り直す）。
作業：`strip4.py`（見出し・本文）→ `strip5.py`（表）→ `pptapply.py`（スライド）→ `reletter.py`（付録記号）。元は `_限界・範囲記載削除前_20260928`／`_付録記号詰め前_20260928`。
2026-09-29 の全PDF検索で取りこぼしを直した：前書きの「本書の立場と限界」は**見出しスタイルでない普通の段落**だったため46本で残っていた（`strip6.py`、元は `_立場と限界削除前_20260929`）。総目次の付録表記・専攻医版の「本編の付録D」参照・トルーソーの「原典を確認できなかった」等は `fix7.py`（元は `_残り修正前_20260929`）。
教訓：表のセルの段落を全部消すと Word が「ファイルが壊れている」で開けない（セルに最低1段落必要）。**検索は docx ではなく出力後の PDF 全文で行う**と取りこぼしが見つかる（`strip/pdfscan4.py`）。
元ファイルがなく PDF だけのもの（研修医講義「評価・計画・実行・再評価」＝pdf-lib製、周術期のはじめかた50頁＝HTML元なし）は直せていない。ただし「仮説を検証」は 2026-09-29 に PDF 上で「確認」へ直接差し替えた（⑩icu_af_revised_pptx.pdf と50頁読本、scratch `pdfedit/edit.py`）。
PDF直接編集の教訓：redact(fill=False, 画像・線画は残す)→同じ原点・大きさ・色で insert_text。**`subset_fonts()` を文書全体にかけると元の埋め込みフォントの字（「に」「I」）が消える**。差し込む字だけ fontTools で部分フォントを作って使う。Noto Sans JP は Windows では可変フォントしかないので fontTools の instancer で wght 400/700 を書き出す。書き換え頁以外の画像が1画素も変わらないことを全頁比較で確かめる。
2026-09-29 にミニ教科書総目次の各巻「○頁 / ○頁」と別冊頁数を実PDFに合わせた。高度心臓血管麻酔の総目次（頁番号を手書きした表）は各章PDFの目次リンクから付け直した。周術期禁煙ガイドライン.pdf は外部文書なので対象外。

**2026-10-09 追加指示「本文と引用文献以外は決して（入れない）」。** 次も全教材から削除した（107原本・106 PDF、控えは scratch の strip\backup・backup_pdf）：参考文献の前書き「本文の肩付き番号は…」、表紙の「全N章／図版N点／参考文献N件」「図版N点」、「本別冊は要点だけを抜いた…本編を参照」「この冊子は…組み直したもの」、「この章の立場と限界」節、「この本／この巻／この冊子／この資料の使い方」、執筆時点の断り、「本書では扱わない」等の範囲の断り、作図・下敷き・統合した5資料などの作成過程。アナフィラキシー統合ガイドは「5資料」の枠組みを見出しごと書き換えた。残したもの：本文中の他巻への参照、臨床上の注意（「用量は施設の手順書に従う」等）、「本書が依拠した文書」（文献の説明）、㊵第19章「施設で決めるということ」（本文の章）。
