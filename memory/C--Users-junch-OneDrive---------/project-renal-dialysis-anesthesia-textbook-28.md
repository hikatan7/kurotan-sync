麻酔科ミニ教科書シリーズ㉘「腎不全患者・透析患者の麻酔 ── 腎臓が無い人ではなく、
六つの仕事が抜けた人として読む」。**75頁（番号引用化後）・全5部30章・図版14点・表24点・コラム12本・
各章まとめ30本**（2026-09-17）。④⑤㉓㉔とは主語が違う ── あちらは「腎臓」、
本巻は「手術室に来る患者」。

**骨格＝腎臓の仕事を六つに分け、抜けた仕事ごとに手術室での顔を対応づける。**
①溶質排泄→出血傾向・意識 ②水電解質→肺うっ血・高K ③酸塩基→昇圧薬の効き
④血圧調節→振れ幅 ⑤内分泌→貧血・石灰化 ⑥薬物排泄→覚めない。
**透析が代行するのは①②③まで。⑤は代行されない。⑥は麻酔科医の仕事そのもの。**
第二の軸は時間 ── 週168時間のうち代わりが動くのは12時間だけなので、
検査値はすべて「前回透析からの経過時間」とセットでしか読めない。

**調べて確認した事実:**
- 2024年末の日本の透析患者 337,414人／人口百万対 2,725.4／平均 70.27歳／
  導入 36,404人（平均71.69歳）／死亡 38,348人／腹膜透析 10,774人。
  原疾患は糖尿病性腎症39.2%・慢性糸球体腎炎23.0%・腎硬化症14.5%。
  導入患者では腎硬化症が19.1%で二位（透析会誌58巻12号）。
- **麻酔導入前の安全なカリウム上限を定めたガイドラインは存在しない。**
  流布している 5.5／6.0 は、5.5超で術中に下げる処置が約2倍、
  24時間以内に6.0以上で中止が2.40倍という観察研究に由来する。
  どちらも**患者の転帰ではなく医師の行動を測った数字**。実際に中止になったのは
  5.5以上の一割にすぎない。**ただしこの二つの効果量（約2倍・2.40倍）は
  2026-09-21 の再調査でも PubMed 上に原典を特定できなかった**ため、
  番号引用化のさいに肩付き番号を付けず、参考文献の前書きにその旨を明記した。
  周辺の記述には Olson 2003（PMID 12826545、無症候性高K 8例で有害事象なし）と
  Ross 2015（PMID 24840070、手技別に中等度以上の高Kが5.8〜38%）を当てた。
- **スガマデクスの日米の食い違いが本巻のハイライト（第20章）。**
  国内添付文書 9.2 は「本剤は腎排泄されるため、排泄が遅延するおそれがある」だけで、
  禁忌でも「投与しない」でもない。米国FDAはCCr<30 mL/分で非推奨。
  同じ薬物動態データを見て解釈が違う。16.6.1 に
  「**high-flux 膜による平均6時間の透析で血漿中濃度が約70%減少、
  low-flux 膜では除去されなかった**」（重度腎機能障害群に透析患者9例）。
- SGLT2阻害薬は手術3日前（エルツグリフロジンは4日前）に中止。
  3日以上の休薬で周術期の正常血糖ケトアシドーシスが有意に少ないという観察研究があるが、
  **エンパグリフロジン中止75時間後の発症例報告がある** ── 守れば起きないものではない。
- GLP-1受容体作動薬は2024年の多学会指針で一律休薬からリスク層別へ。
- 尿毒症性出血は効果発現と持続で手を選ぶ ── デスモプレシン0.3 µg/kgは約1時間で効き
  4〜8時間、クリオ10単位は1時間で4〜12時間、結合型エストロゲン0.6 mg/kg/日×5日は
  6時間で効いて14〜21日（最大効果は5〜7日後）。貧血の是正が効くのは軸集中の回復。
- **リンゲル液1Lのカリウムは約4 mmol ＝ 無尿患者の一日蓄積量（40〜60 mmol）の
  十分の一以下。**生理食塩水大量投与の高クロール性アシドーシスのほうが桁違いに動かす。
- 高カリウムは三層 ── ①カルシウム（1〜3分、値は下がらない）②GI・β2刺激薬
  （15〜30分、いずれも0.5〜1.0 mEq/L）③透析（1時間で1 mEq/L以上）。薬は透析までの橋。

**確認できず保留（付録Cに明記）:** 透析患者に特化した周術期輸血閾値のRCT／
術前追加透析の効果（「改善しない」と示した試験も無い＝データが無い）／
腹膜透析液を残したまま全麻をかけたときの換気への定量的影響／
透析患者の局所麻酔薬中毒閾値／術後の透析導入率の代表値。
