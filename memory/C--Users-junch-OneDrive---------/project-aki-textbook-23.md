④（利尿薬）⑤（AKD/CRRT）とは別主題。
コラムには Willem Kolff と中本悟先生の逸話（クリーブランドの研究室、ツインコイルとミシン、
Baxter 60ドル、透析液をなめて濃度を確かめた話）を収めた。
**付録Cだった「確認できなかった記述と、修正した点」は削除**し、付録D→付録Cに繰り上げた
（2026-09-14の指示）。以下の検証記録はこのメモにだけ残る。

**骨格:** 「腎前性・腎性・腎後性」の上に **IN FLOW / KIDNEY / OUT FLOW** を置く。
治療は五本のレバー（Cause・Perfusion・Pressure・Nephrotoxin・Complications）。

**原案（他AI出力）の記述を検証し、10点を修正して付録Cに一覧化した。** 主なもの:
- 蛋白投与量「AKI 1.3–1.5 / CRRT 1.7 g/kg/日」→ **KDIGO 2012 は 0.8–1.0（非異化性・
  透析なし）、1.0–1.5（RRT中）、最大 1.7（CRRT＋異化亢進）、いずれも 2D**（Web検証済）
- FENa <1%/>2%、BUN/Cr >20 → 補助指標に格下げ
- 横紋筋融解の尿量200–300 mL/h・重炭酸で尿pH>6.5 → 固定目標を置かない
- 骨髄腫腎のHCO-HD/血漿交換「標準治療」→ 補助。最優先は軽鎖産生を止める治療
- コレステロール塞栓「抗凝固は原則中止」→ 適応を再評価（機械弁等では致命的）
- 「腎前性が55–60%」→ 固定値として載せない
- CA-AKI と CI-AKI を分離。PRESERVE（n=5,177、90日イベント 4.7%対4.4%、
  4.6%対4.5%）で重炭酸もNACも生食・プラセボに優越せず（Web検証済）
**確認できず保留:** テルリプレシンの国内HRS適応、造影剤量/eGFR比3.7、NGALのカットオフ。
