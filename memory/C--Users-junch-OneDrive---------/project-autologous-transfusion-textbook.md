この主題で毎回調べ直す必要がある一次資料の要点（2026-08-17時点で確認済み）:

- 厚労省の「血液製剤の使用指針」「輸血療法の実施に関する指針」「血液製剤保管管理マニュアル」は
  **廃止**され、日本輸血・細胞治療学会「輸血療法実践ガイド」（令和8年2月）に統合された。
  院内文書で旧指針を参照している箇所は差し替えが要る。
- ANH の保存ルール（JSAT 希釈式基準2020）＝ 手術室内で室温保存・持ち出し禁止・
  **有効期限は採血日の24時まで**。採血は麻酔導入後、1回400mL上限・総量400〜1,200mL、
  希釈後Hbは7〜8g/dLを下回らせない、代用血漿はHESを等量・20〜30mL/kgまで。
- 保険：K920「5」希釈式自己血輸血＝返血200mLごと1,000点（**採血量ではなく返血量**、未使用分は算定不可）。
  輸血管理料は別区分 K920-2（Ⅰ220点/Ⅱ110点、貯血式自己血輸血管理体制加算50点は貯血式のみ）。
  **採血バッグ・回路・針・保存費用は所定点数に包括され別途請求不可**（バッグ代の薬価請求は誤り）。
  K923 術中術後自己血回収術＝濃縮洗浄5,500点/濾過3,500点、総出血量600mL以上が要件、悪性腫瘍手術は算定不可。

**Why:** ネット上の要約やAI出力にこの4点の誤りが繰り返し混入していた（242点説、バッグ薬価請求説など）。
**How to apply:** 自己血・輸血の資料を作るときは JSAT の各実施基準PDF と しろぼんねっと r08 版を直接取りに行く。
PDFはWebFetchでは読めないので curl で落として PyMuPDF で抽出する。
