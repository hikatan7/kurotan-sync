麻酔科ミニ教科書シリーズ㉔「腎の溶質処理と血液浄化 ── 分子量・経路と、
クレアチニンが語らないこと」。**66頁（番号引用化後）・全5部26章・表31点・コラム8本**（2026-09-16）。
④（利尿薬）⑤（AKD/CRRT）㉓（AKI）とは別主題。発端はユーザーの質問
「クレアチニンが下がった時期に、他のどの溶質が除去できるようになっているか」。

**骨格＝溶質を分子量ではなく排泄機序で四群に分ける。**
- A 純GFR依存（イヌリン・造影剤）── Cr が代表しているのはこの群だけ
- B 濾過＋尿細管再吸収（尿素・K・Mg・P・水）── 回復期の多尿期に破綻が見える
- C 尿細管分泌依存（インドキシル硫酸・p-クレジル硫酸・多くの薬物、OAT/OCT）
- D 低分子蛋白（β2M・シスタチンC、megalin/cubilin）
結論の一行は「**CRRT は糸球体の代用にはなるが、尿細管の代用にはならない**」。

**調べて分かった重要な事実:**
- 「溶質 × 腎機能（回復時期）」を一枚にした図表は**存在しない**。溶質側の一覧は
  Duranton JASN 2012（88溶質）、腎機能側は Moranne JASN 2009（感度90%のmGFR閾値＝
  副甲状腺50/貧血44/アシドーシス40/高K39/高P37）。この2つを掛けた表は無く、
  付録Bは生理学から組んだ仮の地図として明示した。
- 急性期AKIでは分泌クリアランスは Cr とほぼ比例して低下する（Kidney360 2020, n=10）。
  **「AKIで分泌だけが不釣り合いに壊れる」とは言えない。**不釣り合いな低下は進行CKD
  （JASN 2021）。重症患者では同じCr値で分泌能がばらつき予後と関連（JCI Insight 2021）。
- STARRT-AKI：90日死亡 43.9%対43.7%（RR1.00）だが、**生存者の90日透析依存は
  10.4%対6.0%（RR1.74, 95%CI 1.24-2.43）**。有害事象23%対16.5%、主因は低血圧と低P血症。
  標準群の38.2%はRRT不要。
- MCO膜：MWRO 9〜14 kDa、MWCO 55〜130 kDa。β2M・FLCの除去率はhigh-fluxより高いが
  **予後改善は未確立**。
- CRRTの喪失：アミノ酸5〜20 g/日、低P血症 10.9〜65%。

**確認できず保留（付録Cに明記）:** AKI回復期に各尿細管機能が何週で何%戻るかのヒト
データ／HD1回のインドキシル硫酸減少率の一次出典／CRRT離脱の尿量カットオフ（BEST
Kidney事後解析で400 mL/日前後だが幅がある）。
