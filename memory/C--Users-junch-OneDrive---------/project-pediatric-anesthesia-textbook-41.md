`教育ファイル集\麻酔科ミニ教科書シリーズ\41_小児麻酔の基礎\`（2026-09-22）。
`_教材化待ち\マニュアル` の女子医大・小児心臓麻酔／小児カテ麻酔マニュアルが出発点。

**構成**：本編46頁・全24章・図版9点・コラム6本・番号引用32件（全て PubMed）
＋専攻医版**ちょうど10頁**。
- 第I部 小児は小さな大人ではない（1-3）／第II部 気道と呼吸（4-10）
- 第III部 循環・輸液・体温（11-13）／第IV部 麻酔の実際（14-20）
- 第V部 難しい場面と体制（21-24）

**貫く軸**：標語の中身を具体化する。違いは体の大きさではなく
**解剖・生理・薬物動態の三つが別方向に違う**こと。そして
**年齢によって同じ項目の答えが変わる**ので、「何歳の子か」が診断名と同じくらい重要。

**この巻の要点**
- 安全性データ（APRICOT 28363725／NECTARINE／POCA）が一貫して示すのは
  **重篤事象の中心は呼吸・年齢が低いほど頻度が高い・「誰がどこで」が結果に関わる**。
- 気道抵抗は内径にべき乗で効く → 乳児の1mmの浮腫は内径の大部分を奪う。
  だから操作の丁寧さ・サイズ選び・カフ圧・抜管後の観察。
- カフ付きチューブの議論は**「使うか」から「どう管理するか」へ**移った。
- ビデオ喉頭鏡は**見え方は改善するが成功・時間は必ずしも改善しない**
  （小児では「見えても通らない」）。
- 徐脈の最多原因は**低酸素** ── 薬で心拍数を戻すと発見が遅れる。
- 抜管は「深いまま」か「完全に覚めてから」か**決めて**行う。
  最も危ないのは中途半端な深さ（喉頭痙攣が最も起こりやすい）。
- 神経発達：**乳児期の一回・短時間では明らかな影響は示されていない**（GAS の
  2年 26507180／5年 30782342）。複数回・長時間は議論継続。
  保護者への説明の言葉を note にまとめた。
- 最終章は**「引き受けないという技術」** ── 年に数例では技術が保てない。
  断ることの説明コストと引き受けることの無批判さという非対称があるので、
  線引きを施設の方針として文書化する。

**書かなかったこと**（付録C-6・C-7）：薬剤量、チューブのサイズと深さ、年齢別の
血圧・心拍数、絶飲食の時間、輸液量、局所麻酔薬の上限。
先天性心疾患の小児手術・小児集中治療・新生児蘇生・症候群別の管理は対象外。

**残りの `_教材化待ち` 候補**：周術期感染対策（CDC 2011 の血管内カテーテル関連感染）。
ほかに 看護師教育ツール（DAM/局麻中毒/カテ室シナリオ）と ICU講義ファイル
（NPPV・栄養管理・心エコー）が未使用のまま残っている。
