**この巻の核（調査で判明した最新の制度）**
- **2026年3月23日、フィブリノゲンHT静注用1g「JB」が一部変更承認**。効能・効果に
  「心臓血管外科手術における出血に伴う後天性低フィブリノゲン血症に対するフィブリノゲンの補充」が追加された。
  同日、厚労省三課長通知（医薬薬審発0323／医薬安発0323／医薬血発0323）で適正使用の留意事項が発出。
- **適応の四条件**：①人工心肺を用いた手術に限る ②出血に伴うこと ③投与直前の血中フィブリノゲン値を必ず測定
  ④その値が 150 mg/dL 未満。用法は 1回3g、改善なければ同量追加。薬価 94,077円/瓶。
- 承認された言葉は「出血傾向の改善」ではなく**「フィブリノゲンの補充」**（検討会議が、前者は予防投与を
  想起させるため不適切と明記）。つまり予防投与は承認されていない。
- **公知申請の論理**：REPLACE・Bilecen など主要RCTは主要評価項目を未達成だが、いずれも投与前 Fib が
  150 mg/dL 超。報告書は「150未満での有用性を否定するものではない」とし、
  **「予後改善への寄与を示す情報はない」とも明記**している。有効性が証明されたのではない。
- **ケイセントラは適応がVKA拮抗のみ**。FARES-II（JAMA 2025、n=420、止血成功77.9%対60.4%、AKI 10.3%対18.8%）の
  使い方は日本では適応外。エビデンスが先に来て適応が追いつかない構造は、フィブリノゲンが五年かけて通った道。
- 算定：D006-21 血液粘弾性検査 600点（**人工心肺を用いる心臓手術に限る**・術前中後 各1回・一連で1回）、
  K924-3 同種クリオプレシピテート作製術 600点（施設基準）、K923 自己血回収 5,500/3,500点。
- 国内GL（大量出血GL 2019）：FC 初期 50 mg/kg・クリオ 3〜4 mL/kg（2C）、**POCモニタリングのみ 1B**、
  rFVIIa 予防投与しない（1B）。

**未確認（ユーザーが照会する方針）**：三課長通知の本文、承認条件の全文。付録D-8 に明記済み。
