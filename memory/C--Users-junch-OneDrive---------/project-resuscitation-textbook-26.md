## 構成
- 第 I 部（1〜10章）蘇生アルゴリズムの変遷。1960年までの三つの流れ／会議年と公表年は1年ずれる
  （会議 1966・1973・1979・1985・1992・2000、公表 1974・1980・1986・1992・2000）／
  救命の連鎖と ILCOR／2000年に「消す理由は三つだけ」が決まった／2005・2010・2015・2020・2025／日本側の系譜
- 第 II 部（11〜16章）周術期心停止。NAP7・JSA偶発症例調査・JIPAD・NACOR・SPOR の定義と数字／
  手術室の有利と不利／DOPE と二つの道／JSAプラクティカルガイド2021 の構造／薬とタイミング／質を測る
- 第 III 部（17〜21章）RRS。MERIT の読み方／Chen 2009／4要素／日本の制度年表／指標の組
- 第 IV 部（22〜27章）開心術後心停止。EACTS 2009 → STS 2017 → AHA 2025／三つのリズム／
  5分・10日・5点の器械／アドレナリンを入れない／静岡病院A4チャートの読み解き
- 第 V 部（28〜30章）実装。チームと訓練／hot と cold の振り返り／七本目の鎖「予防」

## 押さえた一次資料と数字
- **AHA 2025**（2025-10-22、Circulation 152(16_suppl_2)）: 全12部、勧告 **760**（Class1 233/2a 217/
  2b 234/3NB 55/3H 21、LOE A は **11（1.4%）**、C-LD 38%、C-EO 27%）。救命の連鎖を4種類→**単一の6環**に統合、
  7本目「予防」は保留。rescue breaths 廃止・lay rescuer・ROC/ROSC の書き分け。
  気道異物は**背部叩打が先**、機械的CPRはルーチン非推奨、head-up CPR は試験外で非推奨、
  DSED は 2b、多形性VTは常に即除細動、AF同期通電は初回200 J以上、血管路は**IVが第一**、
  体温管理 **32-37.5 ℃・総36時間以上**。心停止センター搬送は 2a→2b に格下げ。
  safety huddle（2a, B-NR）と医療者バーンアウト介入（2b）が新規。
- **AHA 2020**: 491勧告中 LOE A は 6（1.2%）。6本目の鎖「回復」。
- **薬の引き算史**: 炭酸水素Na（1986〜）／ブレチリウム（2000）／高用量アドレナリン（2000）／
  アトロピン（2010）／バソプレシン（2015、理由は「簡素化」）。残ったのは電気・圧迫・アドレナリン。
- **JSA 術中心停止プラクティカルガイド**（2021-02-26制定、59頁、WG長 髙橋伸二）: 全12章。
  初回ショックの2分以内のアドレナリンは**かえって心拍再開率を下げる**／昇圧薬は圧迫なしには効かず
  生食20 mLで後押し／EtCO2>20 mmHg・拡張期>40 mmHg／3サイクルで戻らねばECMO。
- **JSA 偶発症例調査**: 心停止 2016年 1.04/1万。全周術期死亡 3.93/1万（2009-11）、麻酔関連死 0.07/1万。
  死因1位は出血。死亡率は新生児17.0・85歳以上10.15 の**U字**。
- **NAP7**（英, 2021-22）3.0-3.5/1万麻酔、881件。**JIPAD**（日, 2015-23）ICU入室例の0.41%、緊急1.74% vs 待機0.17%。
- **MERIT**（Lancet 2005）: 起動 3.1→8.7/1000入院だが複合評価に差なし（5.86 vs 5.31）。
  **Chen 2009（Crit Care Med）**: 早期コール割合が10%増えるごとに心停止 −2.2/1万入院、予期せぬ死亡 −0.94/1万。
  → 「起動件数が増えるのは良いこと」の定量的根拠（[[feedback-occurrence-report-positive-framing]] と同じ論理）。
- **JSICM RRS運用指針**（2024-01-27）: 4要素ごとの推奨。15分以内に現場へ、起動事例は全例検討。
  日本の年表 2008共同行動 → 2013レジストリ → 2017用語集 → **2022 急性期充実体制加算で普及** →
  2024運用指針 → 令和8年度改定で**急性期総合体制加算**（加算1〜4に「急変の兆候を捉えて対応する体制」）。
- **STS 2017**（Ann Thorac Surg 103:1005-20）: 3連続ショック（成功率 78%→35%→14%）、
  ペーシング先行、**5分以内の再開胸**、**術後10日目まで標準要素**、緊急セットは**5点だけ**、
  6つの役割、アドレナリン/バソプレシンは Class III harm、AED・機械的圧迫装置も Class III harm、
  IABP は圧トリガー1:1最大augmentation、人工心肺移行時はヘパリン30,000単位＋リザーバに10,000単位。
