**ユーザー原案に対して本資料で修正した主な事実**（同種テーマの再依頼時に再利用可）:
1. AKDは「7〜90日の期間」ではなく**AKIを包含する上位概念**（ADQI 16, 2017）。実務用語としては「AKI後AKD期」。
2. 単独の「KDIGO AKDガイドライン」は存在しない（KDIGO 2012 AKI GL＋ADQI 16が出典）。
3. RAAS阻害薬はAKI後に**再開した群のほうが死亡率が低い**（Brar 2018）。「再開が危険」は逆。
4. フロセミド負荷試験は**AKI進展予測**の検証であって、CRRT離脱指標としては未検証。
5. 離脱時の実測CrClカットオフは研究間で11〜23 mL/minと幅がある。
6. CKMと透析の余命差は年齢層依存（80歳以上では小さいが70代前半では透析群が明らかに長い）。
7. 日本急性血液浄化学会単独の「CRRT導入/離脱基準」ガイドラインは確認できず。国内一次文献は**AKI診療ガイドライン2016（5学会合同）**と**3学会合同 救急・集中治療における終末期医療GL(2014)**。
8. 「家族の意向が強すぎる」は実証データでなく、厚労省GL(2018)の規範（家族等の役割は"本人の意思の推定"）として整理。

**2026-09-21 の改修 ── 略語展開の事故を直し、番号引用にした。**
保存先は `教育ファイル集 / 麻酔科ミニ教科書シリーズ / 05_AKD期管理とCRRT意思決定`。専門家向けは 61 頁・文献 47 件。

- **事故の中身:** 9月14日の再組版で `abbrev.py` が PDF から略語一覧を読むとき、
  第0章の「原案からの修正点」表（1列目が 1,2,3,5,6,7 という通し番号）を略語表と取り違えた。
  結果、本文中の数字「1」「2」「5」「6」に長い注記が展開として差し込まれ、
  **58 箇所が壊れた**（`STARRT-AKI(n=2,927)` → `n=2（注記）,927`、`約1.3倍` → `約1（注記）.3倍`、
  `Kidney Int Suppl. 2012;2:1-138` の巻号、`K が概ね5.0 mEq/L` など）。
  著者名の `Rosner MH` も MH＝悪性高熱症として展開されていた。
- **直し方:** 8月14日の `_略語対応前` の docx を正解として、差し込まれた「（英：日）」の塊を
  段落の run をまたいで削除した（入れ子があるので繰り返す）。数字そのものは残っていたので復元は不要。
  略語表からは通し番号の6行を落とし、消えていた「原案からの修正点（8項目）」の表を付録として作り直した。
- **再発防止:** `abbrev.py` に `looks_like_abbr()` を足した。
  数字だけ・1文字・訳語が長すぎる行を略語と見なさない。他の29巻を同じ検出器で走査したが、被害は⑤だけだった。
- **教訓:** PDF から表を読んで本文を書き換える処理は、**読んだ表が本当にその表か**を検算してから流す。
  そして再組版のあとは必ず、数字を含む代表的な一文（症例数・用量・巻号）を元版と突き合わせる。
