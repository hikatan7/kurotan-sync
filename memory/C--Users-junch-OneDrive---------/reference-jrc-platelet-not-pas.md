**日本赤十字社がルーチン供給している血小板製剤は「濃厚血小板-LR」＝血漿中に浮遊した製剤**であり、PAS（血小板添加液）で血漿を置換した製剤ではない。PAS置換血小板は日赤中央血液研究所などで品質評価が進む研究段階（T-PAS+を用いた血漿置換率65%製剤の冷蔵保存品質など）。

生成系AIや国内の二次資料に「現在の日赤製剤は約30%が血漿・約70%がPAS」という記述がしばしば現れるが、**これは欧州のPAS製剤スペックとの混同で誤り**。2026-09-17に日赤の製剤情報で確認。

日本の臨床で血小板製剤の血漿量（＝持ち込む抗A/抗B）を減らす現実的な手段は**洗浄血小板**で、受注製造のため事前調整が要る。当日オーダーでは間に合わない。

- 製剤情報: https://www.jrc.or.jp/mr/blood_product/about/platelet/
- 濃厚血小板-LR 添付文書: https://www.kegg.jp/medicus-bin/japic_med?japic_code=00058308

製剤仕様は改定されうるので、運用に落とす前に添付文書と輸血部で再確認すること。[[feedback-verify-ai-supplied-urls]] と同じ類型の落とし穴。[[project-abo-incompatible-transfusion-textbook]] の第13章と付録Cに記載済み。
