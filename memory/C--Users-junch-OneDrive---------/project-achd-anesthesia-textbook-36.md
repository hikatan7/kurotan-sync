**貫く軸**：「病名では決まらない」。ACHD の患者は治った人ではなく**変わった人**で、
いまの循環は〈元の疾患＋手術で作られた循環＋二次的変化〉の三つでできている。
だから病名を暗記せず、**生理で四つに分類**する ──
シャント／狭窄・閉塞／単心室・Fontan／体心室が右室。

**この巻で押さえた要点**
- 全例に当てはまる原則＝**静脈路に空気を入れない**（診断が不確かでも実行できる）。
  左→右シャントの患者でも咳・いきみ・陽圧換気で圧は簡単に逆転する。
- 右→左シャントでは **EtCO₂ が PaCO₂ より低く出る** → 「換気足りている」と誤読すると
  高二酸化炭素が PVR を上げてシャントを増やす。
- Fontan の**高い中心静脈圧は仕様**。容量指標として読めない。肝うっ血・リンパの
  問題もこの循環の帰結。陽圧換気そのものが肺血流を減らす操作。
- 大動脈縮窄・鎖骨下動脈を使った術式では**特定の上肢の血圧が当てにならない**。
- 出会いの大半は非心臓手術。決めるべきは〈どこで麻酔・誰が関わる・どこまで調べる・
  術後どこで〉の四つ。申し送りで「この患者の普段の値」を伝えないと、
  正常が異常として扱われ、異常が見過ごされる。
