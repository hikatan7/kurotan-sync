ユーザーが財務諸表のPDF(有価証券報告書・決算短信・病院決算等)を添付またはパス指定して分析を頼んだら、以下を自動で実行する(2026-07-10合意)。

**手順:**
1. PDFを読み(pdfスキル使用、スキャン画像ならOCR)、PL・BS・CFの数値を抽出。連結/単体が両方あれば連結を優先し、どちらを使ったか報告する。
2. デスクトップの[[project-financial-analysis-sheet]]「財務分析シート.xlsx」を複製し「財務分析_【会社名】_【決算期】.xlsx」を作成(原本テンプレートは変更しない)。
3. 複製の「入力」シートに転記(Excel COM経由、[[env-word-com-doc-generation]]の方式)。PDFに複数期あれば最大3期分(B~D列)埋める。単位はPDF表記に合わせ、シートのA2注記を更新。
4. 科目マッピングの規約: その他流動資産=流動資産合計−(現預金+売上債権+棚卸資産)のように差額で合わせ、バランスチェック行が「OK」になることを必ず確認。判断が入った科目(例: 有利子負債の範囲)は転記元ページと共に報告する。
5. 完了後、「分析」シートの主要指標(収益性・安全性を中心に)を要約して所見を伝える。

**Why:** ユーザーはPDFを貼るだけで解析まで完了する運用を希望。
**How to apply:** PDF添付+「財務分析して」程度の指示で発動。確認質問はせず、抽出の不確実箇所は結果報告時に明示する。
