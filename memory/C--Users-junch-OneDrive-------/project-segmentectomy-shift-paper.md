デスクトップ「呼外プレゼン資料作成\論文_区域切除シフト_原稿_20260825.docx」(16頁・4,307語・行番号付き)。図は「論文_区域切除シフト_figures」に4点。

**コホート**: RATS 182例→転移性12・良性1除外→原発性169→cT記載なし16除外→**153例**(cT1a/b 81, cT1c+ 72)。

**主結果**: cT1a/bの区域切除率 2024-25 23/56=41.1% → 2026 19/25=76.0%。RD +34.9pt (95%CI +13.8〜+56.1)、OR 4.54、Fisher p=0.0042、傾向 z=+2.39 p=0.017。cT1c+は 2/46=4.3% → 2/26=7.7%、p=0.62、傾向 p=0.71。

**最重要の注意**: **期間×サイズの交互作用は有意にならない(LRT p=0.383)**。cT1c+の区域切除が全期間で4例しかなく検出力不足。「増加はcT1a/bに統計学的に限局した」とは書けない。「cT1a/b内で有意に増加、cT1c+では増加の証拠なし」と分けて書くこと。原稿・Table 3脚注・Figure 2に明記済み。

**防御材料**: ①case-mix不変(cT1a/b比率 51.4/56.9/49.0%, p=0.68。年齢・性別・cN0も不変) ②2026は8か月だが月あたり症例数は最多(8.0 vs 3.7/6.4)＝低集積による見かけではない ③cT欠損16例の最悪シナリオでも2026は54.3%で41.1%を上回る ④**RFID使用率は逆に低下**(36.4→37.5→19.4%)＝局在同定技術がシフトを駆動したのではない。

**プログラム成熟の証拠**: cT1a/b内で累積症例数10例あたり OR 1.19 (1.07-1.33) p=0.0013。2024と2025はほぼ同一(42.1%/40.5%)で2026に跳ねる＝ロボット導入そのものではなく習熟。手術時間プラトー(約40例)の後に選択が変化。

**未解決**: occult N 区域4.4%(2/45) vs 肺葉18.6%(18/97) p=0.036。郭清LN個数・station数がないため「適切な症例選択」か「郭清不足」か判別不能。優先3の入力が前提。

**用語の禁止事項**: cT1a/bを「適応内/trial-eligible」と呼ばない(CTR・末梢性・腫瘍径mm・SUVmaxが無い)。"trial-supported tumour-size range"とする。主張は "no evidence of **size-based** indication creep" までに限定。
