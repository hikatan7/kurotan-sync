2026-09-04 作成。`教育ファイル集\麻酔科ミニ教科書シリーズ\14_血管確保` に
docx／PDF 65頁＋`図版`20点＋`_生成スクリプト`。
[[project-vascular-access-text]] の10頁テキストを土台に、シリーズ体裁で全面的に書き直したもの。

**構成**：全5部19章＋付録A〜F。Ⅰ総論（1三手技が守るもの／2上肢の血管と神経／
3超音波の基礎／4針先を見失わない）→Ⅱ末梢静脈路（5サイズと部位／6穿刺の実際／
7難しい末梢静脈路／8小児・高齢者・特殊な状況／9骨髄路）→Ⅲ動脈ライン（10適応と禁忌／
11穿刺前の準備／12穿刺手技／13留置後の管理／14採血と血液の節約）→Ⅳ合併症と撤退（15〜17）
→Ⅴ体制（18感染対策／19記録・教育）。付録＝ゲージ別流量／スクエア波テスト判定／
トランスデューサ高さの誤差／困ったときの早見表／参考資料／用語小辞典。

**通した主張**：合併症を減らす最大の介入は手技の上達ではなく適応を絞ること。
「入らないときに増やすのは試行回数ではなく人手」。
カテーテルが動脈内にあることと、表示された数値が正しいことは別の問題（第13章）。

**記載方針で決めたこと**
- Allen 試験は「刺す前の関門」ではなく「留置後の観察を補う一情報」として書いた
- 合併症頻度は Scheer 2002 の数値（一過性閉塞19.7%／血腫14.4%／永続的虚血0.09% 等）
- 図16-2（虚血時の行動順序）は**本文と同じ4手順**に作り直した。当初の図は5手順で本文とずれていた
- 元テキストの提供超音波画像は出典未確定のため**一切使わず**、図版20点はすべて新規に作図した模式図。
  その旨を付録Eの「本書に採録しなかったもの」に明記してある

**ビルド**：`bookkit.py`＋`figlib.py`（[[project-anesthesia-minitextbook-series]] の⑬以降の基盤）。
`build14.py` が `c14_p1/p2/p3` に `c14_new`（後から足した第3・8・9・14章と付録F）を
見出し名で差し込む。図版は `fig14_a/b/c/d` と `fig14_f02`。
略語処理は `run_abbr.py <docx> 14`（展開3件・一覧2語のみ＝ほぼ和文で書いたため）。
図版は必ず [[workflow-figure-text-fit]] の**2段構えの検査**を0件まで通すこと。
