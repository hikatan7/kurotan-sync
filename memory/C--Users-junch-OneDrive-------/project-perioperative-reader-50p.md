2026-08-21 作成。`デスクトップ\研修医用教育ファイル\周術期のはじめかた_初期研修医のための麻酔科読本_50頁.pdf`。

[[project-anesthesia-minitextbook-series]]（10テーマ）と研修医用教育ファイル（9テーマ）の
計19テーマを **8章に統合**して再編した読み物。ユーザー選択は「8章×6頁」案。

**構成**：表紙1＋目次1＋8章×6頁＝ちょうど50頁（A4）。図版26点（全て自作インラインSVG）。
①全身麻酔 ②気道と酸素化 ③麻酔薬の薬理 ④輸液 ⑤輸血とアルブミン ⑥腎臓（乏尿・AKI・利尿薬）
⑦区域麻酔 ⑧ハイリスク患者と医療安全。
各章に〈しくみ〉〈ここを間違える〉〈コラム／歴史〉〈計算してみる〉〈症例〉の枠と、末尾に「この章の要点」6項目。

**ビルド方式**（[[project-pptxlib-slide-engine]] とは別系統。docx ではなく HTML→Chrome print-to-pdf）：
scratchpad の `book/` に engine.py（CSS＋ブロック要素）／svglib.py（SVG DSL）／front.py／ch1〜ch8.py／build.py。
- **1ページ＝1ユニットで明示的に組む**（流し込みにしない）。総ページ数がソース側で確定する。
- `.page` は `overflow:visible` にしておく。溢れると PDF のページ数が増えるので検出できる。
- build.py が PyMuPDF で各頁の **fill率（本文最下端／805pt）** を出す。85〜99%を目標に加筆・削除する。
  ノンブルは数字のみのブロックなので除外して測る。

**略語の扱い**（2026-08-21 にユーザー要望で全面改訂）：
**初出時に「英語正式名称：日本語名称」を必ず併記**する。全132語。
- 本文で初出するものは括弧書きでインライン（例：`MAC（minimum alveolar concentration：最小肺胞濃度）`）
- **図や表のなかで初出するもの**は、その直下に engine.py の `abbr()` が出す
  〈初出の略語〉帯（font 8.5pt・左罫線）でまとめる。インライン括弧より版面を食わず読みやすい。
- 検証は scratchpad の `_verify.py`：略語→説明の目印文字列の辞書を持ち、
  PDFから「初出ページ」と「説明ページ」を出して 説明 ≤ 初出 を確認する。
  誤検出よけに ①英数字に挟まれた出現を除く（CO₂ の CO など）
  ②字送りされた英語見出し行（`CO R E  CO M P O N E N T S`）を除く の2つが必要。
- 併記を入れると各頁 +20〜30pt 増えるので、本文 11pt→10.6pt・行間1.80→1.75 ほか
  9か所の級数を落として吸収した。それでも溢れる頁は 1行分ぶん文を削って調整する。

**この方式の落とし穴**：
- SVG は既定でクリップされるので、viewBox からはみ出した文字は**黙って消える**。
  検出するには svglib.svg() に一時的に `style="overflow:visible"` を付けてビルドし、
  PyMuPDF でブロックの x1 > 548pt を探す。確認後に必ず戻す。
- 日本語は 1文字≒font-size 相当。viewBox 幅1000で size 16 なら約60字が上限。
  右端のラベルは `anchor="end"` にしないと切れる（t() の anchor は第6引数）。
- 円や箱を三角配置するときは中心からの距離＋半径が viewBox に収まるか必ず検算する。
- 表のセル内改行は `<br>` ではなく `\n`（engine.md が `<br>` に変換する）。`<br>` はエスケープされて生で出る。
- **bash のヒアドキュメントで Python を流し込むと `\n` や `\1` が壊れる**（`<<'EOF'` でも起きた）。
  バックスラッシュを含む置換をするときは、スクリプトを Write ツールでファイルに書いてから実行する。
