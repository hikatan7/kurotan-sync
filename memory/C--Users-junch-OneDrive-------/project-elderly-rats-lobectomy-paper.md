デスクトップ「呼外プレゼン資料作成\論文_高齢者RATS肺葉切除_原稿_20260825.docx」(17頁・4,324語・行番号付き投稿形式)。図は同フォルダ「論文_高齢者RATS_figures」に4点。

**対象**: RATS肺葉切除116例(182例から区域切除66例を除外)。≥75歳 45例(38.8%)、<75歳 71例。年齢中央値 78 vs 66。

**主結果**: 未調整では高齢群のほうが手術時間が**短い**(144 vs 157分, p=0.045)。しかし性別・重症麻酔区分・pStage II-III・**累積症例数**で調整すると-8.9分(95%CI -21.5〜+3.6, p=0.16)で消失。回復系は全て差なし(ドレーン比1.05、在院比1.06)。**累積症例数だけが全アウトカムの独立規定因子**(手術時間-0.50分/例, p<0.001)。手術時間は約40例でプラトー、在院日数は最後まで改善継続。

**ドラフト案を実データが否定した2点**(重要): ①「高齢者で重症麻酔区分が多い」は誤り(35.6% vs 29.6%, p=0.543)。閉鎖循環式「重症」は分離肺換気・側臥位で付く**算定区分**であり生理学的重症度ではないので、高齢と相関しない。②「高齢者で手術時間が延びる」も誤りで逆方向。

**タイトルの問題**: 合併症・30日死亡・再入院・ICU入室が一切ないため "Perioperative Safety" は主張できない。原稿ではタイトル頁に代替案を併記し、本文はfeasibility/resource useに限定、Limitations冒頭に明記済み。投稿時は代替タイトル推奨。
