**この症例で最も突かれる5点**（発表本人に伝えるべき順）:
1. 11枚目「保存的治療の基準を全て満たす」と13枚目「脊髄虚血がある」の自己矛盾（臓器虚血がある時点で通常の適応外）
2. DOA 5γ使用中の患者を「血行動態安定」と記載（グラフに書いてある）
3. Cre 1.45 を放置して「他臓器虚血なし」と断言、血液ガス・乳酸の提示ゼロ
4. 膀胱直腸障害が残存し自己導尿を要するのに「良好な転帰」「有効」と結語
5. 23〜26枚目の症例表9本が参考文献リストに1本も無い／28枚目に引用番号「X)」「Y)」が残存

**原案の実物確認で分かったこと**: 埋め込み画像11点すべてがPACSモニタのスマホ撮影（色かぶり・モアレ・マウスカーソル写り込み）。患者IDの焼き込みは無し。画像実測は43.75mm／8.33mm で、本文の「偽腔厚7mm」と不一致。
