**2026-09-10以降、デスクトップはローカル(C:\Users\junch\Desktop)なので以下の注意は当てはまらない → [[env-desktop-localized]]。今もOneDrive同期下にある C:\Users\junch\OneDrive\ の 自作ファイル集 / 教育ファイル集 / 病院経営学 / 経営学 / 経営学テキスト / ドキュメント / 画像 に対してのみ有効。**

旧デスクトップ(C:\Users\junch\OneDrive\デスクトップ)がOneDrive同期下だった当時、ファイル操作で以下の問題が実際に発生した(2026-07-05):

1. Test-Path が実在するファイルに対して一時的に false を返すことがある(特殊文字入りファイル名や同期タイミング)
2. 移動先フォルダがユーザー操作/同期で消えていると、Move-Item がファイルをフォルダ名にリネームしてしまう(19MBのPDFが「_重複レビュー」というファイルになった)
3. ユーザーが手動でフォルダを削除するとローカルのゴミ箱に残らないことがある(OneDriveオンラインごみ箱を案内する)

**Why:** 事故が起きてもハッシュがあれば正体を特定して復元できた。パス文字列の手打ちは特殊文字(｜、①、末尾スペース等)で失敗する。

**How to apply:** 一括移動は (1) 実行直前に New-Item -Force で移動先フォルダを保証、(2) パスを手打ちせず Get-ChildItem で列挙してオブジェクト経由で -LiteralPath 移動、(3) 重複判定は SHA-256 ハッシュで照合、(4) Move-Item は try/catch -ErrorAction Stop で結果を正確に報告。関連: [[env-word-com-doc-generation]]

重複整理の運用: デスクトップの「_重複レビュー」フォルダに重複ファイルを退避し、削除はユーザー自身が行う方式で合意済み。

**Excel COM の保存が後から失われることがある**（2026-09-03）。データセットに3シート追加＋2シート差し替えを保存し「sheets after: 59」まで確認したのに、次のマージで開くと56シートの旧状態に戻っていた（Excelは未起動、ロックファイルも無し）。OneDrive同期下では保存が巻き戻る可能性があるため、**連続して別のマージをするときは毎回「直前の変更が残っているか」を実データで検算してから次に進む**こと。消えていたら該当スクリプトを再実行すれば復旧できる。
