麻酔科ミニ教科書シリーズに、専門医向け教科書が未整備だった4分野を追加した（2026-09-09）。
既刊17巻とTeaching fileの一次資料を突き合わせて空白分野を洗い出し、ユーザーが4つとも選択した。

- **⑱ 呼吸管理と分離肺換気** 64頁・図版20点・表4点。シリーズ初の呼吸の巻
- **⑲ 循環管理と循環作動薬** 58頁・図版20点・表2点。⑥（CVC/PAC）の解釈編にあたる
- **⑳ 周術期の心停止と院内急変対応** 55頁・図版20点・表3点。体位・術野の制約とCALSが中核
- **㉑ 周術期の凝固と抗血栓薬** 56頁・図版20点・表3点。休薬と再開、HIT、VTE

各巻とも `教育ファイル集\麻酔科ミニ教科書シリーズ\<番号>_<書名>\` に docx＋PDF＋`図版`＋`_生成スクリプト`。
`00_麻酔科ミニ教科書シリーズ_総目次` も21巻へ更新済み（⑲がカバーしたため候補「術中低血圧と臓器灌流」は削除）。

**Why:** 用量・休薬日数・エネルギー量などの数値は意図的に本文へ書かず、付録D（研究と限界）と
付録E（施設で決めておくこと）に逃がした。改訂の速い領域で誤った数字が一人歩きするのを避けるため。
この方針は⑯⑰から継承している。

**How to apply:** 新規巻は既刊の `_生成スクリプト` 一式（bookkit.py／figlib.py／figkit.py）を
コピーして始める。⑱で追加した QA スクリプトは全巻で使える：
`fitcheck.py`（図版がキャンバス外へはみ出していないか機械チェック）、
`pagebreak_fix.py`（改ページ段落を pageBreakBefore へ置換して白紙ページを構造的に消す。
w:pPr の子要素順を守ること）。bookkit の boxed/column/table には
keepNext と cantSplit を入れ、枠と表行がページをまたいで割れないようにした。
docx→PDF は必ずスクラッチパッドで行う（[[env-word-com-doc-generation]]）。
