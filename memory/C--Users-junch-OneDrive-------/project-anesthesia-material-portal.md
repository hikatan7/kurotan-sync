1ファイルHTMLポータル。**完成（2026-09-02）**：`デスクトップ\教育ファイル集\麻酔資料ポータル.html`
（Gensparkが止まったためClaudeが自作。131資料・198ファイルのリンク実在を全件検証済み）
- 画面構成：SEC-01サマリ／**SEC-02 テーマ別インデックス（15テーマに全131資料名を並べる）**／SEC-03ミニ教科書12巻／
  SEC-04〜08 対象者別一覧／SEC-09使い方。
  画面上部に**大きな選択ボタン**（分野3個・だれ向け6個・テーマ18個、単一選択でトグル解除）。押すと全セクションが同時に絞られ、
  ボタンの数字は他の条件に連動して変わり、0件のボタンは薄く無効化（行き止まりを作らない）。形式のみ小チップで複数選択
- **Office URI（`ms-word:` 等）は日本語パスでは使えない**（2026-09-03 実機検証）。Chromeが日本語を必ず
  パーセント符号化し、Office側がそれを復号しないため。UTF-8・Shift-JISのどちらで符号化しても開かない。
  → 既定は「ふつうのリンク（Chromeがダウンロードフォルダにコピーを落とす）」。
- 元ファイルを直接開きたい場合は自作ランチャー：`_ポータル生成\ランチャーnes-open.js`（WSH/JScript。
  UTF-16LE保存必須、decodeURIComponentで復号、デスクトップ配下限定・`..`と絶対パスを拒否）＋
  `1_ランチャーを登録する.reg`（HKCUのみ、管理者不要）でanes:プロトコルを登録。
  ポータル右上のボタンで「ダウンロード／アプリで開く」を切替（localStorage保存）。
- 教訓：ボタンに付けた `app` クラスが全体レイアウトの `.app{min-height:100vh}` と衝突し、リンクが画面高いっぱいに膨張した。
  新しいクラス名は既存CSSと必ず突き合わせる（この件は `is-app` に改名して解決）

- 目録データ：`デスクトップ\教育ファイル集\_portal_data.json`（184資料＝教育122／経営62。走査先は 教育ファイル集・手術室経営分析・病院経営学\手術室経営・病院経営学\診療報酬点数・自作ファイル集\手術件数推移・呼外プレゼン資料作成_分析レポート・医事課_月次推移分析.xlsm。患者オーダ情報等の生データは除外。
  ファイル名から自動分類。1資料＝docx/pdf/pptx等をまとめて1件、`files[]`に形式ごとのパス）
  内訳：専攻医・研修医50／共通44／専門医28／手術室経営63／看護師5。テーマ17区分（経営は手術室運営・経営24／診療報酬・算定21／実績データ・分析18）。経営分野の資料は対象者を「手術室経営」に一本化（完全ガイド等の語で専門医向けに混ざるため）
- 生成スクリプト：スクラッチパッドの build_portal.py ＋ portal_template.html（JSONを読んで`const DATA`に直書き）
- 生成プロンプト（Genspark用・未使用のまま保管）：`自作ファイル集\プロンプト集\15_Genspark_資料ポータルHTMLを作らせる.md`
- 体裁の手本：`呼外プレゼン資料作成\1_ダッシュボード\3研究エビデンスダッシュボード.html`
  （和紙色#F7F5F0＋藍oklch(0.45 0.08 250)＋墨色、240pxダークサイドバー、SEC—01見出し、A3横印刷）

**Why:** 資料が270件超に増え、対象者別に取り出せないと使われないため。
**How to apply:** 「検索しても出てこない」と言われたら、検索の不具合ではなく“結果が画面外にあって見えない”ことを疑う。
対策済み：**検索ではなく大きなボタンで選ばせる**／テーマ別インデックスを上部に置く／ヒット0のセクションは丸ごと隠す／入力後は自動でインデックスへスクロール／
IME確定を拾うため compositionend と keyup でも再描画。
資料が増えたらJSONを作り直し、HTML内の `const ITEMS` だけ差し替える（HTML再生成はしない）。
ローカルHTMLではfetch不可なのでJSONは必ず直書き、リンクは `BASE + encodeURI(path)`。

**資料を消したら必ずポータルを作り直す**（2026-09-04）。`_portal_data.json` と `麻酔資料ポータル.html` は実ファイルのパスを直接持っているので、削除するとリンク切れになる。`_ポータル生成\更新する.bat`（= `1_目録を作る.py` → `2_ポータルを作る.py`）を回せば目録から作り直せる。NotebookLM 製など9件を削除したあと再生成し、184→**205資料**（教育143・経営62）になった。ミニ教科書⑭〜⑰も同時に取り込まれる。更新前の版は `_ポータル生成\_更新前` に退避。

**デスクトップを動かすとランチャーが壊れる**（2026-09-10）。`anes:` プロトコルの登録先 `HKCU\Software\Classes\anes\shell\open\command` は **anes-open.js の絶対パスをハードコード**しているので、教育ファイル集ごと移動すると「スクリプトファイルが見つかりません」になる。同時に `1_ランチャーを登録する.reg` も旧パスのままなので、再登録しても直らない。両方を直すこと。JS本体は `SpecialFolders("Desktop")` 基準なので移動に強い。生成スクリプト2本の `DESK` はハードコードをやめ `os.path.join(os.environ["USERPROFILE"], "Desktop")` に変更済み。

**病院経営学はジャンクション経由**（2026-09-10）。実体は `OneDrive\_旧デスクトップ\病院経営学` だが、ランチャーがデスクトップ配下しか解決できないため `Desktop\病院経営学` にジャンクションを張って37リンクを通している。⚠️ デスクトップを再帰削除するツールを使うとOneDrive側まで消えるので、整理ツールの対象から外すこと。詳細は [[env-desktop-localized]]
