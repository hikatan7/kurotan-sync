デスクトップ「医事課_月次推移分析.xlsm」(旧.xlsxは削除)を作成(2026-07-20)。市立静岡病院 医事課報告(別冊)PDFの経営指標を月次推移で可視化するツール。VBAで**オフライン完結の貼付取込**対応。

**シート構成**: ①ダッシュボード(B2で対象月選択→カネ系/ヒト系KPI・前月比・前年同月比・予算差引・自動所見が切替) ②カネ系推移(入院/外来 稼働額・単価・合計+折れ線4枚) ③ヒト系推移(新入院・1日平均入院・病床稼働率・平均在院日数・外来1日平均・救急3種・看護必要度①②+グラフ6枚) ④呼吸器外科(呼外の最新月スナップショット8指標+入院/外来/合計稼働額のR06〜R08月次推移+グラフ3枚。診療科別の追加要望に対応、2026-07-20) ⑤予算対比(実績×予算×差引×達成率、実績は自動参照) ⑥使い方。診療科別データは別冊p.9〜14に月次収載(R06/R07全月+R08最新月、前年比表)→他科も同様シート追加可能。

**データ構造の要点**: 各月PDF内に既にR04〜R08年度の全月次時系列が入っている(1枚で推移作成可)。発行月の前月実績を報告(6月版=7/1発行=R08年5月が最新)。テンプレートは毎月同一構造。ダッシュボードはINDEX/MATCHで対象月を動的参照。稼働率・看護必要度は率(pt差表示)、在院日数は日数差(短縮=緑)、他は比率。

**抽出元ページ**: 稼働額/単価/新入院/稼働率/在院日数=別冊p.2(入院)・p.4(外来)、救急=p.6、看護必要度=p.23(暦月→会計年度配列変換、R7.4欠)、予算=p.5。

**月次更新プロトコル**: 新PDF添付 or **テキスト貼り付け(コピペ)**+「医事課 分析更新して」→最新月抽出→②③のR08年度行 該当月セルに転記→Excel COM再計算→当月自動所見レポート。稼働額は医業収益と非一致(稼働額ベース)。[[workflow-financial-pdf-protocol]]と同型。PDFに開封PW有り→ユーザーがPW解除コピー(印刷→PDF保存)を用意する運用。

**コピペ自動入力の可否(2026-07-20検証)**: 単価/患者数/稼働率/在院日数/救急 等の単純表はコピペテキストでも正確に解析可(R04〜R07がPDF値と一致確認)。ツールはR03〜R08の6年履歴に拡張済(4月版=R07.3月報告のコピペからR03年度追加、R07年4月の看護必要度も補完)。稼働額のみR04〜R08。

**オフラインVBA取込(2026-07-20実装・COM無人テスト済)**: .xlsmに⑥月次取込・⑦全文貼付シート+VBAモジュールmodImport。全文貼付シートA3に報告書テキストをCtrl+V→月次取込シートの[①自動抽出]ボタン(ParseFullText)で単価/患者数/稼働率/在院/救急/稼働額(実績額行)を自動入力→[▶推移表へ転記](TenkiCommit)で対象月のR08行へ書込+稼働額合計/呼外合計を自動計算+ダッシュ対象月同期。自動抽出は12指標中12一致(5月テキスト)。看護必要度・呼外稼働額は手入力。VBAの教訓: ①MonthColIndexは文字列一致でなくVal(m)で数値化(エンコード非依存) ②トークン抽出はラベル(R08年度)がSplitで分割される事故を避け「数値トークンのn番目」方式 ③見出し行は目次(頁除外)+括弧[ ( （を含む行に限定しグラフ/目次の誤マッチ回避 ④ChrW(&H3000)で全角スペース(ChrはNG) ⑤率はv>1.5なら/100。.basはcp932保存でVBProject.Import、ボタンはCOMで配置。ビルド手順: build_iji.py(openpyxl→.xlsx)→make_bas.py(.bas)→COMでImport+ボタン+SaveAs 52(.xlsm)。gSilentフラグでMsgBox抑止しCOMテスト可。
