ユーザーは日本語話者の医療従事者（麻酔・集中治療系のテーマが多い：周術期輸液、敗血症、TEE、ICU鎮静など）。複数のAIツール（Genspark、Manus、NotebookLM、ChatGPT等）を使い分けて、医学講義資料・スライド・文献レビュー・診療報酬請求書のOCRなどを行っている。プロンプトの核は「情報完全保持（要約厳禁）・多層的構造化・エビデンス明示」。2026-07-04 に全プロンプトを統一版マスタープロンプトに統合済み。現在の所在はデスクトップ直下の `master prompt.txt`(2026-07-05確認: 旧 `学習ファイル\プロンプト集\【統一版】全AI対応マスタープロンプト.txt` から改名・移動されていた)。構成＝共通コア＋4モード：A=ドキュメント作成（医学／経営学／その他・株式分析の分野別）、B=高密度スライド（1/2/3/5/10/20枚指定・文字大量OK）、C=画像入りスライド（10/20/30枚・文字少なめ）、D=文献検索（高IF・最新・代表的論文20報、リンク・著者所属・データ詳細・2000字以内要約＋統合レビュー）。OCRプロンプトは統一版から除外する方針。医学以外に経営学講義資料・株式分析にもAIを使う。
