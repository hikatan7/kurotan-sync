構成：全5部17章＋付録A〜F。
第I部 3つの成果物・リスク評価の道具・機能的能力（METS study）／
第II部 心血管×2・バイオマーカーとMINS・呼吸器・気道・腎肝内分泌血液・フレイル／

貫くテーゼは「術前評価は可否の判定ではなく、リスクの言語化・修正可能因子の修正・
計画への変換という3つの成果物をつくる作業」。もう一つの軸は「いつ会うかが結果を決める」
（貧血・禁煙・栄養・Prehabilitation はいずれも4週間以上を要する）。

本文モジュール b_front/b_p1〜b_p5 は両方から同じ API で呼べるように書いてある。
図版は figkit.py＋figs11a/b.py（matplotlib、Meiryo）。
