デスクトップ「呼外プレゼン資料作成\論文_RFID区域切除_原稿_20260825.docx」(17頁・4,404語・行番号付き)。図は「論文_RFID区域切除_figures」に4点(Figure4は空枠)。

**コホート**: ロボット区域切除66例(RFID 19 / 非併用47)。別に手術室マスタから留置26件を抽出。

**主要結果**: pTis/pT1mi は RFID 7/13=53.8%(95%CI 29.1-76.8) vs 非併用 2/32=6.2%(1.7-20.1)、OR 17.5、Fisher p=0.001。cT1a/bはRFID 14/14=100% vs 87.9%。手術時間139 vs 149分(p=0.19)で延長なし。occult N 0/13 vs 2/32。

**ワークフロー(論文⑤を統合した)**: 留置26件は全例ハイブリッド室・全身麻酔。処置14分(IQR 10-24)に対し在室64分(IQR 60-79)、非処置50分。年間約11.5時間の手術室消費。**接続26/26=100%**(翌日23・2日後3)。後続術式はロボット区域16/非ロボット区域5/部分4/ロボット肺葉1で96.2%が縮小手術。曜日は水15・月8・火3(火木の手術日の前日)。

**術式名の落とし穴**: 手術室マスタの「気管・気管支ｽﾃﾝﾄ留置術」は**半角カナ**。NFKC正規化しないと0件になる。

**書き方の方針**: RFIDは「予後改善」ではなく「適応の下限を下げた技術」。Mitsumata 2026(RFIDはRFSの独立因子でなくC/T比が最強)を先回りして引用済み。confounding by indicationは定義的であることをDiscussionで明示。

**空欄で提示した部分**: Table 5(断端距離・マーカー精度13項目)とFigure 4(断端距離×腫瘍径の散布図、対角線のみ)を意図的に空で掲載。優先2の3時間で埋まる。数値の代入は一切していない。
