「横断検索プロンプト」「一気に横断検索させたい」と言われたら、以下のテンプレを提示する（2026-08-21作成）。
モデル非依存で、Gemini / Perplexity / Copilot / ChatGPT のいずれにもそのまま貼れる設計。
実行時は [[workflow-chrome-search-two-modes]] の②AI横断検索モードと組み合わせる。

**Why:** ユーザーは医療従事者で、教材・スライド作成のために文献と図版を大量に集める。
速さより網羅性と「URL捏造ゼロ」が重要。AIごとに拾う情報源がズレるため同一プロンプトを複数モデルで回す。

**How to apply:** 【 】を埋めて渡す。出力後は必ず「STEP5の残課題で2巡目を実行して」と追撃する。

## 本体プロンプト

```
【横断検索タスク】
あなたは学術リサーチャー兼キュレーターです。以下のテーマについて、
可能な限り多くの情報源を「一気に横断して」網羅的に収集してください。
時間がかかって構いません。速さより網羅性と正確性を最優先してください。

■ テーマ：【ここに検索テーマ】
■ 目的・用途：【例：研修医向けスライド作成／論文執筆の背景整理】
■ 収集対象：【文献 / 画像・図表 / 統計データ / ガイドライン / 動画】
■ 期間：【例：2015年〜現在。ただし古典的原著は年代不問で含める】
■ 言語：日本語・英語の両方（他言語は要旨のみ可）
■ 想定件数：最低【30】件。上限は設けない。

【検索の進め方（必ずこの順で実行）】
1. テーマを分解し、検索キーワードを日英で20語以上生成する。
   同義語・略語・正式名称・旧称・MeSH/統制語・綴り違いを含め、
   生成したキーワード一覧を最初に提示してから検索を始める。
2. 下記【情報源リスト】を1つずつ順番に当たる。
   1サイトにつき最低1回は検索し、「検索した／ヒットなし」も必ず記録する。
3. ヒットしたものは、その場で出典URL・発行年・発行主体を控える。
4. 全サイトを回り終えたら、重複を統合し、信頼度で並べ替えて出力する。
5. 情報が薄い領域があれば、キーワードを変えて2巡目を実行する。

【情報源リスト】※アクセスできないものは「アクセス不可」と明記
◆ 学術文献
  PubMed / PubMed Central / Google Scholar / Cochrane Library /
  Embase / Semantic Scholar / medRxiv・bioRxiv / ClinicalTrials.gov /
  J-STAGE / 医中誌Web / CiNii Research / 国立国会図書館サーチ
◆ ガイドライン・公的機関
  各国・各学会の診療ガイドライン / Minds / 厚生労働省 / PMDA /
  e-Stat / WHO / CDC / NICE / 各専門学会サイト
◆ 画像・図版（ライセンス条件を必ず確認）
  Wikimedia Commons / Openverse / Flickr(CC) / NIH Open-i /
  PMC内の図表 / Radiopaedia / Servier Medical Art /
  各学会・公的機関の公開図表 / Unsplash・Pexels
◆ 一般・二次情報（裏取り前提で参考扱い）
  各種Web検索エンジン / 専門メディア / 教科書系サイト / 学会抄録集

【厳守ルール】
・URL・著者名・年・タイトルを推測で書かない。実在を確認できないものは載せない。
・確認できなかった場合は「未確認」と明記する。捏造は最大の失敗とみなす。
・見つからなかった項目は空欄にせず「該当なし（検索語：○○で検索済み）」と書く。
・要約は原文の主張を歪めない。断定と推測を書き分ける。
・画像は必ずライセンス（CC BY / CC0 / 転載許諾要 等）と帰属表記の要否を明記する。
　ライセンス不明の画像は「使用不可候補」として別枠にする。
・出力が長くなっても途中で止めず、通し番号を振って再開可能にする。

【出力形式】
◇STEP1：使用した検索キーワード一覧（日英）
◇STEP2：横断検索ログ（表）
  | 情報源 | 検索語 | ヒット件数 | 採用件数 | 備考 |
◇STEP3：収集結果一覧（表）
  | No | 種別 | タイトル | 著者・発行主体 | 年 | 出典URL |
  | 要点3行 | 信頼度(A:一次資料・査読/B:学会・公的/C:二次情報) | ライセンス |
◇STEP4：テーマ別グルーピングと全体総括（定説／論争中／空白）
◇STEP5：残課題と、次に叩くべき検索語の提案

準備ができたら、STEP1から順に開始してください。
```

## 用途別の差し替え

**画像メイン**：収集対象を「画像・図表」にし、STEP3の表を
`| No | 画像の内容 | 掲載元 | 直接URL | 解像度・形式 | ライセンス | 帰属表記の文例 | 商用可否 | 改変可否 |`
に置換。さらに「そのまま貼れるもの」「許諾申請が必要なもの」の2セクションに分けさせる。

**文献レビュー**：厳守ルールに追記 —
研究デザイン（RCT/観察研究/症例報告/総説）を分類、SR・メタ解析→大規模RCT→症例報告の順に並べる、
相反する結論は両論併記して対立点を明示。

## 運用上の注意
- 投げる前にWeb検索機能をONにする（OFFだと記憶から作文しURL捏造が起きる）
- PubMedのPMIDとJ-STAGEのDOIは誤生成が起きやすく、必ず自分でクリック確認
- 1回で終わらせず、STEP5の残課題で2巡目を回すと回収率が上がる
