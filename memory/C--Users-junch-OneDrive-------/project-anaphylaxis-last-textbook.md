2026-09-04 作成。`教育ファイル集\麻酔科ミニ教科書シリーズ\16_アナフィラキシーと局所麻酔薬中毒` に
docx／PDF 61頁＋`図版`19点＋`_生成スクリプト`。
**骨格は玉里順子先生ご自身の院内講義（2022-12-08「局所麻酔薬中毒」33枚）**と
`手術室アナフィラキシーショックシナリオ①.docx`。どちらも「_統合済み元資料」へ退避済み。

**構成**：全5部21章＋付録A〜G。Ⅰ二つを分ける（機序／治療の分岐／麻酔下の徴候）
→ⅡLAST（機序／どこにどれだけ／誰に／対応の順序／脂肪乳剤／予防7か条／準備）
→Ⅲアナフィラキシー（麻酔下の見え方／原因物質／初期対応／難治と二相性／起きたあと）
→Ⅳ「キシロカインが使えない」（既往の分解／代替薬／効かないとき）
→Ⅴ体制（裁判事例／シナリオ3題／チェックリスト）。付録Fは現場カード（順序＋声かけの型）。

**この巻で並べて書いた理由**：見た目が似ているのに治療が逆。
アナフィラキシーはアドレナリンがなければ助からないが、
LAST に通常量（1 mg）のアドレナリンを使うと蘇生後の不整脈リスクが上がると報告されている。

**記載方針**
- 日本麻酔科学会「局所麻酔薬中毒への対応プラクティカルガイド」2017 の枠組みに沿う
- **具体的な用量・希釈・投与経路は意図的に書いていない**（製剤と施設で変わるため）。
  「覚えるのは用量より、どこに置いてあるかと誰が持ってくるか」と本文で述べた
- 局所麻酔薬アレルギーは、報告例のうち IgE 関与の真のアナフィラキシーは1%未満
  （Bhole 2012 Br J Anaesth 108:903-11）。実際に多いのはE添加による頻脈・軽い中毒症状・迷走神経反射・防腐剤
- 10%キシロカイン取り違え事故（2005年製造中止）から「1A で会話しない、mg で言う」を導いた
