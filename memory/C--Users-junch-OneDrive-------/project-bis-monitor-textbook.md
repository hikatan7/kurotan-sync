**この教材の主張**：BIS 40〜60を守る、ではなく **SQI→EMG→SR→raw EEG の4点セットで読む**。
最低値ではなく **SR>0 の累積時間** を記録する。高齢者の目標は45〜55。

**他AIの原稿を検証して直した点（付録Cに全部書いた）** — 同じ誤りが他資料にも流布している：
- 「655例のBIS50 vs 35」＝BALANCEDせん妄解析（BJA 2021）。せん妄 **19% vs 28%**、OR 0.58
- 「ENGAGESでBIS<40が32分vs60分」→ 公表値は **EEG抑制 7分 vs 13分**（JAMA 2019）
- 「2026年のBJAレビュー」「burst suppression >4.4分」→ 一次情報を確認できず不採用
- **日本麻酔科学会「安全な麻酔のためのモニター指針」（2019年3月・第4回改訂）に BIS 40〜60 の記載はない。**
  本文は「⑦脳波モニターの装着について　脳波モニターは必要に応じて装着すること」のみ（原典PDFで確認済み）

新規に足した論点：レミマゾラム（BISが高く出る・目標値未確立）、小児、低体温CPB（1℃で約1低下）、
筋弛緩薬でBIS低下（Vivien 2003）、侵害受容モニター、記録と医療安全。
