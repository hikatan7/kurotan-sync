他院ベンチマークのための財務諸表分析は `デスクトップ\病院経営学\財務諸表\<病院名>\` に1院1フォルダで蓄積している。中身は「原典PDF（年度別）＋ 分析xlsx」のセット。

- 女子医大（R4〜R7財務諸表＋3期財務分析xlsx＋他院比較版）
- 倉敷中央病院（R6のBS/CS/本表PDF）
- 富山大学病院（2026-08-29追加）: 令和2〜6事業年度の財務諸表PDF＋決算報告書＋`富山大学病院_5期財務分析_R2-R6事業年度.xlsx`（①サマリ／②病院セグメント損益／③運営費交付金／④寄附金／⑤出典リンク）

新しい病院を分析するときは同じ構成に揃える。共通テンプレは [[project-financial-analysis-sheet]]、PDFからの数値抽出手順は [[workflow-financial-pdf-protocol]]。国立大学法人の場合は法人全体P/Lではなく附属明細書の「開示すべきセグメント情報（附属病院列）」を使う。抽出できないPDFは [[env-pdf-cid-decode]] を参照。

同ブックの⑥シートに他大学病院ベンチマーク（金沢・新潟・信州・福井・横浜市大＋全国41法人計、令和6事業年度）を収録。交付金比率は富山8.1%＞全国平均7.2%で、業務損益も全国計が赤字286億のなか富山は黒字。

富山大学病院の要点（令和6事業年度）: 業務損益は17.8億(FY2020)→2.3億に縮小、コロナ補助金消滅(▲14.2億)と材料費率上昇(41.5→44.4%)が主因。国が病院分として予算積算する運営費交付金は約16億で逓減、寄附金は年2.2〜2.8億で業務収益の1%未満。
