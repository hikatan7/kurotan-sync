麻酔科ミニ教科書シリーズ全10テーマを2種類ずつスライド化し、2026-08-20に完成。
配置先は `デスクトップ\教育ファイル集\麻酔科ミニ教科書シリーズ\_スライド版`（2026-08-21に移動、pptx 20本）と
その下の `_PDF（閲覧用）`（PDF 20本）。命名は `NN_テーマ名_①専門医版20枚.pptx` /
`NN_テーマ名_②研修医版10枚＋用語解説.pptx`。

テーマ01〜10：麻酔中の輸液管理ベーシック／同アドバンス／血液製剤とアルブミン／AKIと利尿薬／
AKD期管理とCRRT意思決定／CVC・PAC／麻酔薬理ハンドブック／星状神経節ブロック／術中の自己血輸血／
ICUにおける心房細動。

②研修医版には巻末に「用語・略語解説」（3列×6行カード、1テーマ36項目、2ページ）を必ず付ける。
①専門医版には用語解説を付けない（ユーザー判断）。ヘッダは
「静岡市立静岡病院麻酔科　麻酔科ミニ教科書シリーズ スライド版　2026年8月作成Ver1／作成者：玉里順子」。

同形式の別シリーズ（9テーマ：全身麻酔／術前評価と麻酔計画／区域麻酔／輸液管理／ハイリスク患者の麻酔／
医療安全／プレゼンテーション方法論／アルブミン・輸血管理／声門上器具と気道トラブル）が
`デスクトップ\教育ファイル集` の直下にある（旧「研修医教育」、ユーザーが2026-08頃に改称）。
生成基盤は [[project-pptxlib-slide-engine]]、元テキストは [[project-anesthesia-minitextbook-series]]。
