デスクトップ「**教育ファイル集**」（ユーザーが2026-08に「研修医教育」から改称）を、
麻酔・周術期の教育資料の**唯一の集約先**にした（2026-08-21、45件 → 270件）。

構成：
- 直下 … 研修医向けスライド9テーマ×2種（01_全身麻酔〜09_声門上器具と気道トラブル）と
  `_PDF（閲覧用）` / `動画リスト`（mp4 7本）、読本4点（周術期のはじめかた50頁・声門上器具・
  血管確保の実際10頁・エコーガイド下橈骨動脈穿刺）
- `麻酔科ミニ教科書シリーズ` … 全11巻＋`_スライド版`（[[project-anesthesia-minitextbook-series]]
  [[project-minitextbook-slides]]）
- `麻酔・気道管理` … 旧 `学習ファイル\医学\08_麻酔・気道管理` の12件（気道管理コース、脊髄幹麻酔、
  Grade A帝王切開麻酔、令和8年度改定の鎮静・麻酔ガイド等）
- `周術期・術前管理` … 16件。デスクトップ直下にあった麻酔資料5点と、`学習ファイル\医学` の
  01/06/07/09 から抜き出した周術期資料11点

**Why:** 麻酔資料が「学習ファイル\医学」とデスクトップ直下に分散していた。移動（コピーではない）
方式・事務経営系は対象外、はユーザーの明示指示（2026-08-21）。

**How to apply:** 麻酔・周術期の教材を新規作成したらここに置く。**経営・事務系の麻酔ファイル
（麻酔科待機回数表、医師派遣依頼書、手術麻酔検索結果xlsx、手術室経営分析の麻酔グラフ、
麻酔材料価格表、SACMA研究会の運営資料）はここに入れない** — 現状の
`手術室経営分析` / `病院経営学` / `呼外プレゼン資料作成` / `第9回SACMA研究会` に残す。
移動手順は [[env-onedrive-desktop-file-ops]]、体系は [[project-desktop-folder-layout]]。
`学習ファイル\医学` の残りは非麻酔領域が中心（[[project-teaching-file-folder]]）。

**2026-09-09 追記**：Teaching file の 174 件を
`一次資料（講義スライド・文献）\`（10分類）として取り込み、
ミニ教科書シリーズに ⑱〜㉑ を追加した（[[project-minitextbook-18to21.md]]）。
既存ファイルは麻酔資料ポータルがパスを参照しているため一切動かしていない。
ポータルは再生成済み（388資料）。`学習ファイル\医学` の 51 件も同日に取り込み、同フォルダは削除した（移植6件のみ `学習ファイル\移植` へ）。一次資料は計225件、教育ファイル集は1,032ファイル。
