教育ファイル集に2本ある。**一般版が最新**。

- `学会発表の基本_口演・ポスター・講演・シンポジウム_研修医専攻医版.pptx`（32枚＋PDF、2026-08-31）… **最新・これを使う**。具体的な題材を含まない一般版
- `学会発表の方法論_口演とポスター_研修医・専攻医向け.pptx`（38枚、2026-08-27）… 旧版。CSFD演題を例に使っており、一般版に置き換え済み。削除するかはユーザー判断待ち

**一般版の構成（32枚）**: ①〜③導入とスケジュール ④発表形式4つ（口演/ポスター/講演/シンポジスト比較表）⑤⑥形式別の勝ち筋 ⑦〜⑩作る順番・主張1文・構成の型・抄録 **⑪〜⑯倫理6枚**（同意／個人情報の匿名化／画像に残る個人情報／死亡例・合併症例／トラブル7類型／発表前に通す手続き）⑰〜㉑スライド作法 ㉒㉓考察 ㉔㉕文献 ㉖Limitationと結語 ㉗発表の仕方 ㉘質疑 **㉙㉚国内学会と国際学会** ㉛チェックリスト ㉜まとめ

**既存の `07_プレゼンテーション方法論` とは別物**。07は院内レクチャーの設計論（認知負荷・逆向き設計）。統合しないこと。

覚えておく数値：口演は枚数＝発表分数×2・1枚30秒・日本語300〜350字/分。ポスターは掲示パネル幅90×高さ180〜210cm、A0縦1枚、本文24pt以上・図7:文字3。

**How to apply:** 改訂は scratchpad の `deckkit.py` ＋ `mk_deck_d.py`（一般版）／`mk_deck_c.py`（旧版）を再実行。QAは PowerPoint COM → PDF → PyMuPDF で目視。ps1は必ずUTF-8 BOM（BOM付与は「読んでから書く」こと。`open(w).write(open(r).read())` は先に truncate されて中身が消える）。日本語パスは `[Environment]::GetFolderPath('Desktop')` ＋ワイルドカードで回避。実例教材は [[project-jscva2026-abstracts]]。
