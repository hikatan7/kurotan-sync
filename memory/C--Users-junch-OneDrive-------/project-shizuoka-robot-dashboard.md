デスクトップ「呼外プレゼン資料作成」に `静岡県_呼吸器外科ロボット手術ダッシュボード_20260826.html`（652KB・単一ファイル完結）を作成（2026-08-26）。Genspark版は画像がイラストのままで解決せず、クレジット節約のためClaude側で全面再構築した。

**構成:** 県内12施設。Leaflet地図＋Chart.js（年間件数／ロボット件数／比率／指導医数の4切替）＋写真カード＋検証状況つきデータ表＋医療上・経営上の分析。医療圏フィルタは地図・カード・表・グラフに同期。

**データ基盤:**
- 手術件数は既存の `比較データ\呼吸器外科比較（静岡医療圏中心）.xlsx`（出典シート付）が正。
- 決定打は日本呼吸器外科学会「ロボット支援手術プロクター名簿」PDF（https://jacsurg.gr.jp/qualification/dl_mtm/pro_list.pdf ）。静岡県内は9名＝がんセンター3・浜松医大2・**静岡市立静岡病院1（玉里滋幸）**・聖隷三方原1・順天堂静岡1・藤枝市立1。Gensparkは順天堂のみと記載していて誤り。
- 自院の訴求点はロボット比率27.1%（公表施設中で最高。浜松医大14.9%）。件数の絶対値では東部・西部に劣るので比率と指導医で立てる。

**写真:** Wikimedia Commonsの再利用可画像12枚を480x360にリサイズしBase64直埋め。原本と出典一覧は `病院写真_出典付き\`。CC BY/CC BY-SA は転載時に撮影者＋ライセンス表記が必要。

**再利用:** `施設データ_検証済み_20260826.json` に全データ＋出典＋検証状況を保存済み。他AIに読ませる場合はこれを渡せば再検索不要。

注意: 外部CDN（Leaflet/Chart.js/OSMタイル）を使うのでArtifact化すると地図が出ない。ローカルHTMLのまま運用する。

**全12施設×5年の病院指標を収集（2026-08-29）:** 「非公表」としていた5施設（県立総合・浜松医療センター・済生会・磐田・赤十字）も全て病院指標を公表していた＝当初は調査漏れ。胸腔鏡下肺悪性腫瘍手術K514-2系の令和2〜6年度推移。
- **令和6年度の順位:** がんセンター312／聖隷三方原176／**県立総合113**／**自院105**／聖隷浜松103／浜松医大90／磐田78／藤枝68／浜松医療C47／順天堂静岡38／済生会27／赤十字0（全項目10例未満）
- **最大の発見:** 静岡県立総合病院は5年間113〜124件で安定した県内3位規模だが、**呼吸器外科ロボットの施設基準は届出なし＝全部VATS**。ロボットの有無と症例数は直結しない。
- **自院はR5 52件→R6 105件で倍増**。ロボット施設基準の届出（令和6年6月）と時期が一致。ただしR2〜R5は52〜74件で上下しており、次年度維持できるかが検証点。
- 聖隷浜松は82→103と一貫増（区域13→32）。赤十字は17→0へ縮小。浜松医大は70→90で横ばい。
- URL規則: 県立総合 `/sogo/shihyo/{年}/`、磐田 `/dpcinfo/{年}/template_R{n}.html`、赤十字 `/dpc/{年+1}/`、浜松医療C `/DPC/template_R{n}.html`、自院 `/dpc/{年}/template_R{n}.html`、済生会は1ページに全年度（アンカー #R-06 等）、がんセンターはTSV `/cms/wp-content/uploads/{年}/09/qi06_ope_days_top5.tsv`
- 三方原・順天堂静岡は当該年度のみ公表で過年度アーカイブなし。がんセンターは令和4年度からの3年。
- データは `3_ダッシュボード元データ\DPC病院指標_呼吸器外科5年推移_20260829.csv` と公的データJSONに保存。ダッシュボードに「年度推移」セクション追加済み。

**第3のダッシュボード（研究エビデンス版）:** `プロンプト_Genspark_研究ダッシュボード_一発生成用_20260826.md`。Genspark用に全データを本文へ直接埋め込む一発生成方式（Gensparkはファイル添付が機能しない）。検証済み研究20件・のべ179,920例を収録。中核数値＝RVlob試験(RCT 320例, 3年OS 94.6%対91.5%, 非劣性p=0.0029)／RAVAL試験(ICER $14,925.62/QALY)／Ma 2021メタ解析(11,247例, 開胸移行OR 0.50, 在院-1.12日, 費用+$3,909.87)／Pagès 2024(施設の学習曲線は94-174例・中央値110例、通説の25例を否定)／Watkins 2024(STS 9,927例, 2019年に区域切除でRATSが最多)。自院の3研究(高齢者116例・区域切除シフト182例・RFID 54例)を文献の中に位置づける構成。
