同一学会に静岡病院麻酔科から2演題。2026-08-31に `教育ファイル集\JSCVA2026` へ統合済み。

- `00_共通_発表の作法` … 学会口演スライドの作り方（[[project-conference-presentation-lecture]] の7分版）
- `01_村中_CSFD対麻痺` … 「偽腔血栓閉塞型A型解離＋対麻痺にCSFD」。原案38枚→本編14枚に再構成済み（[[project-csfd-oral-presentation]]）
- `02_押坂_巨大冠動脈瘤とTEE` … 全27枚（実質21枚、ビルド複製5組）のレビュー＋`再構成スライド案_タイトルバー統一版.pptx`（23枚・30MB、2026-08-31）。統一タイトルバー＋右上に①形態/②血栓/③瘻/④圧迫/⑤術後の現在地インジケータ。原案のGIFループは再埋め込み済み。転載図（JACC Central Illustration）とロダン写真は不採用
- `03_文献検索` … Perplexity用プロンプト2本（txt＋使い方docx）。Research/Academicモード指定、STEP4で症例報告一覧表＋自験例を最終行に、STEP7で「考察に書けること／書けないこと」を出させる設計

**押坂演題の核心指摘**（伝えるべき順）:
1. 術後経過・転帰のスライドが1枚もない／病理結果もない（TEEで「真性瘤」と読んだ答え合わせが無い）
2. 演題名「TEEの役割」なのに、TEE所見と術中所見・病理の対応表が無い → これを1枚足すと発表が別物になる
3. 5枚目の副題「RCAは大動脈から起始していない可能性」は医学的に成り立たない（早期相で染まらないのは瘤内の血流が緩徐なため）
4. 9枚目で提示する5評価項目と24枚目でまとめる5項目が不一致
5. 瘤内圧を橈骨動脈圧と比較している（末梢増幅）／測定手技が未記載

押坂演題はスライドの基礎（PACS正規エクスポート、患者情報なし、配色統一）は前回より良い。演題番号「◯」が未確定で発表時間が不明のため、7分／10分の両方で削減案を提示してある。

**How to apply:** 再確認は scratchpad の `osaka.pptx` → PowerPoint COM で PDF 化 → PyMuPDF でコンタクトシート化して目視。生成スクリプトは `mk_doc2.py`。
