月次オカレンスレポート（麻酔科／CE／NS）を頼まれたら、毎回**2点セット**で作成する。片方だけでは不足。

1. **詳細版**：`手術室オカレンス・マンスリーレポート_YYYY年M月度配布用.docx` ＋ PDF（全6頁前後）
2. **会議提出用サマリ**：`手術室オカレンス_会議用サマリー_YYYY年M月度.docx` ＋ PDF（**きっかり2ページ**）

**会議用2ページの必須要素**（ユーザー指定・2026-08-05）
- 手術件数（総手術件数・麻酔科管理件数）と総オカレンス件数、100手術あたり発生率
- **グラフ**（職種別月別推移＋分類別×職種の2点）は絶対に入れる
- **Good Job / Good Catch** は重要項目として独立セクションで扱う
- 加えて：職種別件数・報告率の表、今月のポイント、注目事象（上位5件）、重点対策（担当・期限つき）

**Why:** 会議では数値・推移・良い実践が一目で伝わることが重視され、詳細は別添で足りるため。

書きぶり（件数増を報告文化の定着として肯定的に評価する／指標名は「100手術あたり報告件数」）は [[feedback-occurrence-report-positive-framing]] に従う。

**How to apply:** 保存先は `デスクトップ\自作ファイル集\オカレンスレポート作成\`。生成スクリプトは同フォルダ `_生成スクリプト\` に前月分が残っているので、それをデータ差し替えして再実行するのが最短。書式は2026年6月度配布用docxをテンプレートに python-docx で生成し、Word COM でPDF化＋ページ数を必ず検証する（[[env-word-com-doc-generation]]／[[project-occurrence-tool]]）。
麻酔科の件数は「総計－99.オカレンスなし」で実件数を出す。手術件数は医事課提供値（`自作ファイル集\手術件数推移\YYYY年手術実績_匿名化.xlsx` は月遅れのため、無ければユーザーに確認する）。
