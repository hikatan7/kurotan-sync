2026-09-04 作成。`教育ファイル集\麻酔科ミニ教科書シリーズ\17_区域麻酔と脊髄幹麻酔` に
docx／PDF 60頁＋`図版`19点＋`_生成スクリプト`。

**下敷き**：①当院の初期研修医教育用スライド `03_区域麻酔_①専門医版20枚.pptx`（玉里順子・2026-08）
②脊髄幹ブロックハンズオンワークショップ（東京女子医大 笹川智貴）
③体幹部神経ブロック インストラクター用資料（瀧澤菜々）④脊髄幹麻酔セミナー（津久井亮太）。
**②〜④は他施設作成のため退避せず原資料として残置**。数値と考え方だけを自分の言葉で書き直した。

**構成**：全5部19章＋付録A〜H。Ⅰ設計（処方として選ぶ／組み立ての順序／薬物予算／抗血栓薬）
→Ⅱ解剖（背面から脊髄まで／脊髄円錐／血管支配）→Ⅲくも膜下（何をしているか／広がり／麻酔高位／合併症）
→Ⅳ硬膜外（抵抗消失／カテーテルとテストドーズ／投与量／硬膜外血腫）
→Ⅴ超音波と末梢（ランドマークの限界／プレスキャン／腰椎の超音波／末梢ブロックの原則）。

**通した主張**：区域麻酔は手技ではなくリスクを調整する処方。
部位は「刺せるか」ではなく「出血したときに引き返せるか」で格付けする。
上手くなるとは「この症例では選ばない」と言えるようになること。

**押さえた数値**：黄色靱帯 L2-3 で3〜5mm／皮膚から硬膜外腔まで約4cm／カテーテルは頭側3〜5cm／
テストドーズは心拍数20回/分以上増加（妊婦はE添加不可）／硬膜外1分節あたり20歳代1.5mL・60歳代1.0mL／
硬膜外血腫1万〜3万例に1例／血小板は10万以上が望ましく硬膜外8万・くも膜下5万未満は非推奨／
アダムキーヴィッツ動脈はT12・L1左側が約65%／ランドマークで腰椎椎間レベルが当たるのは29%／
超音波は深さを平均4.68mm過小評価。

**ビルド**：`build17.py`＋`c17_p1/p2`＋`c17_new`（後から足した第10章と付録G・H）。
